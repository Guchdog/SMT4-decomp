I also scanned every byte of the selected image's configured actual text span `[0x00100000,0x003FE624)` for contiguous all-zero runs. This is a bounded byte scan, not proof that no nonzero dead-code interval exists. The segment configuration gives text size `0x2FE624` and aligned size `0x2FF000`; the image and this audit do not establish runtime page permissions or absence of computed references.
