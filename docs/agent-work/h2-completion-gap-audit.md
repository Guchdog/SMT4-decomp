## Decision

H2 remains open. I found **no criterion proved end-to-end**: criteria 1–4 have useful but manually reported runtime subsets, criterion 5 has substantial bounded offline evidence with explicit HLE and domain limits, and criterion 6 has no completed matched-input original-versus-patched observer capture. The H2 runtime retry is currently `claimed` by the integrator, so its outcome is not yet evidence.

The smallest complete route is: reconcile a single reviewed final IPS/image with the accepted production replacements; confirm the existing CTM actually covers the required H2 actions (otherwise obtain a human CLI recording); complete the assigned paired original/patched CLI observer run with identical CCI/CTM and capture complete records; independently review the comparison; then update the H2 function records, milestone and board before opening H3.

## Remaining prerequisites and closure sequence

1. **Non-runtime integration/provenance:** produce and independently review one final production-derived H2 image/IPS/manifest that explicitly composes the latest five callback replacements with the accepted mapper and FillPair replacements; retain CopyPair's matching body. Ensure the staged runtime patch is that exact reviewed image, with source/object/image/IPS hashes and truthful ledger classifications. Resolve any direct dependency chosen for the H2 scope that remains original or document it as a bounded dependency without claiming its behavior reconstructed.
2. **Input suitability preflight:** the integrator's current runtime task must confirm that the pinned CTM is valid and actually covers entry, each required direction/endpoint, cancel, confirm, re-entry and the persistence action being claimed. If not, request a human-made CLI recording; no synthetic/input automation substitute.
3. **Matched runtime evidence:** using the reviewed CLI/wrapper, same pinned CCI and exact CTM, run original and patched profiles serially from verified isolated seeds. Capture complete terminal JSONL and logs, commands/PIDs/exits/hashes, exact `g_ConfigBytes[0..2]`, TitleConfig work/cursor/touch snapshots and logical-query arguments/results. Compare the actions/results and restart persistence that the CTM covers. No savestate load/save in the deterministic movie replay (per [movie-order review](h2-private-azahar-movie-order-review.md)); no GDB/RPC or host input automation.
4. **Independent runtime review and closure:** review paired evidence and first counterexamples; update function records/ledger, H2 milestone result and board. Only after all six criteria are supported and no in-scope failure remains should the coordinator close H2 and proceed to H3.

The report distinguishes partial manual observations from exact guest/runtime evidence. The board, static candidate presence, passing bounded suites and accepted worker tasks do not themselves close H2.
