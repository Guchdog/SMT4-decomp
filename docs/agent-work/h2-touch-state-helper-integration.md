# H2 `UiTouch_GetRegionTouchState` source integration

## Result

Promoted `ui_func_0029d8fc` from a no-argument naked ARM wrapper to a typed
production C++ helper in `src/engine/leaf_batch23_b.cpp`. The function reads
the active manager index at `+0x64E` as signed `s16`, compares it to the
canonical signed `s16` input, and returns manager `+0x08` as a zero-extended
`s32` only on equality. Its manager pointer comes from `0x0043DCB4`. The helper
is read-only; callers must supply an initialized manager.

The H2 Calc caller uses `LDRSH` before calls for handles at `work+0x1C`,
`+0x1E`, `+0x20`, and `+0x22`. The H2 getter return comparisons are exactly
values 1, 2, and 6; the report does not name those values as actions.

## Limits and handoff

This establishes only the getter contract for an initialized manager. The raw
byte's event meaning, the `TOUCH CALC` callback's timing relative to H2 Calc,
the relation between its active index and H2 handles, physical input mapping,
visible UI, persistence, and runtime behavior remain open. The 44-byte
function is source-integrated, but has not been installed in the H2 patch image.

Independent review is required before accepting this task. Do not promote this
bounded helper result into H2 runtime acceptance.
