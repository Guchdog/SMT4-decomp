# H4 integer divide experimental candidate

`experiments/semantic_equivalence/h4_integer_divide_candidate.cpp` models the pinned ARM 0x002C615C with unsigned 32-bit magnitudes and a 32-step shift/subtract loop. Modular negation avoids signed overflow; the 64-bit unsigned scalar packs quotient bits low and remainder bits high. For divisor zero it returns the original dividend as remainder and zero quotient, matching the pinned 0x0014E604→0x001524EC behavior in this image, not a general language division policy. INT_MIN/-1 yields wrapped quotient bits. No `/` or `%` or signed overflow is used; extracted 128-byte ARM candidate has zero relocations, so no unresolved division/libc call or recursive 0x002C615C dependency was present in this compiled object.

`tools/h4_integer_divide_experiment.py` compiled with `build_check.py` ARMv6K hard-float flags into the private output directory, extracted the candidate and rejected all relocations. It executed pinned original and candidate with the same r0/r1 inputs on Unicorn ARM11, mapped stack and fixed LR sentinel; initialized r4-r11 distinctly. 121 directed pairs from {0,1,2,3,5,17,INT_MAX,INT_MIN,INT_MIN+1,-5,-1}, plus 512 deterministic random pairs (seed 20261028), total 633: all returned, no faults, zero differences in r0/r1/SP/r4-r11, and no non-stack writes. The 64-bit scalar return ABI is supported by compiled ARM r0 low/r1 high results across inputs including distinct nonzero quotient/remainder. Full per-case values are in `checks/final-20261028/report.json` and the first counterexample is null. AST parse and `--help` passed.

Stack effects are deliberately **not equivalent**. The original divisor-zero path saves dividend and LR in two words at SP-8/SP-4; candidate divisor-zero path performs no stack write. Candidate nonzero paths save r4-r6/LR at SP-16..SP-4, while the original normal path has no stack write. The harness records examples and checks SP restoration, but does not compare stack bytes as an equivalence criterion; these differences are material for stack-fault, asynchronous observation, or complete machine-state equivalence. Condition flags, untouched scratch registers, stack-depth/fault conditions, and arbitrary memory mappings are outside the validated contract.

Same-input negative control compiles a mutant from the candidate under build/, replacing the zero-divisor remainder with zero. For `(17,0)`, original returns r0=0,r1=17; mutant returns r0=0,r1=0 and detection passes. Mutant source/object/code hashes and outputs are in the report. Earlier `checks/seed-20261028` was a preliminary 633-case run before per-case result recording; final report is the authoritative rerun with unchanged candidate. No caller composition, production replacement, emulator/runtime or player-control claim is made. Independent review and offline selector caller composition are required before promotion.
