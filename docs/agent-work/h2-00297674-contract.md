No argument register is consumed. r0 returns the second read unchanged, including all high bits; there is no comparison, truncation, sign/zero conversion, helper call, write, stack operation, or VFP instruction. r1-r12, SP, LR, callee-saved registers and condition flags are unchanged by these instructions; normal return uses LR interworking. The literal is an address of a static slot group, not the fetched object pointer: the effective pointer slot is 0x0043E190. The first slot and the pointed-to word must be readable; there is no null guard. A null/invalid pointer may fault depending on memory mapping; do not turn it into zero.
