# 0x002bf030: bounded static contract and tail service

## Scope and ABI

Static disassembly of ARM code.bin SHA-256 `1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558`. Original 0x002bf030 is 120 bytes including literal 0x00009249 at 0x002bf0a4; source packet pins `src/engine/leaf_batch41_b.cpp` SHA-256 `0918a76e494b95f54ab62f4139a85c9bbe18d5a44fd1d5a45d82a124bcf27384`. No candidate, build, Unicorn or emulator was run. Function takes raw object pointer r0 and selector word r1, saves/restores r4-r5, leaves r0 unchanged until tail-branching to ARM 0x00138934(obj,selected). Its externally observable return is the service's raw r0, not generally the original object. Existing `0x002b8d24` index 11 calls this function twice with selector 7, discards each r0, then performs its own byte-store tail.

## Pointer graph, scan and selection

Read pointer `p = *(u32*)(obj+0x48)` then unconditionally read `n = *(u16*)(p+8)`; no null checks precede these reads. The literal is 0x9249 and count is `((n*0x9249 + 0x9249) modulo 2^32) >> 20`. Because n is u16 this never overflows and a host-side enumeration of all 65536 values found count equals integer `n/28` throughout that input domain. Preserve the raw formula or prove equivalent for target widths. If count=0, selected=null without reading p+0x1c. If count>0, table=`*(u32*)(p+0x1c)`; neither table nor its entries are null-checked.

Set scan index i=0 and marker count k=0. At each iteration while i<count, first compare k to the full 32-bit selector. If equal, select pointer `table+28*i` immediately, **before** reading its first word. Otherwise read the entry's first word, increment k if that word is exactly 0xffffffff, increment i and continue. If no iteration selects, selected=null. Thus selector 0 chooses the first entry when count>0 regardless of its marker, and a marker in the last entry does not itself cause a later selection once the loop ends. Selector is not narrowed. Precondition normal valid object/p/table storage, alignment and non-wrapping 28-byte strides for all reads and the selected service's needs; aliases and concurrency require separate characterization. 0x002bf030 itself makes no data-memory store before tail B 0x00138934, but the service performs extensive writes.

## 0x00138934 service and return

Entry r0=obj, r1=selected. First it stores the selected word at obj+0x78. If selected is zero it returns immediately with raw r0=obj. For nonzero selection it saves r4/r5/lr, keeps obj in r4, clears halfwords obj+0x7c,+0x7e,+0x80,+0x82 and writes byte 1 at obj+0x84. Reads the signed 32-bit first selected word; if nonnegative, calls ARM 0x002bdac0 with r0=obj, r1=sign-extended low halfword of that word, r2=sign-extended selected byte +4. This dependency itself reads obj+0x4c and may update obj+0x50/+0x52/+0x86/+0x8a/+0x54/+0x0c/+0x10 and derived data; its full bounds and effect contract remain separate. The service reloads selected from obj+0x78 after this call, so aliases or callee mutation cannot be silently ignored.

Next the service reads selected+0x0c as signed word; if nonnegative and obj+0x58 is nonzero, it stores the low halfword at obj+0x5c, zero halfword +0x5e, zero bytes +0x87/+0x8a, signed selected byte +0x10 truncated at obj+0x60, then uses the sign-extended low halfword as a stride-12 index into the list at obj+0x58. Byte +0x10 equal zero selects entry offset 0, otherwise +4; selected word is stored obj+0x20. Valid list indexing, including any negative sign-extended index allowed by real inputs, must be established, not assumed. This is analogous to 0x002af854 but is inline ARM and has its own signed input behavior.

Then it reads selected+0x14 as signed word; if nonnegative and obj+0x64 nonzero, similarly writes halfwords +0x68/+0x6a, bytes +0x88/+0x8a and mode +0x6c, reads a stride-12 list entry, and stores its selected word at obj+0x24,+0x28,+0x2c. Mode comes from signed byte selected+0x18. The service again reloads obj+0x78 before subsequent reads.

Finally reads signed selected word +8. If negative, branches to epilogue leaving r0 equal to that raw word. Otherwise it reads pointer obj+0x48 and halfword at that pointer+6, computes an entry count by shifting right two, and searches its +0x18 table using stride 4. It compares an ordinal counter with sign-extended low halfword of selected+8 before reading each table element; it increments that ordinal for each signed halfword -1 encountered. On no match it stores 0 at obj+0x70 and returns r0=0. On match it stores the selected entry pointer at obj+0x70; clears halfwords +0x74/+0x76 and bytes +0x89/+0x8a; loads signed halfword from that entry, writes it as a word at obj+4 and writes 0xffffffff at obj+8 using STRD, and returns the sign-extended loaded halfword in r0. Memory alignment and object/table alias constraints must be checked. This summary assumes no fault and does not assign semantic names.

The service's `push {r4,r5,lr}` is 12 bytes; at its conditional BL to 0x002bdac0 the guest SP is 4 modulo 8 if entry SP was 8-aligned. Do not invent an original 8-byte-aligned internal call as an observed fact. The external 0x002bf030 entry itself saves/restores 8 bytes then tail-branches; the retained original service preserves the original internal behavior. A C++ reimplementation of the service or ABI change would need separate validation of its callers and guest behavior.

## Validation plan

Start with a full 0x002bf030 candidate retaining the original service, rather than silently replacing it. Compile independently and compare original versus C++ with real service under Unicorn ARM; compare raw r0, SP, r4-r11, ordered calls, writes and full relevant state/faults. Direct cases: n=0,1,27,28,55,56 and 65535 with adequate tables; selector 0,1,7, out-of-range and 0xffffffff; markers in first/middle/last positions, no marker and consecutive markers. Distinguish selected=null, selected nonnull with all signed service fields negative (no nested call), valid nonnegative fields and service subpaths, and 0x002bdac0 invocation with a fully initialized valid graph. Two reproducible random seeds and disjoint ordinary memory are the starting domain; test aliasing separately before broadening it.

Negative controls: change scan comparison order, off-by-one count or stride, wrong marker, return obj instead of raw service r0, omit null-pointer +0x78 store, or substitute signed/unsigned narrowing. Assert each mutation is unique and detected. Measure behavior when service returns obj, negative word, zero and positive/negative signed halfword. Check actual target ARM mode/interworking and VFP/ABI context of composed caller. Compare original 0x002b8d24 index 11 with candidate replacement at both BL sites, fully initialized subobjects and valid original service; compare tail byte at obj+0x405 and raw r0. Offline gates and paired H2 runtime are required before promotion. Full original helper calls and dependencies remain enumerated as unresolved until independently validated; source and runner hashes plus outputs must be pinned.
