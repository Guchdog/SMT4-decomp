# H2 callback split packages independent review

The Calc and Draw/Secondary patches independently partition the 3,413 differences in the previously tested callback-only image. A separate in-memory IPS decoder verified bounded, nonoverlapping record writes and both composition orders from pinned original SHA-256 `1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558` to callback-only SHA-256 `84c6eb66a6f9a2a23d46e08df4eb04d723fef852c0b8bd3405945f9dbdd5ae32`. Every changed byte belongs to its declared nonoverlapping range and agrees with the callback image. This establishes file composition, not behavior.

Calc owns entry `0x1ea928–0x1ea92c` and body `0x3fe624–0x3fee54`, 1,800 changed bytes; its staged IPS SHA-256 is `3f9c30d98f314c37d86e413b869c74d43ece5acb8398d18861740668507e0283` and resulting image hash `c9ebf62679043512c22c684b50f9e9cbf1fe824e016f119c2de4bddf664eb45d`. Draw/Secondary owns main `0x2cafd0–0x2cb588`, helper `0x3fee54–0x3feed0`, format bytes `0x3feed0–0x3feed3`, secondary entry `0x2caef0–0x2caef4`, and body `0x3feed4–0x3ff000`, 1,613 changed bytes; IPS hash `6b09cae37cd70dda20ea46fda274dd3dca13e880e94ddb5e905fadecb12146cd`, image hash `7ebd3fed310dc102f961ce14c31d069d06149b3d1cf79c3b5fc346a13bfcee93`. Intervals are half-open and agree with the reviewed placement manifest. All seven recorded Draw ARM BL sites independently decode to the included helper `0x3fee54`; the format pointer and `%s` literal point within this subset. This verifies those references, not every possible dependency or reachability.

Both diagnostic app trees have 60 identical non-user files; both executables match pinned SHA-256 `c248414eb5328cb8bb720775ace6959898e2f50a0a10221c3a1e7a14190183eb`. Their initial user profiles have the same three config, MAC and NAND seed files except for the respective IPS, with no game save. The shared CCI matches `9cc760c2f37da9a4a3657e918e0eaebb3e8e80a91047e5c18f95aedf0242b4c2`. Both INI files explicitly disable GDB and RPC; the documented commands select the respective executable and shared CCI without a GDB option. Recheck the profile and actual patch load in logs during any user-controlled attempt; stage contents were read-only and are not frozen packet inputs.
