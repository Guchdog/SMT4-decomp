# H2 APT utility-4: offline layout experiment

An isolated reference-based image was built with a four-byte ARM B at 0x002C0EFC and the complete 56-byte candidate at provisional 0x003FEE54. The entry branch is d4f704ea. The pinned reference SHA-256 is 1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558. Exact object, image, source hashes and compiler command are recorded in build/agent-work/H2-semantic/h2-apt-utility4-layout-offline/run-001/final/report.json.

The harness verifies the compiled function against the specifically inspected relocation-free body, including its local wrapper-address literal; checks reference identity, equal image length, exact branch/payload, zero reference cave bytes, no other changed bytes, and unchanged preceding and following functions. The mapping is synthetic in Unicorn: the entire reference image is mapped executable for the test. Original zero bytes do not prove the provisional interval is free in a composed final image or that it is executable in runtime.

Two seeds passed 128 original-versus-patched cases with a synthetic ARM BL caller and controlled wrapper. Checks cover six argument words, ARM state and stack alignment at the wrapper, returned values including 0, 1, 0x7fffffff, 0x80000000 and 0xffffffff, preserved registers, restored stack, return PC and caller-visible memory. The oversized overlay control specifically triggers protection of the next function; six further controls reject wrong BL branch, changed wrapper state, interval overlap, reference input drift, unauthorized mutation and misaligned branch. Two owned unit tests passed.

This is not a real caller-composition suite: the caller is synthetic and all wrapper effects are stubbed. Thumb/interworking, actual call sites, original 0x002C0EE0 fallthrough, service behavior, placement coexistence, execute permission, patched emulator runtime and production integration remain untested. No ledger status changed. The first checks output was superseded by the final output after strengthening the oversized-overlay control; both are retained.
