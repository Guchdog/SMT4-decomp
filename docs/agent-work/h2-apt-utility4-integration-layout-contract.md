# H2 APT utility entry: offline integration layout contract

Status: design and static inspection only. No candidate image, caller-composition, Thumb/interworking test, build or runtime was run for this task. The original reference is SHA-256 1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558 and its mapping starts at 0x00100000.

## Bounds and branch

Disassembly and ledger agree on adjacent half-open regions: 0x002C0EE0..0x002C0EFC (28 bytes), 0x002C0EFC..0x002C0F28 (44 bytes), and 0x002C0F28 onward (1016 bytes). At 0x002C0EF4 the preceding entry restores LR; its NOP at 0x002C0EF8 falls through directly to 0x002C0EFC. The next function begins with a register-saving push at 0x002C0F28. An in-place copy of the present 56-byte candidate at 0x002C0EFC changes the first 12 bytes of that function; reject it. The existing isolated experiment writes that many bytes at the entry, so its passing result proves only the isolated controlled-wrapper behavior, not safe layout or neighboring callers.

A candidate scheme for an offline test image is a single unconditional ARM B at 0x002C0EFC to a separately allocated ARM code region, leaving the rest of this entry and all neighboring bytes untouched. B, not BL, preserves the original caller's LR and therefore also supports the 0x002C0EE0 fallthrough. ARM B displacement is target - (0x002C0EFC + 8), divisible by four and in [-33554432, 33554428]. An illustrative branch to 0x003FEE54 has displacement 0x0013DF50 and little-endian bytes d4 f7 04 ea; it is in range. This address is a proposal for investigation, not an approved or demonstrated free cave.

The current 56-byte compiled body has no ELF relocations; at its new aligned location it uses a PC-relative in-body literal at offset 52 containing 0x002B5A1C, loads it into ip and BLXes it. Its code, local literal and boundary must be preserved together. The target's low bit is zero for ARM. Re-extract and validate the actual frozen object and each instruction, literal address and target at the final placement; do not assume any future compiled object is position-independent from this one. Test the actual branch, body and wrapper transition at final addresses and ensure callers using either instruction set are handled according to their real original ABI, rather than force-setting Thumb bits.

## Cave and composition constraints

Configured text ends at 0x003FE624, aligned text ends at 0x003FF000. Original bytes in [0x003FE624, 0x003FF000) are all zero, but original zeros alone do not establish availability, executable mapping, lack of references, or absence of other patches. Existing H2 function record 0x001EA928 describes a 2096-byte Calc body at [0x003FE624, 0x003FEE54); the final-image runner also uses 0x003FEED4 as a Secondary placement. Hence illustrative [0x003FEE54, 0x003FEE8C) appears between those two locations, but other callback or image placements, alignment and executable permission still need exact-image audit before use. Do not overwrite either region or presume that those descriptions enumerate every occupied byte.

tools/h2_final_image_compose.py starts from a hash-pinned callback image, overlays mapper and FillPair records, checks changes against their authorized ranges, preserves CopyPair, and verifies an IPS round trip. It does not add or authorize this APT entry or its cave. tools/h2_mapper_production_patch.py handles fixed-size in-place mapper bodies and separately audits interior references; its policies are not automatically suitable for this non-leaf entry and fallthrough. A new isolated composer should validate the exact base image and manifests, enumerate all existing records and placements, reject all overlapping intervals even when bytes happen to match, verify original and base entry/neighbor/cave bytes and hashes, preserve original image length, and record the entry branch plus cave payload separately. Explicitly assert that [0x002C0EE0,0x002C0EFC) and [0x002C0F28,0x002C1320) retain their exact base bytes, and that every change outside authorized branch/cave intervals is rejected. Audit branch targets and literal/data references into any replaced region in both original and selected final base; scanning cannot prove absence of all computed references. Inspect runtime segment permission only after the required offline gates.

## Offline caller and interworking plan

1. On frozen input hashes, decode the final entry B and relocated body; ensure target, exact blob size, in-body literal, literal value, branch range, alignment, wrapper state and return flow are checked. Make an isolated final image, IPS and reproducible manifest, and verify round trip and byte-exact protected ranges.
2. Differentially execute the exact original and patched images, not a truncated function blob. Controlled wrapper observes all six arguments, SP alignment, ARM state, return and call count. Cover random incoming registers/NZCV and stack sentinels, callee-saves, live memory and several return words including high-bit failures. Keep wrapper stub evidence separate from real wrapper/service behavior.
3. Exercise entry 0x002C0EE0 through its 0x002BB7A0/0x002BB774 dependencies then fallthrough, direct BL sites 0x002C0F6C/0x002C1260/0x002C1304 and B tail sites 0x00106F00/0x0010700C/0x002A8164/0x002C5638, including 0x00103E80 -> 0x002C5624. Use caller windows with correctly modeled registers, stack and necessary dependency hooks, compare LR/continuation, ordered calls and caller-visible effects; label every unmodeled earlier/later instruction and hook. Validate preservation of actual 0x002C0F28 prologue and exercise its relevant continuation to catch the 12-byte overwrite.
4. Audit real ARM/Thumb and indirect incoming paths. Construct ARM and Thumb interworking only where original caller ABI and LR state establish a meaningful scenario, and test return to each state through the actual final branch/candidate/wrapper sequence. Do not label synthetic Thumb tests proof of a real Thumb caller or universal interworking.
5. Require negative controls: oversized in-place body must trip protected neighbor assertion; corrupted branch target, BL instead of B, swapped state bit or literal, cave overlap, altered entry/cave hashes and unlisted changed byte must be rejected or generate a verified behavioral mismatch. Existing command, argument and discarded-return mutants must remain detected at the final placement.
6. Only after caller composition, instruction-state and differential gates pass should an integrator design any separately authorized bounded runtime comparison. Independent review is required before promotion.

Unknowns include live use of the proposed padding interval, transitive/computed references, real APT service effects, the full caller context and the exact currently selected final image. None is resolved by the candidate's prior passing isolated tests.
