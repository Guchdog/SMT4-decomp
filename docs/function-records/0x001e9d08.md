## Recovered live continuation contract

The pinned callback's inline state-5 body begins at `0x001E9D08`. Either
readiness-gate failure branches to `0x001EA62C`; success performs the navigation
reducer and continues at `0x001E9DE0`. The successful inline body sets `r8` to
the title-work singleton slot `0x0044E300`, sets `s17` to `1.0f`, and captures
the current work pointer in `r4` after both readiness gates. The continuation
uses `r4` for timer/blend work, uses live `s17` in the blend clamp at
`0x001E9E30`, and reloads the singleton through `[r8]` at `0x001E9E4C`.

## Isolated adapter

The private C++ reducer publishes its exact post-gate work pointer through an
explicit output slot. A naked ARM shim calls it from the inline-window entry.
Status zero tail-branches to `0x001EA62C`; status one restores `r4` from the
published pointer, sets `r8=0x0044E300` and `s17=1.0f`, then tail-branches to
`0x001E9DE0`. Neither path returns to the callback caller. The shim leaves the
existing callback frame and stack pointer intact, and the candidate's ordinary
ABI prologue/epilogue preserves callee-saved state while it runs.

The private differential compares original inline execution with shim plus
candidate through `0x001E9E50`, after the original touch-pointer reload. It
covers script-not-ready, preview-not-ready, unchanged selection, changed
selection/event with blend clamp, and an adversarial global-slot mutation at
the first input hook after pointer capture. Under mutation, both paths retain
`r4=0x02000100` for the captured work object while the later touch reload puts
`r6=0x02000300`; the adapter's explicit mailbox still contains `0x02000100`.
At success stops, `r8=0x0044E300` and `s17=0x3F800000`. The gate-failure cases
stop at `0x001EA62C` without timer, cursor/cache or trigger work.

The changed-selection case observes event `0x0100016C` with selection 2 and
cached selection 0 before the cache store; timer and blend memory changes,
helper order, all compared work bytes, `r4-r8`, `d8-d15`, `r6`, SP and FPSCR
agree with original execution; every case asserts 8-byte SP alignment. Three controls are rejected: routing failed
status to success reaches the wrong tail; omitting the `s17` restore changes
`s17` and blend memory; reloading the global slot instead of the captured
pointer changes `r4` and work effects after the adversarial mutation.

## Evidence and limits

The isolated ARMv6K candidate and shims are built by
[`h1_navigation_adapter_experiment.py`](../../tools/h1_navigation_adapter_experiment.py)
into a private output directory. The focused unittest is
[`test_h1_navigation_adapter_experiment.py`](../../tests/test_h1_navigation_adapter_experiment.py).
The reference image must hash to
`1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558`.

The frame is represented by initialized inline-entry state; the enclosing
callback prologue and epilogue are not executed. Readiness, input and event
entry hooks supply configured results; input hardware and event-queue internals
are not executed. The original ARM continuation runs only through the first
touch-pointer reload at `0x001E9E4C`; physical touch dispatch and later callback
behavior are outside the test. No emulator game session, production code
placement/link, runtime-normal object graph, or whole-H1 equivalence is claimed.
Keep the reducer dependent on the pinned original helpers and continuation until
those contracts and integration are separately validated.
