# Function Record: camp_func_00298bdc (0x00298bdc)

## Summary
- **Address:** `0x00298bdc` (original span `[0x00298bdc, 0x00298d74)`, 408 bytes;
  the last word of the span is the `0x0043da90` pool literal at `0x00298d70`).
- **File:** `src/engine/leaf_batch33_c.cpp`
- **Role:** Per-category quest-list animation step. It walks the visible rows of
  the camp quest list, maps every distinct row category to a mask-derived word,
  advances a 24-frame counter per category (wrapping a rolling index through the
  unsigned remainder of a division), then forwards the word selected by the
  list cursor's scroll offset plus selected row to `0x0026DD68`.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  1200 bytes versus 408 original bytes: clang unrolls the ten-bit mask scan,
  splits 32-bit work-field loads/stores into byte accesses (the addresses are
  derived from a `u8*`), and stores the pool literal inline. Register, memory
  and call behavior match the original on the tested domain. The ledger row is
  classified `non_matching`; this record carries the semantic evidence. The
  body does not fit the original 408-byte slot, so no in-place/staged
  integration was attempted.

## Contract and Behavior

- No incoming register or stack argument is read. The work block comes from the

### Control flow
1. `work = *(u32*)0x0043DA90`.
2. `count = 0x0029F0F4(work+0x1DC)`; `second = 0x0029F0F4(work+0x1DC)`; if
   `second < count` (signed) then `count = 0x0029F0F4(work+0x1DC)` again. The
   third call therefore happens only when the second read is smaller; equality
   and greater values keep the first read.
3. `0x002C4B30(sp, 0x64)` zeroes the marker array.
4. For `row = 0 .. count-1` (signed; a non-positive count skips the pass):
   `category = s32[work+0xE40+row*8]`. If the marker word at
   `sp+4+category*4` is non-zero, skip the row; otherwise store 1 and:
   - `mask = u16[record+0x44]`, where `record = 0x002B66EC()` and the offset is
     `+0x72` when `category < 0`, else `record = 0x002A89E4(category)`.
   - `ordinal = 0`. If `mask == 0`, store `0xFFFFFFFF` at
     `work+0x255C+category*4`. Otherwise scan `bit = 1 .. 10`; for each set bit
     compare the word at `work+0x24F8+category*4` with `ordinal`, incrementing
     `ordinal` on a mismatch. The first match calls
     `0x002B0788((s16)bit)` and stores its result; no match leaves the word
     untouched.
   - `[work+0x2494+category*4] += 1`. If the new value is `>= 0x18` under the
     signed comparison, store the high word (remainder) of
     `0x002C615C([work+0x24F8+category*4] + 1, ordinal)` into
     `work+0x24F8+category*4` and clear the frame counter. Wrap values with the
     sign bit set (`0x80000000`, `0xFFFFFFFF`) do not trigger the division.
5. `index = (u32)(0x0029F260(work+0x1DC) + 0x0029F248(work+0x1DC))` with 32-bit
   wrap; the calls are made scroll-first, selected-second.
6. `category = s32[work+0xE40 + index*8]` (32-bit modular offset), then
   `value = u32[work+0x255C + category*4]`.
7. `0x0026DD68(value)`; the wrapper's `r0` after the call is returned.

## Domain Limits
- All nine direct callees are stubbed. The real cursor, record, mask-word,
  divide and manager-store bodies are not executed; only the argument and
  return values this function consumes are modeled. In particular the
  `0x002B0788` fixed words, the `0x002C615C` quotient/remainder convention and
  the `0x0026DD68` manager-store effects are taken from the pinned bodies, not
  from an integrated call.
- The work, fallback and category pages are synthetic RAM. Field names beyond
  the ARM offsets are not established; the names describe observed roles only.
- The marker array is an internal buffer. Categories `-1..23` stay inside the
  25-word array and are exercised. Categories outside that range make the
  original write below `sp` or into its saved-register area; that stack-corruption
  behavior is not reproduced by the C++ frame layout and is out of domain.
- 32-bit work-field accesses are emitted as four byte accesses by clang. The
  byte order and final memory value are identical for aligned or unaligned RAM;
  volatile/MMIO-style width semantics are not preserved.
- The compiled body is 1200 bytes and cannot be placed in the original 408-byte
  slot. No staged image, caller composition, runtime or whole-game equivalence
  is claimed.
