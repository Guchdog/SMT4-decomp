# camp_func_00195044 (0x00195044)

## Summary
- **Address:** 0x00195044
- **Original size:** 868 bytes
- **Domain:** Camp / PlayLog per-frame update state machine
- **Status:** Semantically verified against the pinned original (ledger
  `non_matching`; the compiled C++ body is 876 bytes and is not byte-identical)
- **Source file:** `src/engine/leaf_batch45_b.cpp`
- **Differential suite:** `tools/test_leaf_00195044.py`

## Role and entry contract
The only direct caller in the pinned image is `0x0032F448`, which neither sets
up arguments nor reads the return value. The function ignores the incoming
general-purpose registers and loads the shared workspace pointer from
`*(Work**)0x0043DD08` (`g_PlayLogWork`, the object allocated by
`PlayLog_func_00194dbc`). It dereferences that pointer without a null check,
exactly like the original. Every exit path runs the common tail at
`0x0019534C..0x00195358`, increments the 32-bit frame counter at `work+0x340`
and returns the **post-increment** counter value.

All evidence below is from `extracted/exefs/code.bin` with
`build/disasm_range.py`; the literal pool at `0x00195398..0x001953A4` holds
`0x0043DD08`, `0x00000424`, `0x0100016C` and `0x0100016E`.

## Recovered state machine (`work+0x344`)
### State 0 (`0x0019507C..0x00195108`)
- For `i = 0..4`: if the signed `frame_counter >= i`, call
  `camp_func_002b9220(&work->sprites[i], 0)` (sprite stride `0x8C`).
- If the signed byte at `sprite[4]+0x8A` (`work+0x2DA`) is non-zero, call
  `camp_func_002b88c4(0x30, 0x1A)`, `(0x30, 0x1B)`, `(0x30, 0x1C)` in that
  order and store the low 16 bits of each result at `work+0x348`, `+0x34A`,
  `+0x34C`. Then add `3` to the u16 counter at `work+0x358` (16-bit wrap) and
  set `state = 1`.
- Otherwise the state stays 0.

### State 1 (`0x0019510C..0x001952F4`)
1. If the signed cursor row count `camp_func_0029f0f4(work+0x2DC) > 0`, walk
   `i = 0..` while the row count is still `> i` after each increment:
   - read `s16 visible = work->visible_indices[i]` (`+0x424 + 2*i`);
   - fetch `table = Tbb_GetGlobalSubTable(0x37, 0)`, then
     `payload = Tbb_GetPayloadData(table)`, then
     `rows = Tbb_GetRowCount(table)`;
   - if `(u32)visible < rows` and `payload + ((u32)visible << 6) != 0`, read the
     signed 16-bit key at that address; only when `key < 0` store
     `u32(camp_func_00290a4c())` at `work->entry_values[i]` (`+0x35C + 4*i`).
2. Zero a local `s8 out_flag`, resolve `node = camp_func_002bf6d0(0x30, 0x1C)`
   and save `position_a = camp_func_0029f260(work+0x2DC)`.
3. Call `camp_func_0029f878(work+0x2DC, node, nullptr, work+0x34C, work+0x348,
   work+0x34A, &out_flag, 0, 0)` — the exact argument order, including the
   three stack words and the two trailing zeros. If it returns non-zero, queue
   `0x0100016C` through `camp_func_002bc200` only when
   `camp_func_0029f260() != position_a`.
4. Otherwise, if `camp_func_0029f278(work+0x2DC, 0) != 0`: when
   `camp_func_0029f0f4(...) > 5` and `camp_func_0029f260(...) == position_a`,
   poll repeatedly: exit when `(posA, posB) == (0, 0)`, when
   `posA == row_count - 5 && posB == 4`, or when a `camp_func_0029f278(...,0)`
   call moves `posA` away from `position_a`. Afterwards queue `0x0100016C`
   when `posA != position_a`.
5. Otherwise (`0x0029f278` returned 0): if `camp_func_002c1830(1, 1) != 0`,
   queue `0x0100016E`, call `camp_func_002bdac0(&sprites[i], 1, 0)` for
   `i = 0..4`, and set `state = 2`.

### State 2 (`0x00195360..0x00195394`)

- If the signed byte at `sprite[4]+0x8A` is non-zero, set `state = 3`.

## Differential evidence
`tools/test_leaf_00195044.py` compiles `leaf_batch45_b.cpp` with the ARMv6K
freestanding profile, extracts `camp_func_00195044`, resolves its 41
`R_ARM_CALL` relocations to deterministic stubs at the pinned addresses, and
runs the pinned original against the candidate in separate Unicorn machines
with identical fixtures.

Compared per case: return `r0`, continuation PC, final SP, callee-saved
`r4-r11`, the ordered call log (including all five architected stack words and
the pre-call out-flag byte of `0x0029F878`), the `(address, width, value)`
multiset of non-stack writes, the whole workspace plus a sentinel guard, the
TBB payload, the layout node buffer and the global pointer word.

39/39 cases pass, covering:
- states 0, 1, 2 and several unrelated state words (3, 4, 0xFFFFFFFF);
- signed frame-counter bounds 0/1/3/4/5, 0x7FFFFFFF, 0x80000000, 0xFFFFFFFF
  and the increment wrap to 0;
- the sprite enable byte zero, 1 and 0xFF;
- the three registrations with high garbage in the recovered handles and the
  u16 touch counter wrapping from 0xFFFE and 0xFFFF;
- row-loop bounds: three rows, negative index 0xFFFF, index above the row
  count, row count 0, null payload with index 0, positive keys, `0x8000` and
  `0xFFFF` keys, and a row count that changes between iterations;
- `0x0029F878` hit with moved and unchanged cursor, and miss;
- `0x0029F278` non-zero with row count <= 5 and > 5, the `(0,0)` exit, a
  repeated poll iteration via `(0,1)`, the `(count-5, 4)` bottom-right exit with
  counts 6 and 7, a `(count-5, 3)` fall-through, and poll-driven movement;
- the select gate returning 0 and non-zero.

Negative controls (each detected): changing the changed-dispatch id, changing
the sprite enable offset from `0x8A` to `0x89`, and swapping the
`touch_handle_1c`/`touch_handle_1a` argument positions of `0x0029F878`.

Reproduce with:

```powershell
python tools/test_leaf_00195044.py
```

## Limits
- Every helper is a deterministic Unicorn stub; their real bodies, TBB payload
  contents, touch-manager state, cursor internals and dispatch consumers were
  not executed. Call arguments and order are observed, but semantic effects of
  the real helpers are not part of this evidence.
- The fixture uses synthetic ordinary RAM. Malformed/null workspace pointers,
  aliasing, concurrency, MMIO, fault ordering and the real scheduler cadence
  are unproven.
- The compiled body is 876 bytes versus the 868-byte original span, so it is
  not an in-place byte replacement and the ledger row is `non_matching`.
- No emulator or runtime execution was performed.
