# Function Record: camp_func_0029cee4 (0x0029cee4)

## Summary
- **Address:** `0x0029cee4` (original span `[0x0029cee4, 0x0029d080)`, 412 bytes,
  including the two-word literal pool at `0x0029d078`/`0x0029d07c`)
- **File:** `src/engine/leaf_batch33_c.cpp`
- **Role:** Campaign-panel animation and dismissal step. It advances the
  pending value animation of the object registered in slot `+8` of the
  `0x0043E188` table, then either requests the widget mode again or, when the
  caller asks to close row index `11`, requests the mode and releases both the
  default and the presented row through `0x002B8D24`.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  652 bytes versus 412 original bytes. Clang expands every `u32` access into
  four byte accesses (the base is `u8*`, so no alignment is assumed), keeps both
  constants in a literal pool, and drops the intermediate unclamped store to
  `+0x6C` that the original performs before clamping. The ledger row is
  classified `non_matching`; this record carries the semantic evidence. The body
  does not fit the original 412-byte slot, so no in-place integration was
  attempted.

## Contract and Behavior

### Signature and ABI
```c
extern "C" s32 camp_func_0029cee4(u32 close_request);
```
- `r0` is the only incoming register argument. It is tested once at
  `0x29cf94` (`cmp r0,#0`); incoming `r1-r3` are never read.
- The original saves `r4-r8, lr` (the `r8` push is unused frame padding),
  touches no VFP register, and restores `sp` and `r4-r8` before returning.
- Returns `1` on the "not a dismissal" path and `0` on the dismissal path
  (`mov r0,#1` at `0x29d070`, `mov r0,#0` at `0x29d03c`).

### Control flow
1. `object = *(0x0043E188 + 8)` (entry fetch).
2. **Animation**, only when `u8[object+0x7C] == 3`:
   - if `u8[object+0x7D] != 0`, run one wide step (limit `0x3B9AC9FF`);
   - then, if `u8[object+0x7E] != 0`, run one narrow step (limit `0x63`).
   The narrow step reads the accumulated value **written by the wide step**, so
   with both flags set the two steps compose. Each step:
   ```
   sum = u32[+0x78] + u32[+0x70]           // 32-bit modular add
   u32[+0x6C] = sum                        // pre-clamp store (dead in the C++)
   u32[+0x64] = 10; u32[+0x74] = 0
   u32[+0x78] = sum                        // unclamped sum is retained
   value = (s32)sum; if (value <= 0) value = 0;      // signed lower clamp
   u32[+0x6C] = value
   if (value > limit) value = limit;       // signed upper clamp
   u32[+0x6C] = value
   u8[+0x7C] = 0
   ```
   The upper-bound comparison is signed in both blocks (`movgt` in the
   original); the compiled candidate emits `movlt` / `movge` forms, which agree
   because the value is non-negative after the lower clamp. Signed wrap is
   observable: `0x7FFFFFFF + 1` stores `0x80000000` in `+0x78` and publishes `0`
   in `+0x6C`.
3. `widget = object + 0x754`, computed from the re-fetched `+8` slot at
   `0x29cf9c`.
4. **Dismissal test** (short-circuits in this order): `r0 != 0`,
   `u8[object+9] == 0xB`, `u8[object+8] != 0`.
   - If any fails: read `u8[object+0x7C]`; when it is `0`, `2`, or `1`, store
     `4` to `+0x7C` and call `0x002BF030(widget, mode)` with
     `mode = (u8[+0x7F] != 0) ? 2 : 7`. Return `1`.
   - Otherwise: read `u8[object+0x7C]`; only when it is `0` or `2`, store `4`,
     call `0x002BF030(widget, mode)`, then
     - re-read slot `+4` and, if the pointer is non-null **and** its `+8` byte
       is non-zero, call `0x002B8D24(default, u8[default+9])` and store state
       `3` / flag `0`;
     - if the entry `object` pointer is non-null **and** its `+8` byte is
       non-zero, do the same for it.
   Return `0` in every case of this branch, including phase `1`, `3`, and `4`,
   which produce no call.
5. Phases `3` is reached with the animation already cleared to `0`, so an
   animation step and a dismissal happen in the same invocation.

## Domain Limits
- Both direct callees are stubbed. The widget service behind `0x002BF030` and
  the release switch behind `0x002B8D24` (including its selector-11
  `0x002BF030`/`0x001384F0` path) are not executed; only the arguments and the
  ignored return values this routine observes are modeled.
- The panel and table pages are synthetic RAM. Field names beyond the ARM offsets
  are descriptive only; `+8`, `+9`, `+0x35`, `+0x64`, `+0x6C..+0x7F`, and `+0x754`
  are named by observed role.
- A null presented pointer would fault at the first `ldrb` and is not modeled;
  the default slot is allowed to be null or to change during the call because the
  original tests it after the call.
- The caller audit is a static scan of ARM `bl` sites; indirect calls, Thumb
  callers, and runtime dispatch are not covered, and only `0x0038214C` was
  identified as consuming the return value.
- The compiled body is 652 bytes and therefore cannot be placed in the original
  412-byte slot without overlapping the following function. No staged image,
  caller composition, runtime or whole-game equivalence is claimed.
