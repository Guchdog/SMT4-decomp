# Function Record: ui_func_00256ffc (0x00256ffc)

## Summary
- **Address:** `0x00256ffc`
- **Size:** 460 bytes (original span `[0x00256FFC, 0x002571C8)`; the last four
  bytes at `0x002571C4` are the literal pool word `0x3F000000` = `0.5f`)
- **File:** `src/engine/leaf_batch41_c.cpp`
- **Role:** Expands one 24-byte record of a frame list into a 0x38-byte output
  block. It advances or repeats the frame, resolves a texture object through a
  pointer table, converts the texture's two integer scales to float, and emits
  a corner, half extents, four scaled texture-space coordinates, a style tag
  and a table value. It is a leaf helper: no calls at all.
- **Status:** semantically equivalent C++ (`non_matching`). The compiled body is
  444 B versus the 460 B original (440 B of text plus the 4 B `0.5f` pool
  versus 456 B plus pool); register allocation and store order differ.

## Contract and Behavior

### Signature and ABI
```c
extern "C" void ui_func_00256ffc(void* self, void* output);
```
- `self = r0`, `output = r1`. Only `r4/r5/r6` are saved (push at `0x00256FFC`,
  `pop {r4,r5,r6}` at `0x002571BC`); SP is otherwise untouched. VFP registers
  `s0-s8` are scratch and caller-saved.
- `void` result. The original leaves the last sign-extended record halfword
  (`ldrsh r0,[r0,#0x0E]` at `0x0025718C`) in `r0`; that residue is not a return
  value and is deliberately not reproduced.
- Every 32-bit index/offset arithmetic step is performed through `u32` so the
  original's wraparound is not undefined behaviour.

### Computation (ARM addresses)
1. `0x00257000..0x0025700C`: `state = *(u8**)self+0x10`, then
   `root = *(u8**)self`, then `control = *(u8**)state+0x0C`.
2. `0x00257010`: `control+0x10 & 0x10000000` returns immediately.
3. `0x00257018`: `hold = *(s32*)state+0x08`; when `hold > 0` (signed) it is stored
   back as `hold - 1` and the index update below is skipped.
4. `0x00257028`: otherwise `next = (u32)(*(s32*)state+0x04) + 1` is stored; when
   `count = *(u32*)control+0x0C` is not greater than `next` (unsigned `bhi`),
   bit 4 of `control+0x10` selects: clear the u16 at `self+0x14` and set the
   index to `count - 1`, or simply set the index to 0. Then `state+0x08` =
   `*(s16*)(*(u8**)state+0x10 + 24*index + 0x12)`.
5. `0x00257080..0x00257098`: read the index again, the flags, and the record
   base; `record = records + 24*index`.
6. `0x00257090..0x002570B0`: when flag bit 0 is set,
   `value = *(s32*)(*(u8**)root + *(u32*)control+0x04 + 4*index)`; otherwise
   `value = -1`. Store at `output+0x2C`.
7. `0x002570B4..0x002570C0`: `textures = *(u8**)root+0x14`;
   `texture = textures[(s16)*(s16*)record+0x10]` (sign-extended, scaled by 4).
8. `0x002570C4..0x002570F0`: style halfword from a fresh load of
   `control+0x10`; bit 1 wins over bit 2.
9. `0x002570D0..0x002570F4`: u/v scales via integer loads plus
   `vcvt.f32.s32`; `output+0x10 = *(u32*)record+0x14`; `output+0x14 = texture`.
10. `0x00257100..0x002571B8`: the eight record halfwords; `+0x08..+0x0E` are
    shifted arithmetically right by 4 and divided by the appropriate scale
    (`vdiv.f32`), `+0x00/+0x02` are multiplied by `0.5f` (`vmul.f32`), the
    corner subtracts `+0x04/+0x06`, and the two scales are stored at
    `+0x30/+0x34`.

## Limits
- Fixtures are synthetic: the state/control/root objects, records, value table
  and textures are not captured game data.
- Callers of `ui_func_00256ffc` are not exercised; only the leaf contract above
  is tested. No runtime, caller-composition or whole-game equivalence is
  claimed.
- The reconstruction assumes `self`, `state`, `control`, `root`, the record
  array, the texture table, the textures and `output` do not overlap.
- Only the final contents of `output` and `self+0x14` are contractual; transient
  register and VFP state is not reproduced.
- Null pointers fault in both versions, but the exact faulting instruction can
  differ because the C++ may schedule the independent loads differently; that
  ordering is not part of the comparison.
