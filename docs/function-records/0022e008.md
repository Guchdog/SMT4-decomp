## Limits
- Fixtures are synthetic: the camp work area, the `0x2A8A08` list, and the
  `0x2B9364` info record use deterministic byte patterns, not captured game
  data.
- Every helper is stubbed. The stubs model only the effects the dispatcher
  observes (`0x2BCF58` copy, `0x2C4B30` clear, `0x24BE90` bit set) and log the
  rest; no real helper body, global manager state, script VM, or rendering is
  exercised.
- `0x29C950` is an 8-byte ARM `cmp r0,#0; bxeq lr` dispatch stub in the
  original; the harness treats it as a no-op, which matches the observed
  `r0 != 0` call but does not model the fall-through body at `0x29C958`.
- No runtime or whole-game equivalence is claimed. Static caller/caller-of
  behavior and actual UI state transitions still require integrated runtime
  validation.
