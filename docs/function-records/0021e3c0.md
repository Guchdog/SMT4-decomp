# Function Record: engine_func_0021e3c0 (0x0021e3c0)

## Summary
- **Address:** `0x0021e3c0`
- **Size:** 680 bytes (original span `[0x0021e3c0, 0x0021e668)`, including the
  literal word at `0x21e64c` and the `"map/obj/obj_%02d.bam"` string at
  `0x21e650`)
- **File:** `src/engine/leaf_batch45_a.cpp`
- **Role:** Scripted loader step for the placed-object table behind the
  singleton stored at `0x00447E70`. It walks placement records, matches the
  pending map filter, reserves one of 24 slots, starts the
  `"map/obj/obj_%02d.bam"` model load and publishes the record's placement
  values into the slot once the model is ready.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  1096 B versus the 680 B original (clang unrolls the 24-slot free-slot scan into
  a compare chain and hoists the result register); the ledger row is classified
  `non_matching` with this semantic record.

## Limits
- Every helper is stubbed with scripted results; no real record table, path
  formatter, model loader or model state is exercised.
- `0x0025C07C` may return null and the original dereferences it without a check.
  The harness maps a zeroed page at address 0 so the null-record cases can run;
  in the real game the table lookup is expected not to return null for an index
  below the count.
- `0x002A06C8`'s memory effect (clearing bit `0x200000` in
  `model->flags` and forwarding to `0x001DB890`) is not emulated; both sides
  share the same stub, so the comparison cannot see that effect.
- `0x002BE7FC` is Thumb in the original; the BLX interworking flag is
  normalised away and is not part of the compared domain.
- The 0x80-byte frame-local path buffer is not byte-compared (the frames differ);
  its contents are compared through the path string logged at the
  `0x0029A2D0` call.
- Fixtures are synthetic (records, model handles, slot contents, filters); no
  captured game data, caller-composition or runtime scenario is included.
- The slot may legitimately be `-1` (the original permits it and writes
  `ctx - 0x34`); the reconstruction preserves that raw addressing rather than
  relying on out-of-range array indexing.
- No rendering, map-loading, whole-game or emulator runtime equivalence is
  claimed.
