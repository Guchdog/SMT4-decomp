# Function Record: engine_func_00126480 (0x00126480)

## Summary
- **Address:** `0x00126480`
- **Size:** 424 bytes (100 ARM instructions through the unconditional
  `pop {r4-r8, sb, sl, pc}` at `0x0012660c`, plus the six literal words at
  `0x00126610..0x00126627`)
- **File:** `src/engine/leaf_batch41_c.cpp`
- **Role:** Claims the first free voice pointer of the active stream slot,
  gates the request on three sound-system predicates, asks the manager virtual
  at `AsdSoundSystem + 0x184` to allocate a voice into that slot, then seeds
  and retargets the voice envelope. Both float inputs are the final fade
  endpoints; the integer level selects the intermediate envelope scale.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  500 bytes versus the 424-byte original (different register allocation,
  pre-header slot scan, store order, and literal-pool placement). No
  byte-identity claim is made.

## Contract and Behavior

### Signature and ABI
```c
extern "C" s32 engine_func_00126480(void* object, u32 level, u32 target,
                                    f32 fade_a, f32 fade_b);
```
- `object = r0`, `level = r1`, `target = r2`; `fade_a = s0` and
  `fade_b = s1` under hard-float AAPCS.
- Return: `s32` in `r0`.
- Prologue saves `r4-r8, sb, sl, lr` and `d8-d10` (`s16-s23`); every exit
  restores them (`0x00126480..0x00126498`, `0x00126604..0x0012660c`).
- `level` is converted as **unsigned** (`vcvt.f32.u32` at `0x00126574`).
  `target` is forwarded verbatim as the second argument of `0x002BCD94`.

### Global and object layout (offsets only, as evidenced by the ARM)
- `0x004E1F68`: global `AsdSoundSystem` base (literal at `0x00126610`).
- `AsdSoundSystem + 0x1204` (`0x004E316C`): pointer to the active stream slot
  (`ldr r0, [r7, #0x1204]` at `0x001264A8` via `add r0, r7, #0x1000` /
  `ldr [r0, #0x204]`). The same field is written by `0x002C1ED0`.
- Active stream slot `+0x20..+0x3C`: eight `void*` voice slots
  (`ldr r1, [entries + index*4 + 0x20]` at `0x001264BC..0x001264C0`).
- `AsdSoundSystem + 0x184` (`0x004E20EC`): manager sub-object passed as the
  first argument of `0x002BCDF8` (`add r0, r7, #0x184` at `0x0012653C`).
- Voice object fields written here: `+0xB8` and `+0xB4` (32-bit floats).
  `0x002BCD94` separately rewrites `+0xA0..+0xAC`; `0x0014BEF8` sets the
  enable byte at `+0x85`.
- Literal pool values: `0x3F800000` (1.0f, `0x00126614`), `0x00000000`
  (0.0f, `0x00126618`), `0x42800000` (64.0f, `0x0012661C`), `0x3C810204`
  (0x1.020408p-6, `0x00126620`), `0x40000000` (2.0f, `0x00126624`).

### Control flow and calls
1. `0x001264A8..0x001264B8`: load `active_stream`. If null, return `-1`.
2. `0x001264BC..0x001264DC`: scan slots `0..7` for the first null pointer.
   The loop increments the index and compares `index < 8`; a full table
   returns the `-1` sentinel. `0x001264E0` re-checks `index == -1` (the
   compiler's sentinel path).
3. `0x001264E8..0x001264FC`: `engine_func_002bf85c(AsdSoundSystem)` — reads
   `AsdSoundSystem + 0x04` and returns `1` when non-zero, else `0`. On `0`
   the routine returns the claimed **slot index**.
4. `0x00126500..0x00126514`: `engine_func_00141940(AsdSoundSystem, object)` —
   nested system/object state test. On `0` it returns the **slot index**.
5. `0x00126518..0x00126528`: `func_002c1f44(object)` — registers `object`
   with the manager list at `AsdSoundSystem + 0x250`. On `0` it returns `-1`.
6. `0x0012652C..0x00126540`: form `&active_stream->voices[slot]` (r1) and
   call `func_002bcdf8(AsdSoundSystem + 0x184, &slot, object, 0)`. That helper
   invokes the virtual at `[[manager+0x184] + 8]` with the slot address and
   is expected to publish the allocated voice through it; when the low byte of
   its result is zero and the slot is now non-null it also calls `0x0014BEF8`
   (sets `voice+0x85 = 1`).
7. `0x00126544..0x00126550`: remember `(result & 0xFF) == 0`.
8. `0x00126554..0x00126588`: compute the envelope scale:
   ```text
   level == 0        -> 0.0f
   otherwise         -> 1.0f + ((f32)(u32)level - 64.0f) * 0x1.020408p-6
   clamp             -> 2.0f when the signed bit pattern of the result is
                        greater than 0x40000000
   ```
   The clamp is a signed integer comparison of the raw float word
   (`vmov r0, s18; cmp r0, #0x40000000; vldrgt`), not a floating compare.
9. `0x0012658C..0x001265BC`: if the slot is non-null,
   `func_002bcd94(voice, 0, 0.0f)`, then store `voice+0xB8 = 1.0f` and
   `voice+0xB4 = 0.0f`.
10. `0x001265C0..0x001265D0`: re-read the slot; if non-null call
    `func_002bcd94(voice, target, scale)`.
11. `0x001265D4..0x001265F0`: re-read the slot for each store; if non-null
    write `voice+0xB8 = fade_a` then `voice+0xB4 = fade_b`.
12. `0x001265F4..0x0012660C`: return the slot index when step 7 succeeded,
    otherwise `-1`.

The pointer at `active_stream + 0x20 + slot*4` is re-read before each use, so a
helper that changes the slot is observed exactly like the original.

## Limits

  virtual table, the manager list at `+0x250`, and the voice internals beyond
  the listed offsets are not exercised.
- The indirect target read from `[[manager+0x184]+8]` is logged and varied in
  the fixture but is not executed as ARM code; only its slot-publication
  contract is modelled.
- Caller composition (`0x00105FDC`, `0x0012421C`) is documented but not
  executed against a patched image.
- No whole-game runtime equivalence is claimed.
