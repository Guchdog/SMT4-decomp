## Role and Behavior
- **Role:** Walks 8 dialog audio channel slots and stops active voices.
- **Details:**
  - Loads context pointer from global address `0x004E2F68 + 0x204`.
  - If null, exits immediately.
  - Iterates 8 slots (`i = 0..7`):
    - Examines pointer at `context + (i << 2) + 0x20`.
    - If non-null, calls `engine_func_002bdc08(entry, 0)` to release voice.
    - Calls `engine_func_002bdbcc(slot + 0x20)` to reset slot state.
- **Differential Coverage:** Verified in Unicorn emulator with null context (0 calls) and active populated context (exact sequence of 4 calls with matched arguments) against original ARM binary.
