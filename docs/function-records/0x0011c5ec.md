# `func_0011C5EC` — H2 input-state reader

## Reconstructed behavior

The typed production implementation in `src/engine/leaf_batch30_a.cpp`
preserves the original mode-byte early return, signed calibration clamps,
six-argument ring read, signed-positive count gate, selector-based sample
normalization, ordered context and state-bit updates, signed global short-circuit
and output clearing, state save, and optional postprocess call. It returns the
original raw `0` or `1` result. The seven direct callees remain original ARM
functions.

## Evidence

`tools/h2_11c5ec_experiment.py` compiles the production translation unit,
relocates its seven `R_ARM_CALL` sites to even ARM entries, and stages its
304-byte body into the pinned original's 304-byte span. The final-VMA differential
passed 288 direct cases and 32 compositions through original caller
`0x001078D8`, with no observed differences. The controlled
`0x0012A758` ring seam records register and stack arguments, local output
pointers, stack alignment, and ordered memory effects; the other direct callees
execute the pinned original code. All three mutation controls were detected.
The slot-only IPS replay passed, and the affected translation unit compiled.

Reports and the staged image are under
`build/agent-work/H2-semantic/h2-input-state-reader-cpp-0011c5ec/run001/checks/`.
The reader was subsequently composed with production `0x001078D8` in a
two-slot staged image; 144 full-chain cases passed and received independent
review. See the [composition report](../agent-work/h2-001078d8-0011c5ec-composition.md)
and its [review](../agent-work/h2-001078d8-0011c5ec-composition-review.md).

## Limits

Fixtures use valid, disjoint synthetic ordinary memory. The ring-reader seam
provides controlled count and sample data, so physical input provenance,
buffer freshness, cadence, scheduling, concurrency, aliasing, malformed ring
states, and device/MMIO behavior are not established. Caller compositions run
the original `0x001078D8` wrapper and compare observable memory; they do not
establish natural runtime reachability or whole-title behavior. The compiled
body differs from the pinned original, so its ledger classification is
`non_matching`; semantic evidence is recorded separately.
