# Function record: enclosing state handler `0x00207FFC`

## Boundary and entry

`0x00207FFC` is the actual prologue for the handler whose state-0 block begins
at the catalogued address `0x002080E0`. The recorded 704-byte span is compound:
it includes this handler's internal blocks, literal/string data, and a separate
small routine at `0x0020835C`.

Entry saves `r4-r6,lr`, loads `r4` with address `0x004474D8`, initializes `r6`
to `0x63`, saves `d8`, allocates `0x98` stack bytes, and loads
`self=*(u32*)0x004474D8`. The visible function reads no incoming argument
register. Common exit returns zero and restores the frame; the state-99 arm
returns one. A real caller/dispatcher has not been identified.

## State contract observed in original

The handler dispatches on the signed halfword `self+8`:

| State | Observed behavior |
|---|---|
| `0` | Clear path when word `0x0049FC7C == 1`; otherwise create/setup embedded resource at `+0x28`, or resolve/load/poll sky resource at `+0x10`. Completion sets state 10; a pending load increments 0 to 1. |
| `1` | Poll `+0x10`; configure when ready, optionally pass `(0,-20000,0)` when global halfword `+4 == 0x13`, then set state 10. |
| `10` | Create/setup resource from `+0x20/+0x24` and set 99, or normalize map ID and load resource at `+0x0C`, incrementing state to 11. IDs `0x29..0x2B` normalize to `(0x24,1)`. |
| `11` | Poll `+0x0C`; configure when ready and set 99. |
| `99` | Return 1. |
| Other signed values | Return 0 without state change. |

## Evidence and limits

The initial synthetic ARM differential had a review counterexample: if the setup
helper changed `context+0x10` from the originally polled resource to another
resource, the original reloaded that field before each float setter. The candidate
was corrected to reload the global context pointer, resource slot, and resource
target before `set_a` and again before `set_b`.

The revised runner passed 44 cases with seed 7 and another 44 with seed 20261024,
including post-helper mutations to context fields, the global context pointer, and
resource `+8` fields; all three negative controls were detected in both runs. A
focused regression asserts that the reviewed state-1 case sends target address
`33574912` to both setters in original and candidate. These mutations are explicit
synthetic stimuli and do not claim actual helper behavior. The tests model
helpers rather than execute their real implementations. No caller composition,
production integration, emulator, or runtime game comparison is claimed. The
function caller and real resource/helper semantics remain unresolved.

Machine-readable runner reports distinguish the default helper model (no
context/resource object writes, except the formatter output buffer) from
post-call fixture mutation stimuli, explicitly marked as not attributed to
helpers. A focused assertion checks the descriptor and the reviewed setup event.
