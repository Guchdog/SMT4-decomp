## Contract

The ARM leaf takes `r0=object`, `r1=index`, and returns `1`. It reads the word at `object+0x1C` as the count. For count zero, it writes zero to `+0x24` and then `+0x20`. Otherwise it clamps the index using signed ARM comparisons: signed nonpositive becomes zero; signed `count < index` becomes `count-1`; equality with count is retained. It computes `delta = index - object[+0x20]` modulo 2^32. A signed-negative delta writes the selected index to `+0x20`, then zero to `+0x24`. Otherwise it writes delta to `+0x24`, clamps visible `+0x10` to count using a signed comparison, computes `limit = count-visible` modulo 2^32, and when signed `delta > limit` writes limit to `+0x24` then `index-limit` to `+0x20`.

The implementation preserves the source ARM leaf's `r4-r11` and `sp` behavior through the C++ ABI, makes ordered object stores explicit, uses unsigned arithmetic for wraparound, and retains signed comparisons. There are no calls, global accesses, or relocations. Conversion from `u32` values with the high bit set to `s32` follows the pinned ARMv6K Clang behavior; portability to a C++ implementation with different conversion behavior is not established. Invalid or misaligned objects, MMIO, concurrent observation, CPSR/scratch-register identity, and VFP state are outside the tested contract.
