## Recovered contract

The helper expects the touch manager to have been initialized. It loads the
manager pointer from `g_IfTouchGlobal+4` (`0x0043DCB4`), reads the signed
halfword at manager `+0x64E`, and compares its low 16-bit handle with the
canonical signed `s16` argument. If the IDs differ, it returns zero; if they
match, it returns the raw unsigned byte at manager `+0x08`, zero-extended to
`s32`. It does not write guest memory. The null/uninitialized-manager case is
outside the recovered contract; the original accesses through the manager
pointer without a guard.

H2 caller disassembly uses `LDRSH` for the queried `TitleConfigWork` halfwords
at `+0x1C`, `+0x1E`, `+0x20`, and `+0x22`, so negative sentinel values arrive
sign-extended. The helper's return is compared to raw values such as 1, 2, and
6 by `TitleConfig_Calc`. This does not establish what those raw values mean as
user actions. The callback producer, event meaning, cadence, and relation to
H2 registered regions remain unresolved; see the
[manager producer audit](../agent-work/h2-input-manager-touch-state-producer-audit.md).
