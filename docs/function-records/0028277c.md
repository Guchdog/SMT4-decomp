## Contract and Behaviour

### Signature and ABI
```c
extern "C" f32 script_vm_func_0028277c(f32 x);
```
- Hard-float AAPCS: the argument arrives in `s0` and the result is returned in
  `s0`.  The prologue is `str lr, [sp, #-4]!` + `vpush {d8}` + `sub sp, #4`;
  every exit restores the frame.  `x` is held in callee-saved `s16` (half of
  `d8`) across the reduction calls, and the quadrant is the 4-byte stack slot
  created by `sub sp, #4`.
- `r0`/`r1` carry bit patterns: at entry `r1 = bits(s0)`; the fast path uses
  `r0` as the quadrant word and the generic reduction path passes `sp` in
  `r0`.
- The routine reads and writes no global state.  The only side effect is the
  errno store performed by the unresolved Thumb `0x002A464E` helper on the
  infinity path.

### Control flow
1. **Magnitude windows.**  With `s = bits(x) << 1` (sign dropped), there are
   three paths:
   - `s < 0x73000000` (`|x| < 2^-12`): quadrant `-1`, reduced value `x`.
   - `s < 0x7E921FB6` (`2^-12 <= |x| < pi/4`): quadrant `0`, reduced value `x`.
   - `s >= 0x7E921FB6` (`|x| >= pi/4`): reduce.  If
     `|bits(x)| >= 0x46490E49` (`|x| >= 12867.5712890625`) the generic helper
     `0x003EB4F4` performs the reduction; otherwise the inline reduction runs.
2. **Inline reduction.**  `q = round(x * 2/pi)` uses the 2^23 add/subtract
   trick, with the subtraction direction selected by the sign of `x`; the
   quadrant is `q & 3`.  The reduced angle is
   `r = x - q*(p0 + p1 + p2 + p3)` with each `p` subtracted separately (the
   pinned code uses `VMLS`, one rounding per part).  The 2^23 trick is only used
   below `12867.5712890625`; above it the generic helper is required because the
   rounding constant would lose the quadrant.
3. **Generic reduction helper** `0x003EB4F4(u32* out, u32 value_bits)` writes
   the quadrant through the pointer (0..3, or an equivalent encoded value such
   as `0x10000000 - n` for negative arguments, whose low two bits are `-n & 3`;
   `0xFFFFFFFF` for non-finite input) and returns the reduced angle in `s0`.
   For non-finite input it leaves `s0` equal to the incoming value.
4. **Quadrant `-1` tail.**  `m = bits(r) << 1`:
   - `m > 0xFF000000` (NaN): return `r + r` (VFP NaN propagation).
   - `m == 0xFF000000` (infinity): call `0x002A464E(1)` (sets errno through
     `*__errno_location()`), then return `0.0f / 0.0f` (VFP default NaN).
   - otherwise: call `0x002A4600(bits(r))`; only class `4` (subnormal) calls the
     16-byte probe `0x002A462C(r)` and discards its result; then return `r`.
     Zero classifies as `0` and therefore does *not* run the probe.
5. **Quadrant `0..3` tail.**  `r2 = r*r`; sin is
   `r + r*r2*(C2 + r2*(C0 - r2*C1))`, cos is
   `1 + r2*(C2 + r2*(C1 + r2*C0))`.  The low quadrant bit selects cos (`1`) or
   sin (`0`); the second bit negates the result.  Hence quadrant
   `0/1/2/3 -> sin(r)/cos(r)/-sin(r)/-cos(r)`.

## Differential validation
`python tools/test_leaf_0028277c.py` compiles
`src/engine/leaf_batch45_b.cpp`, extracts `script_vm_func_0028277c`, repairs its
four call relocations (the `0x002A464E` call is emitted as an ARM `BLX`
immediate because the target is Thumb) and runs the pinned original and the
candidate in Unicorn ARM.

Per case the test compares: returned `s0` bits (including NaN payloads), PC, SP,
callee-saved `r4-r11` and the callee-saved `d8`, the ordered helper call log
(classifier bits, probe `s0`, errno value, reduction out-pointer normalised to
`"<stack>"` and input bits), and every emulated write outside the private stack
(none expected, and equal).  The helpers are deterministic stubs placed at the
pinned addresses: the classifier reproduces the `0x002A4600` bit algorithm, the
probe and errno setters only log, and the reduction helper returns a case-chosen
quadrant encoding and reduced value (and the true non-finite contract, `-1`
with `s0` unchanged).

Coverage (70 cases): the `2^-12` and `pi/4` window boundaries from both sides,
all four inline quadrants for positive and negative `x`, exact quarter-turn
ties, the `12867.5712890625` generic-reduction boundary from both sides,
`+/-0`, subnormals, min normal, tiny normals, every helper quadrant encoding
(including the `0x10000000 - n` and `0x0FFFFFFD` forms) with positive and
negative reduced values, `+/-infinity`, quiet/signalling NaNs and maximal NaN
payloads.  Four compiled mutants are detected: the subnormal-probe comparison,
the sine accumulation sign, the cosine negation, and the generic-reduction
threshold.

## Limits
- The reduction helper's finite reduction is treated as an opaque dependency;
  the test stubs it with a case-chosen quadrant/reduced pair, so its internal
  Payne-Hanek arithmetic is not differentially verified here.
- `0x002A464E` is an unresolved Thumb libm/linker helper.  The test does not
  execute its `__errno_location` store; the stub logs the stored value and
  returns.  Its surrounding runtime context is not recovered.
- No emulator run, caller-composition test, or whole-game scenario was
  performed; caller relationships are static evidence only.
