# AsdProcess_func_00118488 (0x00118488)

## Summary
- **Address:** 0x00118488
- **Size:** 556 bytes
- **Domain:** Engine / Process Manager Node Creation, Unique ID Allocation, and Bucket Linking
- **Status:** Semantically verified (non_matching in ledger)
- **Source File:** src/engine/asd_scene.cpp
- **Differential Suite:** tools/asd_scene_experiment.py

## Role and Behavior
- **Role:** Allocates and links a process execution node (`AsdProcessNode`), selects an available 20-bit process ID without collisions across all active bucket chains, initializes its command list and flags, enqueues it onto the requested process bucket, and optionally attaches it to a parent process.
- **Details:**
  - Uses `__attribute__((pcs("aapcs")))` to comply with the engine's AAPCS softfp stack argument layout:
    - Register arguments: `r0 = name`, `r1 = bucket`, `r2 = field_34`, `r3 = field_36`.
    - Stack arguments: `sp[0..3] = floats (field_38, field_3c, field_40, field_48)`, `sp[4] = parent handle`.
  - Allocates 0xA4 bytes from kernel pool via `AsdMem_Alloc(0x100, 0x100, 0, 0xA4, 1)`.
  - Copies up to 24 characters of process name while computing name checksum `name_hash`.
  - Scans buckets to select the next unused `id` (wrapping at `0x000FFFFF` to 1). Packs `handle = (id & 0xFFFFF) | (bucket << 20)`.
  - Instantiates graphics command list via `AsdGxCommandList_Create()`.
  - Sets default active flags (`0x00190000`).
  - Enqueues node into the linked list for the target bucket slot and increments `g_AsdProcessPool.process_count`.
  - If `parent != 0`, attaches node to parent via `AsdProc_Attach(parent, node->handle)`.
- **Differential Coverage:** Verified in Unicorn emulator across multiple process names, bucket slots, floating-point parameters, and parent attachment states against original ARM binary.
