# `0x00159A44` - bounded draw-packet builder

## Contract

The pinned US ARM image `code.bin` (SHA-256
`1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558`) contains
the 896-byte ledger span `0x00159A44..0x00159DC3`. The executable body ends with
the final `b 0x00159C68` at `0x00159DC0`; the literal pool `0x00159D84..0x00159DB0`
sits in the middle of the span and the four-instruction selector-only branch is
at `0x00159DB4..0x00159DC0`. The entry is `extern "C" u32
engine_func_00159A44(void* self, void* params)`.

`self` layout used by this body:

* `+0x0D` sign-extended `u8` mode. Only `0` and `1` proceed; any other value
  returns `0`.
* `+0x00` `u32` destination buffer base. A null value returns `0`.
* `+0x08` `u32` destination buffer capacity in bytes. A zero value returns `0`.

`params` layout used by this body:

* `+0x00` `u32`, `+0x04` `u32` milliseconds, `+0x08` `u32`.
* `+0x0C`, `+0x10`, `+0x18`, `+0x1C` `f32`.
* `+0x14` `u32` table pointer; `0` selects the global table at `0x00473278`.
* `+0x20` `u8` selector.

1. **0x00159A58..0x00159AEC - gates.** Return `0` when the mode byte is not
   `0`/`1`, when the base or capacity is zero, or when any of the four `f32`
   fields fails the original test. Each field is loaded once, compared with
   `VCMP.F32 s, 0.0` and `BLO` (a strict less-than, so a NaN continues), then
   its raw bits are compared with `0x3F800000` using a signed `BGT`. This is a
   bit-pattern gate, not a numeric range check: `-0.0` and negative NaN pass,
   while positive NaN and every positive bit pattern above `1.0f` fail.
2. **0x00159B00..0x00159B60 - slot quantisers.** `slot_a` is
   `((u64)0xD6853CC1 * (params[0x00] * 1000)) >> 44`, clamped with a signed
   `cmp #1` so zero and any 32-bit value whose top bit is set become `1`.
   `slot_b` repeats this with `params[0x08]`. Both are stored as `u16`.
3. **0x00159B64..0x00159BA8 - table row.** The row pointer is `params[0x14]`
   or `0x00473278`. `params[0x04]` is converted unsigned to `f32`, multiplied by
   `0.0010000000474974513f` (0x3A83126F) and then by `32728.0f` (0x46FFB000);
   this divisor feeds both loop iterations. Three table words are divided by
   160 with `(u64)0xCCCCCCCD * value >> 39` and stored as halfwords at `+0x20`,
   `+0x22`, `+0x24`.
4. **0x00159BAC..0x00159BEC - loop.** Twice, `sample = (s16)` of the `+0x20`/
   `+0x22` halfword, `steps = sample * 5 * 32`, exponent
   `((f32)steps * -3.0f) / divisor`, `powf(10.0f, exponent) * 128.0f` truncated to
   `s32` and stored as a halfword at `+0x2C`/`+0x2E`. `powf` is
   `0x002B9CF8`.
5. **0x00159BF0..0x00159C44 - scaled fields.** `+0x18`, `+0x1C` and `+0x0C` are
   multiplied by `128.0f` and converted unsigned to halfwords at `+0x26`,
   `+0x28`, `+0x2A`.
6. **0x00159C48..0x00159DB4 - ratio mirror.** If the signed bit pattern of
   `params[0x10]` exceeds `0x3F733333` the value becomes `0.9499999880790710f`.
   With selector `== 1` the pair is `(value - 1.0, -value)`, otherwise
   `(1.0 - value, value)`; both are multiplied by `128.0f`, truncated signed and
   stored at `+0x30` (first) and `+0x32` (second).
7. **0x00159C68..0x00159D3C - encoded offsets.** Five words are encoded as
   `((address + 0x0C000000) >> 16) | (address << 16)` and stored at
   `+0x08..+0x18`. The cumulative offsets are `slot_a*0x500`, `+slot_b*0x500`,
   `+((s16)divide0)*5 << 8`, `+((s16)divide1)*5 << 8`. `+0x08` is always stored;
   the capacity is compared unsigned (`BLO`) before `+0x0C`, before `+0x10`,
   and before `+0x18`. `+0x14` is stored unguarded once the `+0x10` check
   passes. Every failure shares the same exit path.
8. **0x00159D40..0x00159D80 - submission.** The packet halfword at `+0x00` is
   `6` and `+0x06` is `2`. Call `0x002C3B48(base, capacity)` (zero-fill),
   `0x002A4DB4(base, capacity)`, then `0x002BB7B0()` (returns
   `*(u32*)0x004E6F08`), and finally
   `0x00156208(context, (s32)self[0x0D], &packet)`. The last call's `r0` is the
   routine's return value; the shared early paths return `0`.

## Caller evidence

The pinned caller `func_00157710` (`0x00157710`) calls this routine with
`r0 = r7` (its context object) and `r1 = r8`, then tests `r0` for zero before
marking its per-slot record. `0x00156208` itself reads `rh[2]`, `rh[0]`,
`rh[6]` and later `rh[0x2A]`, so the two never-written halfwords are
stack-dependent in the original as well. `0x002A4DB4` tail-jumps into
`0x00155CE4` when its global slot is non-null.

## Reconstruction / evidence

Readable C++ is in `src/engine/leaf_batch45_b.cpp`
(`engine_func_00159a44`, 1200 compiled bytes) and compiles with the project
ARMv6K clang pipeline (`-O2`, `-std=c++20`, hard VFP). The integer magic
multiplies are reproduced with 64-bit products; the float steps keep the
original single-precision operation order and the NaN/overflow results of the
VFP conversions; the packet's two untouched halfwords are deliberately left
uninitialised to mirror the listing.

Differential test: `python tools/test_leaf_00159a44.py` (Unicorn ARM, 99 cases
plus six compiled negative controls). It compares return `r0`, PC, SP,
`r4..r11`, the ordered call log with every register argument and the raw
`s0`/`s1` bits forwarded to `powf`, the 0x34-byte packet captured at the
`0x00156208` call, the self/params/table/global/context/buffer fixtures, and any
write outside the private stack. Result: 99/99 cases pass; all six mutants
(`pow_exponent_factor`, `ratio_clamp`, `packet_count`, `default_table`,
`address_encoding`, `slot_stride`) are detected. The ledger classification is
`non_matching`; no byte identity or whole-game equivalence is claimed.

## Limits

All five direct callees are deterministic stubs at their original addresses, so
the test establishes the caller contract only. `powf` is stubbed to a constant
return and its argument bits are compared instead. Indirect targets, FPSCR
exception state and the bodies of `0x002C3B48`, `0x002A4DB4`, `0x002BB7B0` and
`0x00156208` are not exercised. Negative-NaN inputs are covered only as far as
the deterministic stubs allow. No runtime-boot, alignment, invalid-pointer,
concurrency or whole-game behaviour is established.
