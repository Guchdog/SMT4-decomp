## Contract

- Signature: `extern "C" void* func_00167dcc(void* config)`; returns the config
  pointer unchanged (`push {r0, lr}` / `add sp, sp, #0x14` / `pop {r0, pc}`).
- There are no direct calls, tail calls, indirect branches or relocations. The
  only external reads are the two PC-relative literal-pool words at
  `0x0016768C`/`0x00167690`: `0x01010101` and `0x20202020`.
- Input object (the same six-word layout as `0x001602dc` / `0x00164054`):
  - `+0x04` `u32 base` — absolute address of the filtered buffer
  - `+0x08` `u32 width_bytes` — used as `width_bytes - 0x10`
  - `+0x0C` `u32 height_bytes` — used as `height_bytes - 8`, stepped by 8
  - `+0x10` `u32 threshold_a` — prefix-OR expanded (`v |= v<<8; v |= v<<16`);
    used only by the final `|C-D| >= threshold_a` comparison
  - `+0x14` `u32 threshold_b` — prefix-OR expanded; used by the first four
    `|A-C|`, `|F-D|`, `|B-C|` and `|D-E|` comparisons
  - `+0x00` is never read.
- This is the same kernel as `0x001602dc`, reorganised for a **0x200-byte row
  pitch and a 0x1000-byte band pitch** (instead of 0x400/0x2000).

## Behaviour

- Starts at `base + 0x1000`. Each chunk filters 0x20 bytes; each 4-byte lane
  reads six rows at `centre{-0x600,-0x400,-0x200,0,+0x200,+0x400}` and rewrites
  only the four middle rows (`-0x400, -0x200, 0, +0x200`), in that store order.
- Per lane (`A/B/C/D/E/F` = outer-above, inner-above, centre-low, centre-high,
  inner-below, outer-below): `pair = uhadd8(C, D)`; `B_out` starts as
  `uhadd8(pair, A)` and `E_out` as `uhadd8(pair, F)`; each is replaced by the
  original `B`/`E` when `|A-C|` / `|F-D|` reaches `threshold_b` per byte. The two
  centre outputs start from `pair` sharpened by
  `m = uhadd8(uhadd8(uhadd8(~E, B), 1), 1)`:
  `C_out = uqadd8(pair, uqsub8(m, 0x20))` then
  `uqsub8(..., uqsub8(0x20, m))`, `D_out = uqsub8(pair, uqsub8(m, 0x20))` then
  `uqadd8(..., uqsub8(0x20, m))`. Finally, for each byte where
  `|B-C| >= threshold_b`, `|D-E| >= threshold_b` or `|C-D| >= threshold_a`,
  all four outputs are replaced by their original row values (`B`, `C`, `D`,
  `E` respectively) — the four selects are per-byte and compose to an OR of the
  masks. `B_out` also uses the `|A-C|` mask and `E_out` the `|F-D|` mask.
- Packed arithmetic: `uhadd8`, `uqsub8`, `uqadd8`, `uadd8`, unsigned `usub8`
  (GE = unsigned `a >= b`, **not** the signed `ssub8` used by the neighbouring
  0x0015f7bc/0x0015fba4 kernels), `mvn` and `sel`. `uadd8` sets GE but every
  `sel` in the kernel consumes the flags of the immediately preceding `usub8`,
  so only unsigned byte comparisons reach a select.
- Loop control: horizontal counter = `width_bytes - 0x10`, decremented by 0x20
  per chunk with a signed `> 0` branch (`bgt`). Exactly zero filters four
  trailing lanes (0x10 bytes) and advances another 0x10; negative skips them
  after the unconditional first chunk. The vertical counter (`height_bytes - 8`)
  is decremented by 8 per band and loops while non-zero (`subs`/`bne`), so
  values where `height_bytes < 8` wrap for ~2^29 bands and are treated as out of
  domain.
- ABI: the original pushes only `{r0, lr}` and therefore clobbers callee-saved
  `r4-r11` (the same ABI violation as `0x001602dc`). The C++ candidate is a
  normal AAPCS function and preserves them.

## Limits

- Byte identity is intentionally not preserved (`non_matching`).
- No helper or indirect target exists to stub; the literal-pool words are
  supplied by the fixture at their pinned addresses.
- No real caller or whole-game runtime scenario was exercised; the caller set
  and the semantic meaning of the two thresholds remain inferred from the kernel
  only.
- The `height_bytes < 8` wrap path is documented but not executed.
- The original's `pld` hints are omitted (non-semantic).
