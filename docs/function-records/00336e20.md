# Function Record: battle_func_00336e20 (0x00336E20)

## Summary

- **Size:** 444 bytes (`[0x00336E20, 0x00336FCC)`): 107 ARM instructions through

  Thumb call target, and every memory effect are preserved. Behavioural

## Contract and Behavior

```text
context->flags_634 |= 0x4000;

        queue[queued++] = entry;               // stored at [fp + queued*4]
    }

row = 0;                                       // s16, dead `sl` flag also cleared
for (index = 0; index < queued; ++index) {     // 0x00336EB4..B0
    entry = queue[index];
    if ((entry->flags_50 & 0x3) != 0x3) continue;   // re-test after the sort
    state = entry->state_58;
    if (state & 0x0800) continue;

    entry->state_58 = state | 0x0800;          // 16-bit store

    if (flags & 0x10) { t0=table[0x0C]; t2=table[0x10]; t4=table[0x14]; }
    else              { t0=table[0x00]; t2=table[0x04]; t4=table[0x08]; }

                (entry->flags_50 & 0x10) ? 7 : 6, 0x0D);  // fresh flag load
    row = (s16)(row + 1);

finish:
0x0024095C(*(Context**)0x004342C8, 0x78);      // 0x00336FB4..C0
```

Key notes:
- `smlabb r0, r7, sb, r8` and `smlabb r0, r7, sb, r0` define the row scaling as
  signed 16x16 products added to a 32-bit accumulator. `row` is sign-extended
  on every increment (`sxth`); in-domain it spans `0..49`, so no 16-bit wrap is
  reachable.
- The layout (`0x10`) selection is latched before the first helper call, but
  the third helper's `6`/`7` kind is read from a **fresh** 32-bit load of
  `flags_50` after the first two calls. The differential test mutates the bit
  from inside both stubs to prove both behaviours.
- `sl` is used only as a dead "processed anything" flag in the original
  (`mov sl,#0; cmp sl,#0; moveq sl,#1`); it is pushed and popped but never
  read, so it is not part of the observable contract.
- The queue re-check after sorting matters when a sort callback or an
  interrupt-side writer changes flags/state between the scan and dispatch.

## Differential Test
`tools/test_leaf_00336e20.py` compiles the TU, extracts the candidate body,
patches the five ARM `R_ARM_CALL` relocations to deterministic stubs at the
original addresses, rewrites the sort call as a Thumb `blx` to `0x002B7F0A`,
and runs the pinned original and the candidate in separate Unicorn machines
with identical fixtures.

Compared:
- final `r0`, continuation PC, final SP, and callee-saved `r4-r11`;
- the ordered call log with every register argument, the exact number of
  architected stack words per helper, and the `0x0019D76C` comparator pointer;
- every non-stack emulated write including width and value (32-bit context
  flag, 16-bit entry-state updates);
- the full context, owner, entry-array, global-slot/table and record pages.

The sort stub reverses the queue deterministically, so the second pass must
consume the sorted array and the original's pointer order is exercised. The
comparator body and the five helper bodies are stubs, not reconstructions.

Coverage: 30 cases span zero/one/many queued entries, the index 3/0x36 decoys,
both queue-flag bits, already-done entries, the full 50-entry window, both
layout selections, four s16 table boundary sets (`0`, `-1`, `INT16_MIN`,
`INT16_MAX`), row scaling over all 50 rows, a nonzero context flag word, a
context-pointer swap observed by the reloaded final call, and helper-time flag
mutations proving the latched layout versus the fresh 6/7 kind load. Seven
negative controls (first index, entry stride, done bit, selected table offset,
comparator address, helper kind, stack value) are each detected.

## Unresolved / domain limits
- The internals of `0x00240744`, `0x002406AC`, `0x00245330`, `0x00240660`,
  `0x0024095C`, the sort routine `0x002B7F08/0x002B7F0A`, and the comparator
  entry `0x0019D76C` were not re-decompiled; only their caller-visible ABI and
  memory effects were recovered.
- `0x0019D76C` is one of three comparator entries inside the 508-byte
  `0x0019D650` block and is passed as an absolute code address. The differential
  stub never executes it, so the real ordering is not exercised against the
  candidate; equivalence is conditional on the sort helper's contract
  `(base, count, element_size, compare)` and on the comparator address being
  preserved exactly.
- `0x0024095C` may clear the context start bit depending on a distance test;
  that branch is inside the helper and was not reconstructed. The caller only
  relies on the final `r0` being whatever that helper leaves.
- Runtime/thread interleavings that rewrite an entry's flags or state between
  the scan and the dispatch pass are represented only through the re-check and
  the stub-driven mutation cases; real hardware or interrupt concurrency was not
  emulated.
- The original's dead `sl` "processed anything" flag suggests a removed debug or
  call-site decision; its original purpose is not recoverable from this caller,
  and it has no observable effect here.
