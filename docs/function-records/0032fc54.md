# Function Record: func_0032fc54 (0x0032fc54)

## Summary
- **Address:** `0x0032fc54`
- **Size:** 672 bytes (original span `[0x0032FC54, 0x0032FEF4)`)
- **File:** `src/engine/leaf_batch45_a.cpp`
- **Role:** Draw-scheduler for up to three glyph-run rectangles. Validates a
  0x38-byte request block, looks up a byte pair for each of two table indices,
  and dispatches zero to three draws through six global function-pointer slots
  selected by the request extent. The helper slots are read with the original
  `ldr/ldr/blx` indirection, so the indirect dispatch is preserved.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  656 B versus the 672 B original; Clang uses a different register allocation,
  converts the index-bound checks to `sub/cmn`, accumulates the result in `r1`,
  and reaches the `+4` slot of each pair with a single base literal plus a
  pre-indexed `ldr`. There are no relocations in the extracted candidate.
  The ledger row is classified `non_matching` with this semantic record.

## Contract and Behavior

### Signature and ABI
```c
extern "C" s32 func_0032fc54(leaf_fc54::Request* request);
```
- `request = r0`. Every access is a 32-bit load; the function writes nothing to
  the request block.
- Return value: `0`, `1`, `2` or `3` on success (bit 0 = primary draw issued
  path, bit 1 = secondary/third draw issued path); `-1`, `-3`, `-4` or `-5` on
  the error paths below. The original materializes the errors with
  `mvn r0,#0` (`-1`), `mvn r0,#2` (`-3`), `mvn r0,#3` (`-4`) and `mvn r0,#4`

  `r4-r11` are preserved and final SP equals the entry SP.
- The renderer slots are function pointers; each renderer is called with
  `r0 = &seven_word_descriptor` and no other architected argument. Every

  its next use).

### Control flow and calls
1. `if (request->word_34 == 0) return -1;`
2. `if (request->word_20 != request->word_24) return -3;`
3. `if ((u32)(word_28 - 0x0C) >= 0x25) return -4;`
4. `if (word_2C < 0x0C || word_2C > 0x30) return -4;`
5. Cache `flags = word_30`, then `a0 = table[word_28]`,
   `a1 = table[0x25 + word_28]`, `b0 = table[word_2C]`,
   `b1 = table[0x25 + word_2C]`, `extra = 0x0040B87E`.
6. If `(flags & 1) && a0 && a1`:
   descriptor `{word_00, word_0C, word_18, word_1C, a0, a1, extra}`,
   `result = 1`, then one draw through the class-selected primary slot
   (`word_20 <= 0x100 / <= 0x200 / <= 0x400`, else `return -5`). The call is
   skipped when `word_34 != 1` but `result` stays 1.
7. Reload `flags = word_30` (after step 6's renderer may have run). If
   `(flags & 2) && b0 && b1`:
   descriptor `{word_04, word_10, word_18 >> 1, word_1C >> 1, b0, b1, extra}`,
   `result |= 2`, then the class-selected secondary slot call (same extent
   buckets and `word_34 == 1` gate).
8. Rewrite descriptor words 0/1 to `{word_08, word_14}` (words 2..6 retained)
   and issue the same secondary slot again with a freshly loaded extent; a
   `word_20 > 0x400` here also returns `-5`.
9. `return result`.

The extent buckets are unsigned `<= 0x100`, `<= 0x200`, `<= 0x400`; anything
above `0x400` returns `-5`, but only when a draw is actually enabled and its
row pair is nonzero.

## Contract corrections found during implementation
- **All three early errors are checked before any table access.** The mode
  check precedes the extent check, which precedes both index checks. The test
  includes cases that would fail a different order.
- **The first index check is an unsigned wrap-safe range test**, not two
  comparisons: `u32(index - 0x0C) >= 0x25`. `0xFFFFFFFF` and `0x8000000B` are
  rejected; the candidate reproduces this exactly (`sub`/`cmn`).
- **Table indexing is raw, not rebased.** The row bytes are read at
  `base[index]` and `base[0x25 + index]` (the valid codes overlap the row's
  `0x0C`-based start), not at `base[index - 0x0C]`.
- **Flags are read twice.** The original reloads `word_30` at `0x32FD88`
  after the primary draw may have run; the candidate likewise re-reads the
  field after the primary dispatch.
- **`result` is set before the mode gate.** A skipped primary call still
  returns bit 0; a skipped secondary pair still returns bit 1 (`orr r5,#2` at
  `0x32FDA4`).
- **`-5` is conditional.** An extent above `0x400` returns `-5` only when a
  draw is enabled and its row pair is nonzero; `flags == 0` with an oversized
  extent returns `0`.
- **The two extent words must match but their value is unconstrained.**
  Extent `0` is accepted (small class); only `word_34` gating calls further.
- **Renderer return values are dead.** The original reloads `r0` before every
  subsequent use; the stubs return garbage to prove this.

## Limits
- Fixtures are synthetic. The request block, destination pointers and table
  page are not captured live game state; the table page is the pinned image
  bytes, but no renderer consumes the descriptor.
- All six renderers (`func_00167244`, `func_00167274`, `func_0016AFBC`,
  `func_0016AFEC`, `func_001634CC`, `func_001634FC`) are stubbed. Their own
  descriptor word 0/1 comparisons, sub-renderer dispatch and GPU work are not
  exercised or reconstructed here.
- The semantic meaning of the table bytes, the extent, the request words and
  the three row tables is not established. They are treated as opaque 32-bit
  values and indices; no float interpretation is claimed.
- The original speculatively loads the three secondary slot words before the
  size tests (`0x32FDD0..0x32FDE0`); the candidate loads only the selected
  slot. Because every slot is an ordinary read-only word in the pinned image,
  this read-order difference is unobservable.
- When the first secondary call is skipped at extent `<= 0x100`, the candidate
  jumps directly to the shared return instead of rewriting descriptor words
  0/1 and re-testing the extent. No call and no caller-visible memory effect is
  skipped, so the observable result is identical.
- The descriptor and register allocation inside the candidate differ from the
  original; only the documented ABI inputs, renderer arguments, saved
  registers and returned value are compared.
- No caller-composition (`func_003f5f98` is still a raw block), rendering or
  whole-game runtime equivalence is claimed.
