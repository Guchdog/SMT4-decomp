## Role and Behavior
- **Role:** Updates party slot IDs and marks which demon/party slots are newly added compared to the previous party state.
- **Details:**
  - Backs up previous 8 party IDs into a stack buffer.
  - Clears `new_party_flags` (8 bytes) and `party_ids` (16 bytes).
  - Copies incoming `ids` of count `count` into `work->party_ids` via `AsdMem_Copy`.
  - Scans `party_ids` to count consecutive non-zero IDs (`valid_count`).
  - Sets up main list cursor `UiListCursor_Setup(&work->list_cursor_main, valid_count, 8, 1, 0, 1)`.
  - Sets `work->needs_refresh = 1` and `work->flag_548 = 0`.
  - Compares each non-zero slot in `work->party_ids[0..count-1]` against `prev_ids[0..7]`.
  - If a demon ID was not present in `prev_ids`, sets `work->new_party_flags[i] = 1`.
