# `0x002B96F0` — `AsdResource_Resolve`

## Recovered behavior

The function takes two 32-bit indices. It loads the table pointer from `0x0044EA28`, reads the manager entry at `table + group * 24` using 32-bit ARM arithmetic, and tail-transfers to the existing four-instruction helper at `0x00145798`, preserving LR and the second argument. That helper returns zero for a null manager entry; otherwise it loads the manager's first word and returns `base + subindex * 32` with 32-bit wraparound. A non-null manager with a zero base still returns `subindex * 32`. There are no table bounds checks.

The H2 predicate at `0x002A63F8` calls this resolver. `TitleConfig_Calc` reaches that predicate with `(group, subindex) = (0x2F, 0)`.

## C++ reconstruction

`engine_func_002b96f0(u32 group, u32 subindex)` is implemented in [leaf_batch39_a.cpp](../../src/engine/leaf_batch39_a.cpp). It types the group-table lookup and tail-helper call. The helper name `AsdResource_ResolveSubindexTail` aliases the existing ARM code at `0x00145798`, which lies inside another mapped function's span and remains original machine code.

The body is 24 bytes. Its absolute ARM `JUMP24` relocation is explicitly rebased to `0x00145798` at the final VMA; the resulting bytes equal the original slot, so `config/functions.csv` remains `matching`. The generic `asm_diff.py` display does not resolve this empty-symbol absolute relocation as a final-VMA branch; `tools/h2_2b96f0_experiment.py` performs and verifies the rebase directly.

## Evidence

The offline differential compares original ARM, a temporary compiled body, and the re-based final-VMA body over 103 fixtures: seven directed boundary cases and 96 seeded cases. It compares the return, preserved `r1`, callee-saved registers, SP, ordered reads and absence of writes. A null manager entry is covered; non-null zero bases, wraparound-shaped values, the titleConfig `(0x2F, 0)` pair and large indices are included.

The group-stride mutation is detected by differential output. Replacing the forwarded second argument changes the compiled body to 28 bytes and is rejected because it no longer fits the 24-byte slot. The runner also composes the typed predicate `0x002A63F8` and this resolver at final VMAs through the actual `TitleConfig_Calc` call slice for flag words `0`, `4`, and `0xFFFFFFFF`; return value and caller zero flag match the original pair.

The full ARMv6K build completed 204/204 translation units. Final relocated bytes equal the original, so a separate image overlay was unnecessary. Runtime was not run; the internal tail-helper call and controlled memory fixtures remain the scope of this evidence.
