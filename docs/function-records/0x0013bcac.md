# `0x0013BCAC` — H2 input record postprocessor

## Reconstructed behavior

The ARM helper receives a pointer to three adjacent 32-bit record words at
`+0`, `+4`, and `+8`. It updates the transition bit `0x8` in `+4` and `+8`
sequentially using the current bits `0x4`/`0x8` in each word and the prior
word's corresponding bits. For either current word, bit `0x8` is set when both
current bits are set, when current bit `0x4` is set and prior bit `0x8` is
clear, or when current bit `0x8` is set and prior bit `0x4` is clear; otherwise
it is cleared. It then moves bit `0x4` to bit `0x8` in word `+0` when bit `0x4`
was set, clears bit `0x4` in `+4` and then `+8`, and returns the final raw word
at `+8` in `r0`. All other bits are preserved.

The typed implementation in [leaf_batch16_c.cpp](../../src/engine/leaf_batch16_c.cpp)
uses volatile word accesses to retain the observed store order for the mapped
record. The original's callee-save push/pop touches stack scratch below entry
SP; the differential checks restored SP and callee-saved registers, while the
scratch save/restore is excluded from the persistent-memory comparison.

## Evidence

The final-VMA runner passed 192 direct cases: all 64 combinations of the three
words' transition bits plus 128 seeded full-word cases. It compared return,
SP, callee-saved registers, all three words, and ordered non-stack writes. A
mutant that omits the `current bit 0x4 AND current bit 0x8` condition was
detected. The body is 148/212 bytes, has no relocations, targets the original
even ARM entry, and passes exact-slot IPS replay.

An additional 32-case composition passed through the pinned original reader
`0x0011C5EC`, with its ring read intercepted at the documented ABI seam. In 16
cases the reader called `0x0013BCAC`; the observed `context+8` snapshot matched
output word `+0` at postprocessor entry, confirming the reader's save-before-
postprocess ordering. The reader discards the helper's raw return.

The affected translation unit compiled and the full ARMv6K build passed all
204 translation units. Independent review passed a fresh seed: 192 direct cases,
32 original-reader compositions, and the mutation control, with no counterexample.
See the [conversion report](../agent-work/h2-0013bcac-conversion.md) and
[independent review](../agent-work/h2-0013bcac-independent-review.md).

## Limits

The supported domain is an aligned, fully mapped three-word record in ordinary
RAM. Invalid mappings/fault timing, concurrent observers, MMIO and physical
input provenance are not established. The parent composition uses a controlled
ring-read seam and does not establish live input production or H2 lifecycle
equivalence. The body differs from the pinned original, so the ledger is
truthfully `non_matching`.
