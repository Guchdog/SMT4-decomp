# `0x0027FBC8` — calibrated axis sample reader

## Production reconstruction

`script_vm_func_0027fbc8` is now typed C++ in `src/engine/leaf_batch41_a.cpp`. Its three-word ABI is `(float* out_x, float* out_y, u32 mode)`, returning a signed 32-bit status in `r0`. Both output pointers may be null. The function reads state pointer `*(u32*)0x004650A0`, then the calibration pointer from that state. Those globals and the calibration object must be valid and mapped before any mode rejection: the original loads the selector before checking the requested mode.

The selector byte at calibration `+0x18` chooses axis 0 for selector 0, axis 1 for selector 1, and axis 2 for every other value. Signed halfwords at `+0x0C + 2*axis` and `+0x12 + 2*axis` form the signed calibration span. The mode is rejected when unsigned `mode >= 2` or when the state's maximum-mode word at `+4` is less than `mode`. Otherwise, bit 0 of the state flags at `+8` selects either the alternate sample record at `0x004E3C48` or `0x004E3C28 + mode*16`. Signed samples at record offsets `+0x0C` and `+0x0E` are converted to `float` and divided by the span.

If the threshold float at state `+0x14` compares unequal to zero, the original ARM helper `0x0019FE4C` is called first for X and then for Y. If both post-helper values compare equal to zero, the function returns 0 without writing either output. A zero threshold skips that rejection, so a neutral sample returns 1 and writes zeroes. On the successful path it writes X before Y, skipping either store when that pointer is null, then returns 1. The two original helper calls remain as ARM relocations.

## Limits

These fixtures use synthetic ordinary RAM. They do not establish physical input mapping, concurrent mutation, MMIO behavior, every caller state, or game-level effects. The direct audit does not compare the full stack scratch area, SP, condition flags, or all caller-saved registers. Exceptional floating-point states and arbitrary aliasing with globals or device memory are not established beyond the listed fixtures. In particular, this conversion does not resolve the downstream `0x00254CA8` path that reads its local output floats when this reader returns without writing them. That consumer domain remains unresolved, and H2 remains open.

The compiled body differs from the pinned original, so `config/functions.csv` truthfully classifies the function as `non_matching`; the experimental differential and staged-image reports are the semantic evidence for the bounded behavior above.
