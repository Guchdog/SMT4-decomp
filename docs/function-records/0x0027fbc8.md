# 0x0027FBC8 — experimental axis reader

Candidate: `experiments/semantic_equivalence/h4_axis_reader_candidate.cpp`; direct runner: `tools/h4_axis_reader_experiment.py`; bounded caller runner: `tools/h4_axis_camera_composition.py`. The candidate remains experimental and is not integrated. Reference image SHA-256: `1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558`.

## Supported contract

ARM state, hard-float VFPv2. r0/r1 are nullable 32-bit output pointers, r2 is an unsigned mode, and r0 returns an integer status. The function reads calibration through `0x004650A0`, selects signed halfword endpoints by selector byte `+0x18`, and reads signed samples from either the indexed 16-byte source records at `0x004E3C28 + mode*16` or the alternate record at `0x004E3C48`. It converts each sample to a float ratio using the selected signed endpoint difference. For a nonzero threshold it calls original helper `0x0019FE4C` for each axis. Invalid mode or unavailable source returns 0 without output writes; when both deadzoned values compare equal to zero it also returns 0 without writes. Otherwise each non-null output is written and the function returns 1. A zero threshold bypasses the all-zero rejection, so neutral samples can return 1 and write zeroes.

The candidate preserves the two ARM `R_ARM_CALL` references to the original `0x0019FE4C`. The earlier direct differential suite covered 476 synthetic cases (four 119-case runs with seeds 7, 20261028, 42, and 73) with no reported differences. The expanded audit added a 146-case matrix at seed 42; 144 valid cases matched and two invalid-output-pointer probes recorded the same Unicorn unmapped-write class and ordered writes. An independent review reran that audit at seed 20261029 with the same result. Both expanded runs detect a same-input mode-2 mutation of the unsigned upper-mode bound. The observed camera caller at `0x001FA948` has six equal candidate/original bounded instruction-window cases through `0x001FAA84`; a secondary UI caller has eight. The field-camera retarget word, candidate mapping, and helper relocations are independently recorded and reviewed. See `h4-axis-reader-review.md`, `h4-camera-candidate-composition-review.md`, `h4-reproducible-camera-composition-review.md`, and `h4-axis-reader-contract-audit-review.md`.

## Limits and status

The caller checks execute a synthetic stack/view fixture, not the complete `0x001FA840` task or a captured live view fixture. The expanded direct audit compares selected memory snapshots, ordered non-stack writes, `r4-r11`, `d8-d15`, and FPSCR; it does not compare all memory, SP, condition flags, all scratch GPRs, or compiler-dependent stack layout. Its invalid-pointer probes record Unicorn fault class and ordered writes only; they do not establish supported invalid-pointer semantics. Alias, NaN/Inf, zero/reversed-span and deadzone boundary cases are included in the synthetic matrix, but hardware and live caller behavior remain untested. The live runtime intervention changed the original helper's validated stack outputs; it did not execute this candidate and did not establish physical controls, player movement, rendered-camera response, interaction, or transition. Keep the candidate experimental and unintegrated until caller contract and production integration requirements are validated or explicitly bounded.
