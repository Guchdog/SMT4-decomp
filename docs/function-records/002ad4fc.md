## Role and Behavior
- **Role:** Computes a standard 4x4 perspective projection matrix (`glFrustum` equivalent) into caller memory.
- **Details:**
  - Uses `__attribute__((pcs("aapcs-vfp")))` where scalar arguments `(left, right, top, bottom, near, far)` are passed in VFP registers `s0..s5`, and `out` pointer is passed in `r0`.
  - Calculates:
    - `width = right - left`
    - `height = bottom - top`
    - `depth = far - near`
  - Fills 4x4 row-major matrix:
    - `out[0x00] = 2.0f * near / width`
    - `out[0x08] = (right + left) / width`
    - `out[0x14] = 2.0f * near / height`
    - `out[0x18] = (bottom + top) / height`
    - `out[0x28] = far / depth`
    - `out[0x2C] = (near * far) / depth`
    - `out[0x38] = -1.0f`
    - All other entries are zeroed (`0.0f`).
