# InfoWin_Dismiss (0x0010b320)

## Summary
- **Address:** 0x0010b320
- **Size:** 32 bytes
- **Domain:** UI Window / Information Window Dismissal & Bound Checker
- **Status:** Semantically verified (non_matching in ledger)
- **Source File:** src/ui/window.cpp
- **Differential Suite:** tools/window_batch1_experiment.py

## Role and Behavior
- **Role:** Checks an incoming dismissal code against the context bound; if within range, stores the code and acknowledges dismissal.
- **Details:**
  - Takes `value` in `r0`.
  - Reads dismissal context pointer from global address `0x00464A70`.
  - Reads maximum valid limit from `context[1]` (offset +4).
  - If `value < limit`: stores `context[3] = value` (offset +0x0C) and returns `true` (1).
  - If `value >= limit`: does not modify context and returns `false` (0).
- **Differential Coverage:** Verified in Unicorn across values strictly below the limit, equal to the limit, and above the limit against original ARM binary with 100% register and memory equivalence.
