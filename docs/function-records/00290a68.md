# ui_func_00290a68 (0x00290A68)

## Summary

- **Address:** 0x00290A68
- **Size:** 464 bytes (104 ARM instructions + 48 literal bytes)
- **Domain:** UI decimal text formatter
- **Ledger status:** `non_matching` (readable semantic reconstruction)
- **Source:** `src/engine/leaf_batch41_c.cpp`
- **Differential suite:** `tools/test_leaf_00290a68.py`

## Recovered contract

The callable ABI is `int ui_func_00290a68(char* dst, s32 value)`:

- `r0` is the destination cursor; `r1` is the signed decimal value.
- `r4-r11` are preserved; the frame is balanced (`push {r4,r5,r6,r7,r8,sb,sl,lr}`,
  `pop {r4,r5,r6,r7,r8,sb,sl,pc}`).
- For `value == 0` the function restores its registers and tail-branches through
  the 0x002BE7F4 ARM-to-Thumb veneer into 0x002BE7FC with `dst` and the first
  glyph literal.  The formatter's return value is this function's return value.
- For every non-zero argument the loop below runs; the last loop step executes
  `smull/asr` on the place value, which leaves `r0` at zero, so the returned
  word is the dead residue `0`.  The production caller
  (`src/engine/leaf_batch45_a.cpp`) declares the function `void` and ignores it.

### Non-zero path

Places iterate 100000000, 10000000, ..., 1 and then terminate (`place /= 10`,
loop while `place > 0`).  For each place:

1. The guard is a **signed** comparison of the current `place` against the
   **original** argument, not the running remainder.  Negative arguments
   therefore skip every place and write nothing.
2. If `place <= value`, `ui_func_002c615c(remaining, place)` is called and its
   low return word is the quotient.
3. Only quotients 0..9 have a glyph; the ten glyphs are appended with
   `ui_func_002be7fc(dst + written, glyph)`, and `written` advances by the
   formatter's returned byte count.  A quotient >= 10 is not printed.
4. Regardless of whether a glyph was printed, `remaining -= place * quotient`
   is applied with 32-bit wrapping, then `place /= 10` (compiled as the
   `0x66666667` signed-division magic).

A positive value below 100000000 skips the leading places; a value at or above
100000000 can produce a first quotient of 10 or more (e.g. 1000000000 -> 10,
2147483647 -> 21).  Those quotients are dropped but still subtracted, so the
next places continue from the reduced remainder.

### Literals

The 48 trailing bytes are:

- `0x05F5E100` = 100000000 (initial place);
- `0x66666667` (signed-division magic for `/10`);
- ten 4-byte entries at 0x00290C10 = full-width Shift-JIS digits "0".."9"
  (glyph `0x824F..0x8258`, NUL, alignment zero).

## Calls and data

- `0x002C615C` (ARM `bl`): quotient/remainder helper.  `r0` low word is the
  quotient, `r1` high word is the remainder.  Only the quotient is consumed.
- `0x002BE7FC` (Thumb): variadic text formatter.  Reached by `blx` from the
  per-digit cases and by a tail branch through the 0x002BE7F4 veneer for a
  zero value.  Its `r0` byte count advances the destination cursor.
- No indirect calls, no global/object accesses, no stack arguments, no writes
  other than the destination text produced by the formatter.

## Evidence

`python tools/test_leaf_00290a68.py` compiles `src/engine/leaf_batch41_c.cpp`
for ARMv6K, relocates only this function, and runs it against the pinned
original in separate Unicorn machines with identical fixtures.

- 54 differential cases: zero, every place transition (1..2147483647), signed
  boundaries (including -1 and INT_MIN), and forced helper quotients
  0..11 and 0xFFFFFFFF (both multi-place and single-place).  The forced
  quotients exercise the `quotient < 10` glyph guard in both directions.
- Compared: return `r0`, continuation PC, SP, callee-saved `r4-r11`, the
  ordered call log (numerator/denominator and destination offset/glyph bytes),
  the whole 64 KiB destination page, and any write outside the private stack
  and destination page.
- Three compiled negative controls are detected: widening the glyph guard to
  `<= 10`, tightening the place guard to `<`, and changing the dead return
  value.

Result: `All 54/54 differential cases PASSED.`

## Limits

- Both helpers are deterministic stubs: the real 0x002C615C division loop and
  the real 0x002BE7FC Thumb formatter were not executed.  The stubs implement
  the recovered contracts (quotient/remainder; glyph copy + byte count).
- The zero-value path's formatter return value is therefore fixture-defined
  (the copied byte count), not a measured runtime result.
- No caller composition, whole-binary promotion, or runtime scenario is
  established.
