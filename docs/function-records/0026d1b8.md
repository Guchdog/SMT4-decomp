# Function Record: script_vm_func_0026d1b8 (0x0026D1B8)

## Summary
- **Address:** `0x0026D1B8`
- **Size:** 504 bytes (`[0x0026D1B8, 0x0026D3B0)`): 125 ARM instructions
  `0x0026D1B8..0x0026D3A8` (500 bytes) plus the literal word `0x0043DCF0` at
  `0x0026D3AC`.  The body ends at the `pop {r4, r5, r6, r7, r8, pc}` at
  `0x0026D3A8`; the tail branch path uses `0x0026D3A0` (`pop ... lr`) followed by
  `b 0x001B0454`.
- **File:** `src/engine/leaf_batch42_b.cpp`
- **Role:** Script-VM event filter.  Reads a live event id and two comparison
  values from argument-free helpers, classifies the id into six overlapping
  groups, invokes a follow-up routine (`0x0026C480`) when the recovered
  predicate says so, and then either returns early because the object already
  matches the event, dispatches a state transition through `0x001B0454`, or
  simply returns the current state byte.
- **Classification:** `non_matching` with semantic evidence.  The compiled body
  is 620 bytes including local literal words versus 504 bytes in the original.
  The compiler replaces the explicit per-id compare chains with bitmask tests,
  merges some equivalent branches and saves extra callee-saved registers, while
  performing the same seven calls in the same order, reading the same object
  fields and producing the same return value and memory side effects (343/343
  differential cases, 22/22 negative controls).

## Contract and Behavior

### Signature and ABI
```c
u32 script_vm_func_0026d1b8(void);   // extern "C"
```
- Every live input arrives through global state, not registers.  The routine
  takes no arguments; `r0-r3` on entry are dead and are never read before being
  overwritten by the first helper call.
- Prologue `push {r4, r5, r6, r7, r8, lr}`; epilogue
  `pop {r4, r5, r6, r7, r8, pc}`.  The tail path pops the same set into `lr`
  and branches.  Final SP equals entry SP; there are no stack arguments or local
  objects.
- There are **no indirect calls** and **no memory writes** in this function.
  Every object access is a load.

### Recovered layout

| `*(u8**)0x0043DCF0` | u32 | global script/VM object pointer; loaded **once** before the probes |

No other object field is touched.  The literal `0x0043DCF0` is loaded by
`ldr r0, [pc, #0x1DC]` at `0x0026D1C8` (PC `0x0026D1D0` + `0x1DC` =
`0x0026D3AC`), followed by `ldr r5, [r0]`.  `r5` then holds the cached object
pointer for the rest of the body, including across all probe calls and the
conditional callback.

### Call order
1. `0x0029E2CC` — gate; non-zero result is returned immediately.
2. `0x0029AF4C` (`Status_GetSelectedActorPtr`) — result discarded.
3. `0x002B8CCC` — returns the event id byte (`u8`, zero-extended).
4. `0x002830E0` — returns the first signed 32-bit comparison value (`value6`).
5. `0x00282F3C` — returns the second signed 32-bit comparison value (`value8`).
6. `0x0026C480` — conditional follow-up, called only when the accumulated
   `flagged` predicate is true.
7. `0x001B0454` — tail branch for the recovered state set; its `r0` is forwarded.

All seven are direct `bl` sites in the original.  Each helper begins by loading
its own globals and overwriting `r0-r3`, so none consumes an argument; the
selected-actor result (`r0` after call 2) is immediately discarded by call 3.
The candidate declares them explicitly; `0x0026C480` (defined later in the same
translation unit as a naked body) and `0x001B0454` (defined in another
translation unit) are reached through asm-labelled declarations so the shared
prototypes are not redefined.  The tail declaration returns `u32` solely to
expose the ABI `r0` that the original forwards to its caller.

The six groups overlap exactly as in the ARM: `0xCC` belongs to groups 1, 3 and
5; `0xE3` to groups 2, 4 and 6.  All id comparisons are equality tests on the
zero-extended `u8` event id.  `value8` is signed in the group predicates
(`value8 < 0` vs `value8 >= 0`) and in the halfword comparison; `value6` is
signed but only tested for zero in the predicates.  The flag byte is read only
when the preceding register tests do not already decide the predicate, matching
the original `cmpne`/`ldrb` short-circuit chains.

### Return values (r0 is not forced to zero)
1. Gate non-zero: returns the gate result unchanged (tested with `1`, `2`,
   `0x7FFFFFFF`, `0xFFFFFFFF` and `0x80000000`).
2. Object already matches: returns the sign-extended `object[0x44]`, which is
   numerically equal to `value6` on that path (`-128`, `-1`, `0`, `1`, `127`).
3. Tail state: returns whatever `0x001B0454` leaves in `r0` (the offline stub
   supplies a distinctive value).
4. Every other path: returns the `u8` state byte at `object + 0x66C`
   (`0x00`, `0x05`, `0x0B`, `0x11`, `0x80`, `0xFF`, ...).

### Data written
None.  The function only reads the global slot and the four object fields.
Stub-driven fixtures in the test mutate `object + 0x42/0x3A/0x44/0x66C` from
inside the probes to prove that the candidate reads those fields after the
probes, not from cached values.

## Domain Limits
- All seven helpers are stubbed deterministically.  Their live contracts are
  reduced to: gate result, selected-actor pointer (discarded here), event byte,
  two signed comparison values, a void follow-up and a forwarded tail result.
  The real helpers depend on script/VM/camp state that the offline fixture does
  not reproduce.
- The object fixture is synthetic.  The recovered field meanings are limited to
  the widths and offsets above; no semantic names beyond "flag byte",
  "comparison halfword", "comparison byte" and "state byte" are justified by the
  ARM evidence.
- The object pointer is not null-checked in either body: a null global slot with
  a zero gate faults on the first field read, exactly as in the original.
- The tail target `0x001B0454` and the conditional callback `0x0026C480` are
  exercised only through stubs.  `0x0026C480` is itself a not-yet-reconstructed
  naked body in the same translation unit; its real effects, and those of
  `0x001B0454`, are outside this record.
- The `u32` return type of the `0x001B0454` alias documents only the forwarded
  ABI register; no source-level return contract for that function was recovered.
  All callers of `0x0026D1B8` at `0x001C48C4`, `0x001C514C` and `0x001C6A80`
  ignore its result.
- Runtime integration (live script VM state and the real helper effects) was not
  exercised; this record covers offline differential equivalence only.
