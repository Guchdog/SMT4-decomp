## Contract & Behavior
1. Each input angle is made absolute (`vabs.f32`), then reduced by repeated
   subtraction of `65536.0f` while the absolute value's IEEE bit pattern,
   compared as a signed 32-bit word, is `>= 0x47800000` (i.e. while the value is
   `>= 65536.0f`). The result lies in `[0, 65536.0f)`.
   The sign is taken separately from the original argument (`vcmpe` with `0.0`
   before `vabs`); `-0.0` and NaN are non-negative for this test.
2. For each reduced angle, `vcvt.u32.f32` truncates it. The low 8 bits of the
   truncated value select a 16-byte table entry; the full low 16 bits (equal to
   the truncation while the value is below 65536) rebuild the integer part, and
   the float difference is the fraction in `[0, 1)`.
3. The table base is the literal `0x00407FC0`, 256 entries of four floats
   `{f0, f1, f2, f3}` in 16 bytes. For angle *x* (entry `ex`, fraction `fx`):
   `a = ex.f0 + fx*ex.f2`, `b = ex.f1 + fx*ex.f3`; likewise `{c, d}` from
   `angle1` and `{e, f}` from `angle2` (the original uses `vmla.f32`).
   If the angle was negative, its own pair is sign-flipped (`vnegne.f32`):
   `a = -a`, `c = -c`, `e = -e`.
4. Independent products are formed and rounded first: `af=a*f`, `bf=b*f`,
   `fd=f*d`, `be=b*e`, `ae=a*e`, `ed=e*d`, `ad=a*d`, `bd=b*d`.
5. The three 4-word rows written at the matrix pointer are:
   ```
   [0x00]=fd           [0x04]=af*c-be      [0x08]=ae+bf*c
   [0x10]=ed           [0x14]=bf+ae*c      [0x18]=be*c-af
   [0x20]=-c           [0x24]=ad           [0x28]=bd
   ```
   (sed-like offsets; `0x04`/`0x18` come from `vnmls`, which computes
   `Sn*Sm - Sd`, and `0x08`/`0x14` from `vmla`).
6. When `clear_padding` (r1) is non-zero, the three padding words at
   `+0x0C`, `+0x1C` and `+0x2C` are written as `0.0f`; otherwise they are left
   untouched. The test is a plain non-zero word test (`0xFFFFFFFF` clears).

All loads/stores are 32-bit float or word accesses. The original reads the
matrix only to write it; all matrix words listed above are written on every
path.

## Domain limits
- The reduction loop in the original never terminates for `+infinity` or NaN
  absolute values, so those inputs are outside the recovered domain; the
  replacement reproduces the same non-termination but was not exercised with
  them.
- Inputs are assumed to be finite values whose magnitude is representable in
  the reduced range after the repeated subtraction.
- The absolute value of the input is compared by bit pattern. For all finite
  non-negative floats this is the same as the signed comparison used by the
  original (the sign bit is clear), which the test covers including denormals.
- The matrix pointer is assumed suitably aligned for 32-bit VFP/word stores,
  as in the original.
