# `camp_func_002aa268` — select and copy a profile record word

## Recovered behavior

The helper takes `(record, index, selector)` as full-width 32-bit arguments. It first loads the table pointer from `record+0x64`; a null table returns the original record pointer without any writes or table read. On the non-null path it writes `(u16)index` to `+0x68`, clears the halfword at `+0x6A`, clears bytes `+0x88` and `+0x8A`, and stores `(u8)selector` at `+0x6C`. It then selects one word at `table + index*12 + (selector == 0 ? 0 : 4)`, using the full selector for the branch and full index for address arithmetic. That selected 32-bit word is written, in order, to `record+0x24`, `+0x28`, and `+0x2C`; the function returns the original record pointer.

All accesses that determine the observed ordering use volatile typed memory operations. The selected table read occurs after the metadata writes. Direct alias fixtures demonstrate that writes at `+0x68` and `+0x6C` can alter the selected entry before it is read. Address arithmetic is unsigned 32-bit modulo `2^32`, including the `index*12` stride and selector word offset.

## Caller and offline evidence

The original selector at `0x002B85BC` calls this helper from both two-slot loop iterations when its mode byte is not 1. The composition fixture executes the original selector with mapped records and tables; the observed helper arguments are `(object+0x37C, 0, 1)` and `(object+0x408, 0, 1)`, each with aligned SP. Other selector service dependencies are controlled hooks, and the composition is a bounded fixture rather than evidence of natural runtime reachability.

The focused experiment in `tools/h2_profile_record_copy_experiment.py` compares the pinned original and staged candidate. Its final run passed 12 direct cases, the original-selector composition, and four mutation controls. Coverage includes null table, selector values 0/1/0x100/0x10000/0xFFFFFFFF, indices 0/1/0xFFFF/0x10000/0xFFFFFFFF, two record/table alias orders, the invalid-record fault, and a selected-table fault after metadata writes. The stride, full-width selector branch, destination field, and load/store order controls were all detected. The compiled body is 68 bytes in the original 72-byte slot, has no relocations, and differs from the original. IPS replay passed and no bytes outside the slot changed.

The direct mapped-memory tests use synthetic aligned records and tables. There is no table length check, and the original does not validate pointer alignment or bounds. The two deliberate fault cases match at the fault address and preserve the same pre-fault writes. This evidence does not establish live profile table population, pointer lifetime, concurrency, or runtime H2 behavior.
