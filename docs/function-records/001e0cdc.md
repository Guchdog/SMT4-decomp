## Behavior
1. Clear `+0x217c` to 0 and `+0x2180` to 3; store the low halfwords of the two
   count arguments.
2. Clamp the requested count:
   - if `coord + first < 0`, replace it with `-coord` (as a halfword);
   - then, after reading the stored halfword back as s16, if
     `count + coord > 10`, replace it with `10 - coord`.
3. When `second > 0`:
   - if the clamped count is positive, add it to the base coordinate;
   - raise script event `0x01000173` through `0x002bf9e8`;
   - if the stored `+0x2192` halfword is positive, iterate index
     `0 .. reloaded-0x2192-1`. For each index:
     * write marker `8` (flag non-zero) or `7` (flag zero) to
       `slot(base - 0x218e - index + 0x13) + 0x20`;
     * call service `0x002bf030` with selector `10` on
       `slot(base - 0x218e - index + 0x31) + 0x20`;
     * rewrite that slot with marker `0xfa6` (flag zero) or `0xfa7`
       (flag non-zero). The original derives the high marker with
       `orr sl, sl, sl, asr #9`.
4. Reload `+0x2190` and branch on its signed value:
   - **positive:** iterate index `0 .. reloaded-0x2190-1`. Each iteration makes
     two `0x002bf030` selector-2 calls at `+0x20` and `+0x598`, then four marker
     writes at `+0x20`, `+0xb10`, `+0x1088`, `+0x1600`. The marker set is
     `1/8/3/0xfa1` when the mode flag is non-zero and `0/7/2/0xfa0` otherwise.
     The coordinate is reloaded before each call/write.
   - **zero:** return 0.
   - **negative:** walk index `0, -1, ...` while it remains greater than the
     reloaded count. Each iteration makes four `0x002bf030` calls with selectors
     `8/8/9/8` at `-0x6c`, `+0x50c`, `+0xa84`, `+0xffc`. The coordinate is
     reloaded before each call.

Every count, coordinate and flag read is reloaded at the same point as the
original, including after helper calls that may have rewritten the block.
