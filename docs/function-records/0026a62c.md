## Contract and Behavior

### Signature and ABI
```c
u32 camp_func_0026a62c(u32 mode);   // r0 = mode
```
- `mode` is only compared for equality against `0xB`, `0xC` and `0xD`.
- The prologue saves `r4`, `r5`, `r6`, `r7`, `r8`, `sb` (r9) and `lr`, and
  reserves 0xC bytes of stack (`0x0026a62c..0x0026a634`). The final call to
  `0x0029fae8` uses that space for its two stack arguments.
- Return: on the non-dispatch/wrap exit the original leaves `r0` holding the
  work pointer loaded at `0x0026a640`. On the selected-list path it sets
  `r0 = mode` and tail-branches to `0x002831f0`; that callee's `r0` is forwarded
  to the caller. Existing callers ignore the result, but the reconstruction
  returns the same value for differential observability.

### Table writes
Accepted ids are stored as zero-extended halfwords at `table[count]`, and
`count` (r4) is incremented after every store. The first table entry is index 0
on every path; the second pass continues with the count left by the first pass.
All bounds are inclusive.

### Mode 0xB (`0x0026a6d4..0x0026a6e8`, loop `0x0026a684..0x0026a6ac`)
- Enumerate `id = 1..0x3C` with the signed `cmp r5,r7` / `ble` bound.
- Store when `0x0028ec78(id) != 0`.
- There is no second pass (`0x0026a6d0` jumps directly to `0x0026a774`).

### Mode 0xC (`0x0026a6ec..0x0026a700`, `0x0026a704..0x0026a72c`)
- First pass: `id = 0x3B7..0x47E`, signed `ble`, store when
  `0x0028ec78(id) != 0`.
- Second pass: `id = 0x47F..0x79E`, unsigned `bls`, same predicate.
- The passes are contiguous, so the table concatenates both ranges.

### Mode 0xD (`0x0026a658..0x0026a668`, `0x0026a734..0x0026a770`)
- First pass: `id = 0x33F..0x3B6`, signed `ble`, store when
  `0x0028ec78(id) != 0`.
- Second pass: `id = 0x79F..0x802`, unsigned `bls`.
  - Call `0x0028ec78(id)` first.
  - Only when that result is non-zero, call `0x0028fde4(id)`.
  - Store when the **signed** result of `0x0028fde4(id)` is `> 0`
    (`cmp r0,#0` / `ble` at `0x0026a750..0x0026a758`).
  - The second call is therefore not made for rejected first-predicate ids,
    even though `0x0028ec78` is normally the `> 0` normalization of
    `0x0028fde4`. The differential test exercises both helpers independently.

ignored. The original then restores the stack and saved registers, loads
