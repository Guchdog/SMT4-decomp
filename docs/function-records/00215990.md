## Role and Behavior
- **Role:** Sets the party prompt configuration and plays prompt audio cues according to active screen mode and menu ID.
- **Details:**
  - When `active_sound_id >= 0` and `active_mode == 1`:
    - Checks `Status_GetMainMenuId()`.
    - If menu ID is `0x0D` or `0x06`, plays sound effect `0x2F` (`Sound_PlaySE(0x2F)`).
    - Otherwise plays sound effect `0x1F` (`Sound_PlaySE(0x1F)`).
  - Resets `active_sound_id` to `-1`.
  - Stores prompt configuration parameters into `prompt_field0`, `prompt_field1`, `prompt_field2`, `prompt_field3`.
  - Configures prompt list cursor via `UiListCursor_Setup(&work->list_cursor_prompt, 7, 7, 1, 0, 1)`.
  - Sets `needs_refresh = 1`.
