### Control flow
1. If `handle == 0`, return `0`.
2. `status = open(self, handle, 5, 2, &size)`.
3. If `(status & 0x3FF) == 0x3F7`, return `0` (the high bits and kind are
   ignored for this test).
4. Prepare the source when `size == 0` or when
   `kind = (status >> 10) & 0xFF == 0x11` and `(status & 0x3FF)` is in
   `[0x64, 0xB3]`. Preparing calls `reset(self, handle, 0, 0, 0)`; a negative
   result returns `0` before allocation.
5. `buffer = alloc(0x320, 4)`. A null result stores `0` at `self + 0x560` and
   returns `0`.
6. `status = read(self, buffer, size, &written, handle, 5, 0x12)`;
   a negative result frees the buffer and returns `0` **without** changing the
   current count.
7. If `written != 0`, copy the 8-byte header from `buffer` to `self + 0x55C`.
8. Accept when `u16(self + 0x55C) == 0x6767` and
   `u32(self + 0x560) == (size - 8) >> 3` (unsigned 32-bit subtraction and
   logical shift; sizes below eight wrap).
9. Otherwise retry once: `reset` (negative → free and return `0` without
   changing the count), `open` (negative → zero the count, free, return `0`),
   `read` (negative → zero the count, free, return `0`), then
   unconditionally copy the 8-byte header from `buffer` to `self + 0x55C`.
   Re-validate; failure zeroes the count, frees and returns `0`.
10. On success, copy `self->count` records: for each `index`, copy eight bytes
    from `buffer + 8 + index*8` to `self + 0x564 + index*8`. The loop condition
    reloads `self->count` after every copy, so a callee that changes the count
    changes the bound. A zero count skips the loop.
11. Free the buffer, reload `self + 0x560`, and return that word.
