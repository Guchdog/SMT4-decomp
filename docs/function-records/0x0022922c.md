# `func_0022922c` — `0x0022922C`

This function iterates over a 109-element array of records stored in an engine data graph
and clears bit `0x400` from the first 32-bit word of every record.
The C++ definition is in [`src/engine/leaf_batch30_c.cpp`](../../src/engine/leaf_batch30_c.cpp).

## Contract and logic

1. Traverses the double indirection from input pointer `obj`:
   - `base_addr = *reinterpret_cast<const uintptr_t*>(*obj + 0x1FC0u)`
2. Iterates over 109 records (`i = 0..108`) at stride 648 bytes (`0x288`):
   - `word = reinterpret_cast<uint32_t*>(array + i * 648)`
   - `*word &= ~0x400u`
3. Returns void.
