The 444-byte body is `[0x002B1FC0,0x002B217C)` with SHA-256

It saves/restores `r4/r5`, returns through `bx lr` at `0x002B2024`,
`0x002B2114`, `0x002B2120`, or `0x002B2178`, and uses no external calls. The
single pointer argument in `r0` is retained as the return value. `r4-r11` and

untouched. FPSCR exception/status bits can change on floating-point paths.

The preview helper at `0x002BF9F0` calls this function at `0x002BFC30` after

calls are separate entries: `0x002B1DFC` updates a distinct track/output field

not merge their contracts.

## Supported direct behavior

- Byte `object+0x87` is an early completion gate; nonzero returns without
  touching track data. Otherwise a zero word at `+0x58` returns unchanged.
- Signed halfwords at `+0x5C` and `+0x5E` are row index and progress. The row
  address is `table + 12 * signed_index` modulo 2^32. Row `+8` is an unsigned
  duration compared as signed `duration > progress`; there is no index or
  pointer bounds check.
- While progress is below duration, direction byte `+0x60` selects the float
  difference order: nonzero computes `row[0] - row[1]`, zero computes
  `row[1] - row[0]`. ARM performs single-precision subtraction, unsigned
  duration conversion, division, then adds the result to float `object+0x20`.
  It stores `progress+1` as a low halfword and the new float at `+0x20`.
- Once progress reaches/exceeds duration, row byte `+0x0A` selects one of two
  endpoint paths. Nonzero mode stores row float `+4` for nonzero signed
  direction or row float `+0` for zero direction, clears progress, and returns.
  Zero mode first stores the opposite endpoint, then checks the optional
  sequence feature byte `+0x84` and pointer `+0x78`.
- The sequence array uses 28-byte entries, with its first marker/row word at
  base `+0x0C`, signed direction at `+0x10`, and subsequent entry fields at the
  same offsets. The signed halfword index is `+0x7E`. Current `-1`, next `-1`,
  and next `-3` set `+0x87`; next `-2` resets index to zero and restarts using
  the first entry. Ordinary next entries supply a signed-halfword row index
  and signed-byte direction, reset progress, clear `+0x8A`, and write the
  selected endpoint to `+0x20`. Disabled/missing sequence state sets `+0x87`.
