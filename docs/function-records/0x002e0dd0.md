## Limitations

Validation covers only the wrapper interacting with modeled dependencies: the gate stub returns configured words, the count stub scans the supplied zero-terminated `u16` array, and setter/cleanup stubs log calls without reproducing their true effects. Caller tests begin at direct BL sites with audited argument shapes and execute through the caller return; they do not run the callers' full setup paths. Global/object fixtures are synthetic. MMIO, concurrent mutation, malformed strings, runtime loader, and whole-game behavior are not tested. No byte-matching or production equivalence claim.
