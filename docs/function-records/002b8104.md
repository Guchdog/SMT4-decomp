## Role and Behavior
- **Role:** Converts float32 screen coordinates, texture UVs, and vertex colors into PICA200 packed 24-bit floats and emits a 4-vertex quad via `func_002a9414`.
- **Details:**
  - Receives 4 vertex colors in registers `r0..r3` and 9 floating point coordinates in VFP registers `s0..s8` (x, y, w, h, u, v, uw, vh, z).
  - Uses exponent translation table at `0x004E31A0` to convert IEEE-754 32-bit floats into PICA200 24-bit float format (`exp_tbl[exp] | mant | (sign << 23)`).
  - Uses color expansion table at `0x004E35A0` to pack byte color components into 3-word GPU vertex color attributes.
  - Generates 4 vertices forming a triangle strip quad:
    - Vertex 1: top-left `(x, y)`, `(u, v)`, `col0`
    - Vertex 2: bottom-left `(x, y + h)`, `(u, v + vh)`, `col1`
    - Vertex 3: top-right `(x + w, y)`, `(u + uw, v)`, `col2`
    - Vertex 4: bottom-right `(x + w, y + h)`, `(u + uw, v + vh)`, `col3`
  - Dispatches each vertex to the UI geometry batcher via `func_002a9414(pos, col, tex)`.
