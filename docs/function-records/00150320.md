## Contract corrections and hazard notes
- **Null-object loads are real.** After zeroing the candidate object the
  original unconditionally reads `[object+0x51]`, `[object+0x44]` and
  `[object+0x50]`. With a valid caller those are normal object fields; a failed
  vtable check makes them absolute low-address reads. The harness maps page 0
  and fills `0x44/0x50/0x51` to exercise this path without a fault; the
  candidate reproduces it with volatile integer-address loads.
- **The first memcpy destination is the pre-call cursor.** The record starts at
  the post-call cursor plus `(size & ~3)`, not at the payload start.
- **Two cursor reloads.** The original re-reads `0x004652A0` after the first
  memcpy and after each trailing memcpy; the candidate does the same.
- **Bytes 0x18/0x1C are a `strd`.** The pair `0x80000019, 0x000F02C0` is stored
  as two words at `record+0x18`.
- **`0x002A1B98` writes `{0, z, y, x}`.** It reads three multiplying-order
  floats from the source and writes a zero word plus the reversed triple.
- **Selector re-read.** `stream[0x30]` is loaded at `0x150370` and again at
  `0x150594`; the candidate uses separate `early_selector`/`late_selector`
  reads.

## Limits
- Fixtures are synthetic; scene/unit/entry/node/model/stream/matrix data and
  payload bytes are not captured game data.
- Every callee is stubbed: `0x002ACD38` (memcpy semantics), `0x002C255C`
  (select-call boundary), `0x002A1AC8`, `0x002A1A90`, `0x002A1B98`,
  `0x002A5078` (affine multiply) and `0x00155584` (returns `unit+0xFC` after a
  scripted lazy copy). No real GPU submission, scene graph, model or stream
  update is exercised.
- `0x002A5078`'s stub uses host double arithmetic before packing to `f32`; the
  original VFP rounding is not modeled. Both sides of the differential use the
  same stub, so this does not affect the comparison.
- The original's null-object path is only observable because page 0 is mapped;
  in a real process it would fault. The candidate preserves the same accesses.
- No caller-composition, emulator-runtime or whole-game equivalence is
  claimed.
