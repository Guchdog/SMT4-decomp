## Contract and Behaviour

### Signature and ABI
```c
extern "C" f32 engine_func_00288424(f32 x);
```
- Hard-float AAPCS: the argument arrives in `s0`, the result is returned in
  `s0`.  The prologue is `push {lr}` + `vpush {d8}` + `sub sp, #4` and the four
  exits restore them; the function keeps `x` in callee-saved `s16` (half of
  `d8`) across the reduction calls.
- `r0`/`r1` carry bit patterns: `r1 = bits(s0)` at entry.  The only memory the
  routine itself touches is the 4-byte quadrant slot in its own frame
  (`[sp]`).
- No global state is read or written by the routine; the only side effect is
  the errno store performed by the unresolved `0x002A464E` helper on the
  infinity path.

### Control flow
1. **Magnitude windows.**  With `s = bits(x) << 1` (sign dropped), the routine
   takes three paths:
   - `s < 0x73000000` (`|x| < 2^-12`): quadrant `-1`, reduced value `x`; the
     result is `x` unchanged (after the classifier/underflow probe below).
   - `s < 0x7E921FB6` (`2^-12 <= |x| < pi/4`): quadrant `0`, reduced value `x`.
   - `s >= 0x7E921FB6` (`|x| >= pi/4`): reduce.  If
     `|bits(x)| >= 0x46490E49` (`|x| >= 12867.5712890625`) the generic helper
     `0x003EB4F4` performs the reduction; otherwise the inline reduction runs.
2. **Inline reduction.**  `q = round(x * 2/pi)` uses the 2^23 add/subtract
   trick, with the subtraction direction selected by the sign of `x`.  The
   quadrant is `q & 3`.  The reduced angle is
   `r = x - q*(p0 + p1 + p2 + p3)` with each `p` subtracted separately (the
   pinned code uses VMLS, one rounding per part).  The 2^23 trick is only used
   below `12867.5712890625`; above it the generic helper is required because the
   rounding constant would lose the quadrant.
3. **Generic reduction helper** `0x003EB4F4(u32* out, u32 value_bits)` writes
   the quadrant through the pointer (0..3, or `0xFFFFFFFF` for non-finite
   input) and returns the reduced angle in `s0`.  For non-finite input it leaves
   `s0` equal to the incoming value; this contract is verified against the
   pinned body in the test.
4. **Quadrant `-1` tail.**  `m = bits(r) << 1`:
   - `m > 0xFF000000` (NaN): return `r + r` (VFP quieting addition).
   - `m == 0xFF000000` (infinity): call `0x002A464E(1)` (sets errno through
     `*__errno_location()`), then return `0.0f / 0.0f` (VFP default NaN).
   - otherwise: call `0x002A4600(bits(r))`; if the class is 4 (subnormal) call
     the 16-byte probe `0x002A462C(r)` and discard its result; return `r`.
5. **Quadrant `0..3` tail.**  `r2 = r*r`;
   `P = c5 + r2*(c4 + r2*(c3 + r2*(c2 + r2*(c1 + r2*c0))))` (evaluated from
   the lowest coefficient upward); `t = r + r*(P*r2)` = `tan(r)`.
   Even quadrant returns `t`; odd quadrant returns `-1.0f / t`
   (`tan(r + k*pi/2)` for odd `k`).

## Differential validation
`python tools/test_leaf_00288424.py` compiles `src/engine/leaf_batch45_b.cpp`,
extracts `engine_func_00288424`, repairs its four call relocations (the
`0x002A464E` call is emitted as an ARM `BLX` immediate because the target is
Thumb) and runs the pinned original and the candidate in Unicorn ARM.

Compared per case: returned `s0` bits, PC, SP, callee-saved `r4-r11` and
`s16-s31`, the ordered helper call log (reduction value bits, classifier bits,
probe `s0`, errno value), stack bytes outside the private 0x100-byte window,
image hash and writes outside the window.  The four helpers execute their pinned
bodies; the hooks log arguments and can inject the reduction result/class to
reach the otherwise hard-to-reach `quadrant == -1` sub-branches.  A Python model
(`f32`-rounded) checks every case whose reduction does not need the generic
helper, including the call log.

Coverage (129 cases): the three magnitude windows with exact bit boundaries
(`2^-12`, `pi/4`, `12867.5712890625`), all four quadrants and exact quarter-turn
ties, `+/-0`, subnormals, min normal, max finite, `+/-infinity` and every NaN
class, injected reduction results for each quadrant and each `quadrant == -1`
sub-branch (normal, subnormal, `+/-inf`, qNaN, sNaN), and forced/natural
classifier classes.  14 compiled mutants (boundary shifts, threshold off-by-one,
sign of the rounding direction, quadrant mask, a skipped reduction part,
classifier comparison, errno value, NaN/inf order, parity inversion, a
polynomial coefficient, reciprocal sign, ignored helper result, disabled
reduction window) are all detected.

## Limits
- The reduction helper's finite reduction is treated as an opaque dependency;
  the test runs the pinned body for finite huge inputs but the Python model does
  not reproduce it.  Only the non-finite contract (`out = -1`, `s0` unchanged)
  is modelled and pinned-verified.
- `0x002A464E` is an unresolved Thumb libm/linker helper.  The test does not
  execute its `__errno_location` store; the hook logs the stored value and
  returns to the caller.  Its surrounding runtime context is not recovered.
- The compiler emits separate `VMUL`/`VADD` (and `VMUL`/`VSUB`) instead of the
  pinned `VMLA`/`VMLS` chain, so a double-rounding difference is theoretically
  possible for inputs outside the covered set; every covered input is
  bit-exact.
- No emulator run, caller-composition test, or whole-game scenario was
  performed; the caller relationship is static evidence only.
