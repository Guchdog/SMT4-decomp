# Function Record: ui_func_00195424 (0x00195424)

## Summary
- **Address:** `0x00195424`
- **Size:** 408 bytes (original span `[0x00195424, 0x001955BC)`)
- **File:** `src/engine/leaf_batch44_b.cpp`
- **Role:** State dispatcher that updates the heading fields of one UI object.
  The byte at `+0x1D8` selects a no-op (0 and every value other than 1/2), a
  sign-based heading (`+0x0C`, and optionally `+0x04`) computed from the
  `+0x120`/`+0x124`/`+0x128` angles and the `+0x34C` divisor, or a whole-degree
  heading derived from the `+0x120`/`+0x124` minus `+0x2D4`/`+0x2D8` vector
  through the 16-bit-units atan2 helper at `0x00360F48`.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  312 bytes versus 408 original bytes (different register allocation, a merged
  duplicate comparison of the unchanged `+0x124` field, and the literal-pool
  word at `0x1955B8` being folded into the compare-with-zero immediate); the
  ledger row is classified `non_matching` and this record carries the semantic
  evidence.

## Contract and Behavior

### Signature and ABI
```cpp
extern "C" s32 ui_func_00195424(u8* self, s32 mirrored);
```
- `self = r0`, `mirrored = r1`.
- **Return value:** the original leaves an incidental value in `r0` on each
  exit, and the C++ reproduces it exactly for the register differential:
  - state 0 / other state: the state byte (`+0x1D8`),
  - state 2: the value stored at `+0x0C`,
  - state 1 with `+0x130` bit 0 clear: the `+0x130` flag byte,
  - state 1 with `+0x130` bit 0 set: the value stored at `+0x04`.
  Both callers (`0x001AA7DC` with `r1 = 0`, `0x001AAFF8` with `r1 = 1`) reload
  `r0` immediately (`ldrb r0,[r4,#0x380]` at `0x001AA7E0` / `0x001AAFFC`), so
  the value is not a real caller contract.
- The original saves `r4`, `r5`, `r6`, `lr` and pushes `d8` (it caches `+0x124`
  in `s16`/`s17` across the divide calls and the `+0x130` test). `r6` is never
  written.

### Dispatch (`+0x1D8`)
- `0` -> return with the state byte, no stores, no calls.
- `1` -> state-1 heading path.
- `2` -> state-2 degree path.
- anything else -> return with the state byte, no stores, no calls.

### State 1 (`+0x1D8 == 1`)
`y = [+0x124]`, `x = [+0x120]`. Every sign test is the original
`vcmpe.f32` + `ble` pair, so NaN takes the less-or-equal arm (the C++ uses
`> 0.0f` and its negation-by-else to keep that behavior).

| `y > 0` | `x > 0` | `[+0x0C]` |
| --- | --- | --- |
| yes | yes | `90 / (s32)[+0x34C]` |
| yes | no | `-90 / (s32)[+0x34C]` |
| no | yes | `90 / (s32)[+0x34C] + 90` |
| no | no | `-90 / (s32)[+0x34C] - 90` |

`d = (s32)[+0x34C]` is produced by `vcvt.s32.f32`, which on VFPv2 truncates
toward zero, saturates out-of-range values and converts NaN to 0; clang emits
the same `vcvt.s32.f32` for the C++ `static_cast<s32>(f32)`. Division goes
through `0x002C615C` (`__aeabi_idivmod`: quotient in `r0`, remainder in `r1`);
only the quotient is read.

If bit 0 of `+0x130` is clear the routine returns with the flag byte. If it is
set, the same `+0x124` sign is re-tested (the original compares the cached
`s17`, not a reload) and:

| `y > 0` | `z = [+0x128] > 0` | `[+0x04]` |
| --- | --- | --- |
| yes | yes | `-90 / d` |
| yes | no | `90 / d` |
| no | yes | `-90 / d - 90` |
| no | no | `90 / d + 90` |

The value stored at `+0x04` is also the exit `r0` on this path.

### State 2 (`+0x1D8 == 2`)
```
dx = f32[+0x120] - f32[+0x2D4]
dy = f32[+0x124] - f32[+0x2D8]
angle = func_00360f48(dy, dx)          // 16-bit angle units, 0x10000 = a turn
turn  = (u16)(angle - 0x4000)          // quarter-turn offset, 16-bit wrap
deg   = ((u32)turn * 0x168) >> 16      // whole degrees, truncating
[+0x0C] = mirrored ? -deg : deg
```
The two subtractions are single precision in the order X then Y, matching the
two `vsub.f32` instructions; the quarter-turn subtraction is followed by
`uxth`, i.e. modulo 0x10000. `mirrored` is the `r1` argument: 0 from the caller
at `0x001AA7DC`, 1 from the caller at `0x001AAFF8`.

### Observed call order
- state 0 / other: no calls.
- state 1: exactly one `0x002C615C` call; a second one only when `+0x130`
  bit 0 is set (after `[+0x0C]` has been stored).
- state 2: exactly one `0x00360F48` call with `s0 = dy`, `s1 = dx`.

## Domain Limits
- `0x00360F48` and `0x002C615C` are deterministic stubs. The real atan2 math and
  the divide-by-zero escalation inside `0x002C615C` (`0x0014E604`) are not
  modelled; only their observed call/return contract is exercised.
- FPSCR `NZCV` bits are not compared: they are scratch compare state, and the
  compiler legally merges the two compares of the unchanged `+0x124` field, so
  the last-compare flag can differ. FPSCR `IOC` (bit 0) is also excluded: the
  original's signaling `vcmpe.f32` raises it for a quiet NaN operand while clang
  emits the quiet `vcmp.f32` for the equivalent C++ `>` (the branch result is
  identical). The remaining cumulative exception bits are compared.
- Out-of-range/NaN `vcvt.s32.f32` values are covered through the emulated VFP
  behavior of this Unicorn build, which matches the VFPv2 truncating conversion
  and saturation; hardware FPSCR state after those conversions was not measured.
- Runtime behavior inside the game (how the two callers consume `+0x0C`/`+0x04`
  and the ignored `r0`) was not exercised; this record covers offline
  differential equivalence only.
