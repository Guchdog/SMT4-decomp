# StatusDown_DrawPartySlotRow (0x0029a520)

## Summary
- **Address:** `0x0029a520`
- **Size:** 1,696 bytes
- **Domain:** UI / Status Down Screen (Bottom Screen Party Status)
- **Status:** Semantically verified (`non_matching` in ledger)
- **Source File:** `src/ui/status_down.cpp`

## Calling Convention and ABI
- Uses `__attribute__((pcs("aapcs")))` to match the 3DS ARM calling convention where parameters beyond `r0..r3` (including 5th float parameter `scale`) are passed on the stack.

## Role and Behavior
- **Role:** Renders an individual party slot row on the bottom screen, handling cursor selection highlights (pulsing alpha panel, frame node, scissor animation), demon name or empty registration text, HP/MP status bars, demon level (in empty mode), and party order number.
- **Details:**
  - Queries `selected_row = UiListCursor_GetSelectedRow(&work->list_cursor_main)`.
  - Renders cursor selection highlight:
    - Sets global alpha from `work->panel_sprites[1].raw[0x20]`.
    - Draws panel 8 on group `0x1A` at priority `0xBF`.
    - Resets global alpha to 1.0f and draws selection base node `0x41F` at priority `0xC4`.
    - Chooses cursor frame node: `0x421` if idle touch hold state (`touch_drag_state[0..2] == 0 && lr_state_left == 0 && lr_state_right == 0 && touch_hold_state >= 0`), else `0x420`.
    - Draws cursor frame node at priority `0xC4`.
    - Sets scissor mode via `GpuModeSlotSet(0x30C, 3)` and clips to node `0x420`'s rect via `UiScissor_SetRect`.
    - Draws animated node `0x422` offset by `UiAnimSprite_GetPosX/Y(&work->panel_sprites[3])` at priority `0xC9`.
    - Restores scissor mode via `GpuModeSlotSet(0x30C, 0)`.
  - Determines text color:
    - Defaults to white `0xFFFFFFFF`.
    - If `highlight_mode == 1`, green `0x72E027FF`.
    - If `highlight_mode == 2`, red `0xDC0F14FF`.
    - In States 11 and 14:
      - If `selected_row == work->selected_result`: green `0x72E027FF`.
      - Else if `selected_row == UiListCursor_GetRowCount(...) - 1`: green `0x72E027FF`.
      - Else: gray `0x5A5A5AFF`.
    - In other states (excluding 6 and 9):
      - If `work->flag_548 != 0 && work->highlighted_slot_index == selected_row`: green `0x72E027FF`.
  - Renders slot name:
    - If `is_empty_mode != 0 && demon_id == 0`: formats `"ＮＥＷ　ＲＥＧＩＳＴＲＡＴＩＯＮ　ＰＯＳＳＩＢＬＥ！"` and overrides text color to gray `0x5A5A5AFF`.
    - Else if `is_stock_row != 0`: formats `"？？？"`.
    - Else: formats demon's name via `camp_func_002bcff0(demon_id)`.
    - Draws name at node `0x42B` via `UiFont_DrawText(3, text_color, ..., 0.2f, 0.0f, 1.0f)`.
  - If `is_empty_mode == 0 || demon_id != 0`:
    - Draws base node `0x425` at priority `0xC4`.
    - Draws HP/MP bars via `UiParty_DrawDemonBars(demon_id, x + bar_node->x, y + bar_node->y, 0xC9, scale_word, 0)`.
  - If `is_stock_row != 0`, returns immediately.
  - If `is_empty_mode != 0`:
    - Draws level container node `0x522` at priority `0xC4`.
    - If `demon_id != 0`: draws formatted level `%d` via `Party_GetDemonLevel(demon_id)` at node `0x52A`.
    - Else: draws empty level `"---"` at node `0x52A`.
    - Returns.
  - Draws order container node `0x423` at priority `0xC4`.
  - Calculates order number:
    - If `work->active_sound_id < 0`: `Party_GetDemonOrderNumber(demon_id, 1)`.
    - Else if `Camp_GetMainMenuId() == 6`: reads `dwork[0x22]` from `Party_GetDemonWorkPtr(demon_id)`.
    - Else: `Party_GetDemonActiveIndex(demon_id)`.
  - Draws formatted order number `%d` at node `0x429` with width 4 and priority `0xC9` via `UiFont_DrawFormatted`.
