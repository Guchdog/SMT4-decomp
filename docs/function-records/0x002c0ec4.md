# `Tbb_GetGlobalSubTable` — `0x002C0EC4`

This function resolves a global TBB container slot from the fixed global array
at `0x0049382C` (`g_GlobalTbbSlots`, 67 entries of 16 bytes each) and retrieves
a subtable via `Tbb_GetSubTable(container, table_index)` (`0x002AC2F4`). For an
unsigned `slot_id` strictly less than `0x43` (67 decimal), it loads the container
pointer from offset `+4` of that slot (`0x00493830 + slot_id * 16`). If `slot_id`
is out of range (`>= 0x43`), it passes a null container pointer (`nullptr`) to
`Tbb_GetSubTable`. The C++ definition is in [`tbb_loader.cpp`](../../src/ui/tbb_loader.cpp).

The function is a direct dependency of the H2 profile selector at `0x002AEA28`.
Its compiled 28-byte ARM body occupies the original 28-byte slot with no overflow,
and contains an unconditional branch relocation to `Tbb_GetSubTable` (`0x002AC2F4`).
Because Clang produces semantically equivalent instructions (`cmp r0, #0x42; ldrls ...; movhi r0, #0; lslls ...; ldrls ...; b ...`)
rather than historical byte-identical instructions, the ledger row in `config/functions.csv`
is truthfully classified as `non_matching`.

`tools/h2_global_tbb_lookup_experiment.py` passed 130 direct final-VMA cases,
seven caller compositions through the original `0x002AEA28` profile selector,
and three mutation controls (`wrong_boundary_43`, `wrong_base_offset`, `return_non_null_out_of_bounds`).
The direct checks compare raw return register `r0`, stack pointer `sp`, callee-saved registers
`r4`–`r11`, mapped memory writes, and exact call events to `Tbb_GetSubTable`
(verifying argument ordering: container in `r0`, subtable index in `r1`).
The slot-only IPS replay passed with byte-for-byte roundtrip.

Fixtures exercise all boundary slot values (`0`, `1`, `2`, `14`, `0x41`, `0x42`, `0x43`, `0x44`,
`0x50`, `0x100`, `0x7FFFFFFF`, `0x80000000`, `0xFFFFFFFF`), varied table indices,
null and valid `TBCR` container headers, and malformed container data within mapped ordinary RAM.
This evidence establishes bounded offline equivalence for ordinary memory and does not
claim live resource loading or whole-game execution parity.
