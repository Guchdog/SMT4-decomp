### Observed virtual-slot and reload details
- Both indirect calls use the same sequence: `ldr r1,[r0]` then
  `ldr r1,[r1,#4]` then `blx r1`. Slot 1 is called with the object itself.
- The two loads of `+0x00` in step 5 are real: the first happens after the
  `+0x20` virtual call, and the second after the conditional `0x00152af8`
  call. The differential test uses stubs that rewrite those slots so a cached

- The conditional signed test is `s32 >= 0`: `0x7fffffff` calls the release
  helper, while `0x80000000`, `0xfffffffe` and `-1` skip it.
