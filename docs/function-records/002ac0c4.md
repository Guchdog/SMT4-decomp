## Recovered contract

The callable ABI is `float expf(float x)`: the argument arrives in `s0` and the
result is returned in `s0`.  The prologue is `push {r4, lr}` + `vpush {d8}`, so
`r4` and `d8` are preserved and the frame is 16 bytes; `r0-r3` and `s0-s15` are
caller-saved.  There are no loops, no stack arguments and no direct memory
accesses other than the three helper calls.

The function computes `e^x`:

1. `n = trunc(x * 5.770780086517334 +/- 0.5)` (the sign-dependent `+/- 0.5`
   is selected from bit 31 and added before the truncation).
2. `r = x - n*0.17327880859375 - n*7.986545824678615e-06`, i.e.
   `r = x - n*ln(2)/4` using the split literal pair.
3. `e^r - 1 = r + r^2/2 + r^3/6 + r^4/24`, evaluated as
   `r * (1 + r*(~0.5 + r*(~1/6 + r/24)))` with the pinned rounded coefficients.
4. `e^x = 2^(n>>2) * (C[k] + A[k] + B[k]*(e^r - 1))` where `k = n & 3` and the
   three four-entry tables hold `2^(k/4)` as a coarse float `C`, the accurate
   float `B`, and the residual `A = B - C`.

### Control flow (exact branch tests)

Let `raw` be the argument's bit pattern and `u = 0x99000000 + (raw << 1)`,
which is a signed-free test for `2*raw` in `[0x67000000, 0x85500000]`
(`|x|` in `[2^-24, 84]`):

- `u <= 0x1e500000` (unsigned): the normal band above, `n >> 2` is applied as a
  single `2^k` multiply.
- Otherwise, `((~raw) << 1) >> 24 == 0` means exponent `0xFF` (inf/NaN): `-inf`
  (`raw == 0xFF800000`) returns `+0.0`, every other value returns `2*x`
  (`vadd s0,s0,s0`, which propagates inf/NaN).
- Otherwise `0x67000000 > (raw << 1)` (magnitude below `2^-24`, including `+-0`
  and denormals) returns `1.0f`.
- Otherwise `0x85a00000 >= (raw << 1)` (`|x|` in `(84, 104]`) uses the same
  polynomial but splits `n >> 2` into two half exponents (`exponent`,
  `exponent - half`, with `half = (exponent + (exponent<0 ? 1 : 0)) >> 1`) so
  neither intermediate multiply overflows.
- Otherwise `|x| > 104`: the code stores `2` into `errno` and then returns
  `+inf` for positive `x` (`0x70000000 * 0x70000000` overflows) or `+0` for
  negative `x` (a synthetic underflow square of `0x10000000`).

### Split-path result checks

After the two exponent multiplies, the raw result bits are inspected:

- exactly `0x00000000` (underflow to `+0`): store `2` into `errno`, then tail
  into the synthetic-underflow helper and return its `+0` result;
- exactly `0x7F800000` (`+inf`, overflow): store `2` into `errno`, then return
  `0x70000000 * 0x70000000`;
- otherwise call the classifier helper: a result class of `4` (denormal) calls
  the synthetic-underflow helper only to raise the IEEE underflow flag, then
  returns the denormal result.  All other classes return the result unchanged.

## Evidence

`python tools/test_leaf_002ac0c4.py` compiles `src/engine/leaf_batch45_b.cpp`
for ARMv6K, relocates only this function, and runs the pinned original bytes
against the candidate in separate Unicorn ARM machines with identical fixtures.
The real `0x002A4600` and `0x002A462C` helper bodies are placed at their pinned
addresses so both sides execute the same classification/squaring logic; the
`0x002A464E` errno store is a deterministic Thumb stub that records its code and
writes a private errno cell.

- 54 differential cases: `+-0`, `+-`denormals, the `2^-24` and `84.0` band
  edges (and the neighbouring float), every `n & 3` table index, `84.5`, `86.5`,
  `88.0`, `88.72`, `89.0`, `100.0`, `104.0` (and its successor), `-88..-104`
  (denormal and underflow-to-zero results), `+-105`, `+-1000`, `+-1e30`, `+-max
  float`, `+-inf`, quiet/signalling/payload NaNs; positive and negative
  magnitudes are covered for both the normal and split bands.
- Compared per case: return `s0` bits, continuation PC, final SP, callee-saved
  `r4-r11` and `d8-d15`, FPSCR (cumulative exception-flag bits 0-4 masked), the
  ordered helper log including the classifier input bits and every errno code,
  the errno cell, and detection of any write outside the private stack frame or
  the errno cell.
- Six compiled negative controls are detected: a changed reduction constant, a
  changed table index mask, the `-inf` special case, the range-error sign test,
  the classifier threshold, and the tiny-input constant.

Result: `All 54/54 differential cases PASSED.` and `All negative controls
detected.`

## Limits

- The errno helper `0x002A464E` and its `0x002C6840` address lookup are stubbed;
  the test only observes the value (`2`) it would store, not the real global.
- The `+inf` returns are produced from `0x70000000 * 0x70000000`.  The compiler
  may constant-fold that product, so the returned bits are exact but the
  candidate is not guaranteed to raise the FPSCR overflow flag in those paths.
  (The underflow paths do execute the pinned `0x002A462C` body.)
- The candidate uses the target's `n >> 2` arithmetic shift and C++ float
  rounding; this was validated bit-exactly on Unicorn's VFP model for the listed
  inputs, not on hardware.
- No caller composition, whole-binary promotion or runtime scenario is
  established.  The production caller `func_0014a998` already invokes the
  symbol through a `float (*)(float)` cast.
