# `0x00296F60` — H2 callback value getter

## Contract

The input `r0` is a zero-based selector. The helper loads the work pointer from `0x0044DEB8`, reads the word count at work `+0x1C`, and computes `index = count - selector - 1` using 32-bit arithmetic. It reads the type byte at work `+0x20+index`. There are no bounds checks; the supported domain is a mapped work object, nonempty count, and selector less than count.

| Type byte | Result |
| --- | --- |
| 0 or 4 | Raw word at work `+0x3C+4*index` |
| 1 | Read float at work `+0x3C+4*index`, convert with `VCVT.S32.F32` (truncate toward zero), return the signed result's raw 32-bit word |
| 2 | Read a word index from work `+0x3C+4*index`, then return raw word at `0x004C4744 + 4*word_index` |
| 3 | Read a word index from work `+0x3C+4*index`, read float at `0x004C4D44 + 4*word_index`, convert toward zero, return its raw signed 32-bit result |
| 5 or greater | Zero |

It does not write memory or preserve a normalized type. The original caller `0x00221168` issues an ARM `BL` at `0x002211C0` with selector zero. The getter returns the selected raw value as `r0`; `r1-r3` and VFP `s0` are caller-saved, while SP and `r4-r11` are preserved. The callback passes this result as the final helper's `r1` argument.

## Evidence

The typed implementation compiles to 156 bytes in the 164-byte span, with no relocations. The staged body stays inside the slot; IPS replay is exact. The repaired fresh offline run passed 109 direct cases across types 0–4 and unknown types, selectors 0–4 at both table boundaries, and finite float values within signed-32 conversion range, including all 48 combinations of types 1/3, four selector positions, and six values. It passed 24 compositions through original callback `0x00221168`, with the production getter real and the final helper controlled. The callback's selector call resolves to even ARM entry `0x00296F60`.

Two mutations were detected: changing the work value offset from `+0x3C` to `+0x40`, and using the work selector index instead of the stored word index for global table lookup. An additional out-of-mapping type-2 probe faults in the original (and candidate); it is reported as outside the supported domain, not semantic coverage.
