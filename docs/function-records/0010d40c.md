## Role and Behavior
- **Role:** Resets sound system runtime state, halts or fades active voices and streams, and reinitializes DSP/mixer parameters.
- **Details:**
  - Takes `(fade_duration)`.
  - Resets stream volume state `g_AsdSoundStream.field_00 = 0.0f`.
  - If `fade_duration > 0`, initiates fade-out transitions across active channels.
  - Iterates over all 16 mixer channels, clearing voice bindings, active flags, and DSP effects.
  - Resets global sound subsystem flags in `g_AsdSoundSystem.field_00` and `g_AsdSoundSystem.field_1204`.
  - Re-initializes DSP coefficients and audio hardware mixer bus.
