# `0x00151404` — type-1 title transition callback (experimental)

## Recovered contract

The entry is a hard-float callback with a GP context pointer in `r0`, then
`start`, `end`, and `sample` in `s0`, `s1`, and `s2`. The observed original
caller supplied `start=0.5`, `end=1.0`, and `sample=0.75`. The callback returns
its float in `s0`; that caller stores the result and immediately overwrites
`r0`, so incidental `r0` output is not part of the observed return contract.
The context pointer is unused by this callback body.

The callback computes `interval = end - start`. If the interval compares equal
to zero, it returns `start`. Otherwise it computes `delta = sample - start`.
The original uses `VCMPE(0, delta)` followed by `BLE`: unordered NaN flags take
the nonnegative/no-wrap branch. Only when that branch is not taken does it call
the original float helper at `0x002A337C` with `-delta / interval`, add one to
that helper's result, and adjust `delta` by that value times the interval. It
then calls original helper `0x0014D608(adjusted_delta, interval)` and adds
`start` to the returned `s0`.

The direct helper boundaries are preserved as `f32 (*)(f32)` and
`f32 (*)(f32, f32)`. Their implementations are not reconstructed here. The
original callback saves/restores `r4` and `d8-d9`; the candidate satisfies the
ARM callee-save contract for `r4-r11`, `d8-d15`, and `sp` in completed test
cases.

## Evidence and limits

- Static evidence: pinned original ARM at `0x00151404` through `0x00151464`,
  literal pool at `0x00151468`/`0x0015146C`, reached caller window, and helper
  entry disassembly. The report preserves helper-entry ABI arguments.
- Synthetic evidence: directed Unicorn runs compare original ARM and compiled
  candidate for zero interval, equal/below/inside/at/above samples, positive
  and negative intervals, a rounding-boundary sample, positive infinity, and
  quiet NaN. Ordinary completed cases match in `s0`, `fpscr`, direct-helper ABI
  arguments, callee-saved state, and data-memory effects. Two mutation controls
  demonstrate divergence for ordered C++ NaN branching and eliding the
  `0x002A337C` call.
- Positive infinity reaches the original exceptional indirect path
  `0x0014D6CC -> 0x002A464E`. Both executions fault at the same pinned PC due to
  the emulator's read-only text mapping. This is recorded as a matched domain
  limit, not a successful callback return or ABI pass.
- Runtime evidence: none. Static type-1 registration can select this address
  under a separate byte condition, but actual live callback selection remains
  unproven. No live title, rendering, visible UI, or gameplay equivalence is
  claimed.
