- **Details:**

  - Validates slot index `slot_idx < 16`. If `>= 16`, returns 0 immediately.

  - If `size > 0` and `data` is valid, attaches sequence payload or initializes stream reader.
  - Marks slot as active (`slot->field_00 |= 1`), updates active sequence count.
  - Publishes active sequence pointer to `g_AsdSoundSystem.field_1218`.
  - Returns 1 on success, 0 on failure.
