- **Details:**

    - Masked if `Camp_GetMainMenuId() == 6` and `!Camp_IsActorPlayer(*Camp_GetSelectedActorPtr())`.

    - Checks `work->skill_entries[scroll_offset + row].value`; if 0, skips the row.

    - Draws skill name with `UiFont_DrawText(2, 0xFF, ..., x, y, 0.28f, 0.0f, 1.0f)`:

      - Otherwise, obtains name via `Skill_GetNameString(entry.value)`.
    - Draws skill icon and count via `UiSkill_DrawItemIconAndCount`:
      - Item ID is 0 if `hide_names` is true, otherwise `static_cast<s16>(entry.id)`.
      - Priority `0xB5`.
    - Draws skill cost and info via `UiSkill_DrawSkillCostAndInfo(entry.value, ...)` at priority `0xB5`.

    - Selects cursor frame node: `0x421` if idle touch hold state (`touch_drag_state[0..2] == 0 && lr_state_left == 0 && lr_state_right == 0 && touch_hold_state >= 0`), else `0x420`.

    - Re-draws selected row's icon (`0x458`) and cost (`0x459`) at top priority `0xC9`.
