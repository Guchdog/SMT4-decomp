# Function Record: func_0014c5c0 (0x0014C5C0)

## Summary
- **Address:** `0x0014C5C0`
- **Size:** 480 bytes (original span `[0x0014C5C0, 0x0014C7A0)` including five
  literal-pool words at `0x0014C78C..0x0014C79C`)
- **File:** `src/engine/leaf_batch41_c.cpp`
- **Role:** Per-frame timing/statistics sampler. Adds the frame's 64-bit tick
  delta into a 64-bit total, scales the delta to a small float sample through
  two 64-bit division helpers and one int64-to-float helper, folds the sample
  into a running maximum/sum/101-bin histogram with a [0, 100] outlier counter,
  and optionally appends an 8-byte entry to a caller-owned record array.
- **Status:** Reconstructed as readable C++ and **semantically verified**
  against the pinned original. The candidate body is 468 bytes with six direct
  call relocations and no data relocations, so it is not byte-identical; the
  ledger row is `non_matching` and this record carries the semantic evidence.

  does in the original; `-0.0f` is neither negative nor above 100.
