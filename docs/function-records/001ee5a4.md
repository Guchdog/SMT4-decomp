# StatusDown_PopulateSkillList (0x001ee5a4)

## Summary
- **Address:** `0x001ee5a4`
- **Size:** 548 bytes
- **Domain:** UI / Status Down Screen (Bottom Screen Party Status)
- **Status:** Semantically verified (`non_matching` in ledger)
- **Source File:** `src/ui/status_down.cpp`
- **Differential Suite:** `tools/test_status_down_lists.py`

## Role and Behavior
- **Role:** Scans the global skill/item table and populates the bottom status screen skill list based on a passed skill acquisition bitfield, then sorts the list according to camp sort configuration.
- **Details:**
  - Resets `skill_count = 0` and `skill_total = 0`.
  - Zeroes `skill_entries[512]` via `AsdMem_Zero`.
  - Scans item table IDs `0..0x4FF` via `Battle_GetTalkEntry(i)`:
    - Filters entries requiring bit 0 of flags set and non-zero `skill_id`.
    - Checks bit `skill_id` in `skill_bitfield`: if set, appends entry `(id, skill_id)` into `skill_entries` and increments `skill_count`.
    - Increments `skill_total`.
  - Configures `skill_cursor` via `UiListCursor_Setup(&work->skill_cursor, work->skill_count, 11, 1, 0, 1)`.
  - Reads camp sort config at byte `0x15`:
    - If `sort_key == 1`: sorts by item/skill ID (descending if bit 7 set, else ascending).
    - If `sort_key == 0x21`: sorts by MP/HP skill cost (descending if bit 7 set, else ascending).
    - If `sort_key == 3`: sorts by skill name string order (descending if bit 7 set, else ascending).
  - Sets `needs_refresh = 1`.
