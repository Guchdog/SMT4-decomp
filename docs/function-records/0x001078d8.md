# `func_001078D8` — logical input counter refresh

## Reconstructed behavior

The typed C++ implementation in `src/engine/leaf_batch27_a.cpp` calls the
converted typed C++ `func_0011C5EC(handle, 0x004E3C28)`. It normalizes that helper's
result to 0 or 1 and writes the value to `0x004650A4`. It then processes exactly
31 rows from `0x004099C0`, updating counters at `0x004E3C58`.

For a nonzero first word in a row, the matching counter is cleared. For a zero
first word, availability false leaves the counter unchanged. With availability
true, the function tests the row's second-word mask against the same fixed state
word at `0x004E3C28`; a set bit increments the counter modulo 2^32 and a missing
bit clears it. The function is void. It does not advance the state-word pointer.

## Limits

The state reader's ring helper is controlled in its fixtures; the actual input
source, buffer population, physical mapping, refresh cadence, and scheduler
registration are not established. The caller's later `0x00108B10` service is stubbed during
composition. These results do not establish concurrent mutation, MMIO behavior,
or whole-title runtime behavior. The source's machine code differs from the
pinned original, so the ledger remains truthfully `non_matching` while semantic
evidence is reported separately.
