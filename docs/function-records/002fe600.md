# Function Record: ui_func_002fe600 (0x002fe600)

## Summary
- **Address:** `0x002fe600`
- **Size:** 628 bytes (`[0x002fe600, 0x002fe874)`): 152 ARM instructions
  `0x002fe600..0x002fe85f` plus the five-word literal pool
  `0x002fe860..0x002fe873`.
- **File:** `src/engine/leaf_batch45_a.cpp`
- **Role:** Builds a contiguous array of 32-byte effect/draw records from a
  catalog-selected descriptor. Each record carries the catalog key, the low
  byte of the catalog index, a grey channel derived from a group field, an
  accumulating vertical offset and two element indices.
- **Classification:** `non_matching` with semantic evidence. The compiled body
  is 720 bytes versus 628: Clang saves eight VFP registers instead of four,
  schedules the group arithmetic differently and splits the original
  `vmla`/`vmls` sequences, but the branch structure, helper calls, stored words
  and return value are the same. Verified by the differential runner below.

## Contract and Behavior

### Signature and ABI
```c
s32 ui_func_002fe600(OutputRecord* out, s32 capacity, const u8* source,
                     const CatalogSlot* catalog, s32 catalog_count);
```
- `r0` output record pointer, `r1` signed output capacity, `r2` source
  descriptor, `r3` catalog base, first stack word (`[entry_sp+0]`, reached as
  `[sp+0x68]` after the prologue) `catalog_count`.
- The original also re-reads `r3` from its stack home at `[sp+0x40]`; this is
  the same incoming catalog pointer.
- Prologue: `push {r0-r3,r4-r8,sb,sl,fp,lr}`, `vpush {d8-d11}`,
  `sub sp,#0x14`. All exits restore them; the final SP equals the entry SP.
- Return is the number of records written (`r7`); the early failures return 0.

## Control Flow

### Search phase (`0x2fe618..0x2fe65c`, `0x2fe7b8..0x2fe7c4`)
1. Read `source+0x18`; `<= 0` returns 0.
2. Read `catalog_count`; `<= 0` returns 0.
3. For `index = 0 .. catalog_count-1`, compare `*(s32*)(catalog + index*0x48 + 4)`
   with the key. Miss returns 0.
4. The found entry address is re-tested for zero (`adds`/`beq`); zero returns 0.
   This can only fire for a wrapping catalog base, but is preserved.
5. `written = 0`; `0x003df0d8(entry)` supplies the float scale (`s17`).

### Group loop (`0x2fe670..0x2fe858`)
- Read `source+0x1C`; `<= 0` returns 0 after the scale call.
- `index` in `[0, group_count)`; the count is reloaded at `0x2fe848` each
  iteration.
- Group pointer is `source + 0x28 + index*0x14`.
- For `index != 0`, the accumulator is initialised to `0.0f` and
  `accumulated_z -= group+0x08` before the group is processed.
- Per group precomputation:
  - `span_bits = (u32)field_04 * ((u32)repeat - 1)` (wrapping product);
    `span = (f32)(s32)span_bits`.
  - `grey = (u32)(field_0C * 255.0f)`; packed word as in the table above.
  - `denominator = (span + scale*(f32)repeat) * 0.1f`.
  - `offset = (field_10*scale)*0.05f - (field_10*denominator)*0.5f`.

### Element loop (`0x2fe720..0x2fe844`)
- Gate: `repeat = group+0x00`; `<= 0` skips to the next group.
- Continue while the signed element counter is below `group+0x00` (reloaded at
  `0x2fe820`).
- Break the element loop when `written >= capacity` (signed `bge`); the outer
  group loop then continues, so later groups are still scanned without writes.
- All record fields except `+0x04` are written unconditionally.
- `selector = (s8)(u8)catalog_index`:
  - `selector < 0` (catalog index 128..255): skip the whole unit block; `+0x04`
    keeps its previous memory value.
  - `selector >= 0`: `target = (s32)ui_func_00293ca8(catalog + selector*0x48, 0)`;
    then mode dispatch:
    - `0`: `+0x04 = 0`
    - `1`: `+0x04 = (u16)(ui_func_00297004(0, 4) << 2)`
    - `2`: `+0x04 = (u16)ui_func_00297004(0, target)`
    - other: `+0x04` left untouched
  - Clamp: `current = (s16)*(u16*)(out+4)`; when `current >= target` call
    `0x002c615c(current, target)` and store the **remainder** (r1 / high half of
    the u64 return) into `+0x04`.
- After each element: `offset += field_10 * (((f32)field_04 + scale) * 0.1f)`,
  `out += 0x20`, `written += 1`, element counter += 1.

- Compiles `src/engine/leaf_batch45_a.cpp` with

  symbol and resolves its five `R_ARM_CALL` relocations to the four original

- Per case compares returned r0, continuation PC, final SP, r4-r11, s16-s31,
  the ordered helper call log, the complete output/source/catalog pages and all
  writes outside the private stack.
- 84 structured cases cover: key `<= 0`, `catalog_count <= 0`, search miss,
  the computed-entry null exit, `group_count <= 0`, repeat 0/negative, capacity
  boundaries (`-1, 0, 1, 2, 3, 4, 0x7FFFFFFF`), catalog indices
  `0/3/127/128/129/200`, modes `-1,0,1,2,3,4`, mode-1 range endpoints, mode-2
  u16 truncation, targets `0`, `+-1`, fractional, NaN, infinities and 1e10,
  `current <`, `==` and `>=` target, grey values `0..2`, negative and NaN,

## Domain Limits
- `0x003DF0D8`, `0x00293CA8`, `0x00297004` and `0x002C615C` are deterministic
  stubs in the runner. Their internal table/RNG state and the real
  `__aeabi_idivmod` divide-by-zero path are not exercised. The stub models a
  zero divisor as `(0,0)`; both bodies call the same stub, so the differential
  comparison remains valid but does not prove the original library routine's
  divide-by-zero behavior.
- The original fuses `span + scale*repeat` with `vmla` and
  `offset - ...` with `vmls`; Clang emits split `vmul`/`vadd` sequences in the
  candidate. The 84 boundary cases and 600 random cases produced identical
  stored bits, including subnormal/NaN/Inf inputs, but a formal proof that the
  split sequences round identically for every float is not provided.
- The computed-entry null exit is only reachable with a wrapping catalog base;
  it is tested with `catalog = 0` and the key placed at address 4.
- Aliasing between the output array and the source/catalog fixtures is not
  tested; the runner keeps them in separate pages.
- FPSCR exception flags are not compared (the instruction schedules differ).
- Runtime integration (game rendering and consumers of the records) was not
  exercised; this record covers offline differential equivalence only.
