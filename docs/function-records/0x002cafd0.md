## ABI and observed state

The task callback receives one pointer-sized callback argument in r0 and ignores it; no meaningful input is consumed from that argument. The callback returns r0=0 on its observed normal return. It preserves r4-r11, SP, and d8-d15, saves/restores lr and d8, and uses a 0x5C-byte local formatting area. VFP registers participate in coordinate and font argument handling.

The callback reads the work pointer through global 0x0044E2D0. From the work object it reads state word +0x08, sprite pointer +0x5C (the position helpers read sprite fields +0x0C and +0x10), cursor object +0xE8 through cursor helpers, option words starting at +0x28, and signed touch-region halfwords +0x1C, +0x1E, +0x20, and +0x22. Row traversal starts at zero and repeats while the signed cursor row count is positive and the row index is below the current count. For absolute list indices below 3 under an unsigned comparison, it reads table 0x3A, subtable 1 payload descriptors at payload + index*0x96, then formats into the local buffer. Original `cmp r7,#3; bhs` skips TBB formatting for signed negative indices as well as indices 3 or greater.

The function does not directly write TitleConfigWork or g_ConfigBytes (0x0044E0F8). It reads the renderer root pointer through global 0x0044EA00, then writes a 32-bit render value to cache record +8+4*index. If cache byte +0x18 is nonzero or the prior record word differs, it calls the function pointer at cache +0x1C with the new render value in r0, then clears cache byte +0x18. Renderer helper internals and any callback side effects are outside the direct body contract.

## Reconstructed behavior and dependencies

The candidate retains the panel and sprite draw calls, row selection/color branch, layout lookup order, cursor calls, option-dependent node lookup, guarded table formatting, font calls, touch codes 1/2/6, and renderer cache updates and conditional indirect callback. ## Evidence and limits

The differential runner compiled the ARM candidate with Clang 23.1.3 and compared it with the pinned original in Unicorn. It compared ordered helper/callback traces and arguments, work/config/cache bytes, return/fault/PC state, and preserved ABI state. All 46 directed cases passed, including nonpositive row counts, active selected rows 0/1/2, response codes 1/2/6 on each of four configured handles, cache dirty/matching paths, and a wrong-stride negative control that was detected. The signedness-fix run adds absolute-index -1 and 3 cases; in both original and candidate, the report records zero TBB subtable/payload calls and no formatted descriptor indices.

This establishes behavior only for the mocked callback scenarios. Explicit absolute-index -1 and 3 fixtures verify that the unsigned guard skips TBB access while option reads remain inside the allocated work object; this does not establish that either cursor state is caller-reachable. It also does not establish initializer-created caller state, actual table contents, helper semantics, scheduler ordering, calc/draw concurrency, persistent config behavior, Azahar behavior, or whole-menu equivalence. See docs/agent-work/h2-draw-candidate.md and the signedness-fix run report for the case matrix and commands.
