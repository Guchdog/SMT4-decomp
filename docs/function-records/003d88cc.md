# Function Record: func_003d88cc (0x003d88cc)

## Summary
- **Address:** `0x003d88cc`
- **Size:** 404 bytes (original span `[0x003d88cc, 0x003d8a60)`): 98 ARM
  instructions `0x003d88cc..0x003d8a50` plus the three-word literal pool at
  `0x003d8a54` (`+0.0f`, `0x004342c8`, `0x00493518`).
- **File:** `src/engine/leaf_batch36_b.cpp`
- **Role:** Restart/reset half of the result-panel animation state. It clears a
  pending bit, optionally bails out on a block bit, snapshots the current
  animation samples into the interpolation bases (including two `.bss` tracks),
  clears the matching targets and the phase counters, publishes one word to a
  global slot, and arms the animation by setting its timer, limit and started
  flag. It is a leaf: no direct or indirect calls.
- **Classification:** `non_matching` with semantic evidence. The compiled body
  is 388 bytes versus the 404-byte original. The difference is code generation,
  not behaviour: the candidate places the early return before saving
  `r4-r8`, interleaves the independent copies, materialises the zero stores as
  integer `str` instead of `vstr`, and needs two literal words. Return `r0`,
  continuation PC, SP, `r4-r11`, the exact store set and the complete observable
  memory are identical in the differential suite.

## Contract and Behavior

### Signature and ABI
```c
extern "C" u32 func_003d88cc(u8* object, u32 unused, s32 value);
// r0 = object, r1 is never read, r2 is stored verbatim at object+0x680.
```
- `object` is the animation work block. Its address is the value of the global
  pointer at `0x004342C8` in both static callers.
- The prologue is `push {r4,r5,r6,r7}`; the epilogue is
  `pop {r4,r5,r6,r7}; bx lr`. There is no stack frame, no stack argument and no
  callee-saved VFP register.
- The body is a leaf. The only VFP instructions are `vldr`/`vstr` of the
  `+0.0f` literal at `0x003d8a54`; there is no floating-point arithmetic.
- **Return value:** on the blocked path the original leaves `r0 = object`; on
  the completed path `ldr r0,[r0,#0x634]; orr r0,r0,#0x10; str r0,[ip]` leaves
  `r0 = (flags | 0x10)`. Neither caller reads `r0`, but the reconstruction
  returns that same word and the differential suite compares it on both paths.

### Code-generation note
- The candidate's only material differences are scheduling and instruction
  selection. The early path performs the flag store and `bxne lr` before the
  `push`, so the blocked path never writes the stack; SP is unchanged either
  way.
- Zero-valued fields are emitted as `str` of a zero integer rather than `vstr`
  of `+0.0f`. The stored bits, width and address are identical.
- The final `+0x634` re-read is scheduled before the last `.bss` target clears;
  nothing in between touches `+0x634`, so the result is the same in a
  single-threaded execution.

## Unresolved Calls and Limits
- There are no direct or indirect calls, so no helper contract is unresolved.
  The differential suite's call log is necessarily empty.
- The object type is a local partial view. The phase fields (`+0x79c..+0x840`,
  `+0x5ac..+0x5f8`, `+0x658..+0x6ec`, `+0x794..+0x7d4`) are named by offset;
  their engine-level meaning and the concrete `ResultWork` layout are not
  established. The `+0x634`/`+0x680`/`+0x684` roles are inferred from this body
  and the sibling update at `0x003d58c4`.
- The semantic role of the `r2` value is not proven independently; it is stored
  verbatim at `+0x680`, which `0x003d58c4` later reads as a signed denominator.
  The test covers `0`, `±1`, `INT_MIN`, `INT_MAX` and `0xffffffff`.
- The global slot `0x004342f4` and scalar `0x004342f8` are only characterised by
  this routine's writes. Their consumers were not traced, and the
  `ResultAnimConfig` view in `include/ui/ui_scene_extras.h` stops at `+0x24`.
- Single-threaded execution with a valid non-null object was modelled. A null
  object faults in both original and candidate. Concurrent writes to `+0x634`
  between the prologue clear and the final re-read are outside the model.
- No caller-composition, game-engine or whole-game runtime equivalence is
  claimed. No emulator or canonical full build was run.
