# `0x0028686C` — H2 callback context getter

## Contract

The one-word input in `r0` is ignored. The helper loads the pointer at `0x0044DEB8` (`0x0044DE98 + 0x20`), then returns the raw 32-bit word at that pointer plus `0xC0`. The pinned ARM body is `LDR literal 0x0044DE98; LDR [r0,#0x20]; LDR [r0,#0xC0]; BX LR`. It performs no writes, has no pointer checks, and propagates ordinary load faults for invalid mappings. The typed implementation uses volatile word accesses to preserve the observed read sequence.

The caller `0x00221168` passes its current `r0` (the pointer read from `[0x0043E188+4]`) even though the getter ignores it. The callback saves this raw getter result and later passes it as `r0` to `0x00286928`; the callback returns the final helper's raw `r0`.

The original callback's `BL` at `0x002211B4` resolves to the getter's even ARM entry `0x0028686C`.
