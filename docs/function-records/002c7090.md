## Contract and Behavior

### Signature and ABI
```c

```
- Only `r0` is live on entry; `r1-r3` and `s0` are dead. The routine is called
  with no stack arguments.
- Callee-saved `r4-r8`, `sb` (`r9`) and `sl` (`r10`) are preserved by
  `push {r4, r5, r6, r7, r8, sb, sl, lr}` / `pop {..., pc}`. `sl` is pushed but
  never read.
- r0 on the early-exit path is explicitly set to 0 (`mov r0, #0`); on the normal
  path the last value loaded into r0 is `state->value_28` (`ldr r0, [r5, #0x28]`
  immediately before `str r0, [r4, #0x10]`), so the C++ returns that word.
- `state = owner->state_24` is dereferenced without a null check; a null
  `owner` or `state` faults exactly as in the original.

### Control flow and memory effects
1. `count = state->count_b8` (signed word) is always read. When `count != 0`
   the routine reads `frame = owner->frame_1c`; a signed `frame > count` test
   (ARM `cmp r7, r8` / `bgt`) then clears display byte `+0x0F` (the top byte of
   `color_0c`) and returns 0 immediately, before any helper call. A zero count
   leaves `frame = 0` and never touches `owner + 0x1C`.
2. `sample = func_00269768(state + 0x8C, frame, count)` returns a float in `s0`;
   that value drives the geometry. The callee's `r0` return is dead.
3. `state->flag_bc != 0` selects the default geometry:
   - `span_x_04 = 200.0f`, `span_y_08 = 120.0f`;
   - `min_x_14 = 200.0f - sample`, `min_y_18 = 120.0f - sample`;
   - `max_x_1c = 200.0f + sample`, `max_y_20 = 120.0f + sample`.
4. `state->flag_bc == 0` selects the owner-driven geometry:
   - the four raw words at `owner + 0x00..0x0C` are stored unchanged to
     `0x004EA81C + 0x100` (words, `stm`);
   - `radius = ui_func_001e1bb0(0x004EA81C + 0x100, owner->scale_14 * sample)`
     runs with the product in `s0` and returns the radius in `s0`;
   - `span_x_04`/`span_y_08` take components 0/1 read back from the block and
     the four bounds are `component0 - radius`, `component1 - radius`,
     `component0 + radius`, `component1 + radius`.
5. The merge point calls `func_002698f4(state, state + 0x24, frame, count)`,
   which returns a packed colour in `r0`.
6. `func_00257614(owner->color_10)` converts that colour into four normalized
   floats at `0x004EA81C + 0x100`; the four words are then copied to
   `0x004EA81C + 0x110` (the "previous" vector). `func_00257614(sampled)` runs
   on the sampled colour and each current component is multiplied in place by
   the matching previous component.
7. Each product is scaled by `255.0f`, truncated with `vcvt.u32.f32`, and the
   low bytes are written in reverse order: `color_0c[0] = component3`,
   `[1] = component2`, `[2] = component1`, `[3] = component0`.
8. `display->value_10 = state->value_28` and that word is returned.

All four callees are direct (`bl`); there is no indirect call and no loop.

## Verification Evidence
- Differential runner: `tools/test_leaf_002c7090.py` (Unicorn ARM11 MPCORE,
  VFP enabled via `C1_C0_2 = 0x00F00000` and `FPEXC.EN`).
- The original `extracted/exefs/code.bin` body is compared against the compiled
  `func_002c7090` with all four `R_ARM_CALL` relocations retargeted to
  deterministic stubs at the original addresses.
- 63/63 differential cases pass. They cover: count zero/positive/negative and
  both 32-bit signed extremes; `frame` below, equal to and above `count`
  (including the `+/-0x80000000` signed boundaries); both `flag_bc` variants;
  zero, positive and negative samples; owner scale `0.0`, positive, negative
  and extreme magnitudes; four distinct source-word patterns; and colour bytes
  `0x00/0x7F/0xFF`.
- Each case compares r0, continuation PC (the trap), final SP, callee-saved
  r4-r11, the ordered call log (register arguments, the `s0` float argument and
  the four raw block words seen by `0x001E1BB0`), the exact floats written by
  each `0x00257614` stub, the owner page, the whole state page and the
  `0x004EA81C` block page, and rejects writes outside the private stack and
  fixture pages.
- Seven negative controls are detected: default span 200 -> 201, signed `>` ->
  `>=`, flag selector inverted, colour-byte order swapped, one source word
  redirected, the scale argument altered, and the value word incremented.
