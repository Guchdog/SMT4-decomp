# Function Record: func_0013fa8c (0x0013fa8c)

## Summary
- **Address:** `0x0013fa8c`
- **Size:** 524 bytes (122 ARM instructions plus an 8-word literal pool)
- **File:** `src/engine/leaf_batch34_c.cpp`
- **Role:** Emit a fixed six-word header plus one six-word block per counted unit
  into a caller-provided bump buffer, then advance that arena's cursor by the
  emitted size.
- **Status:** Semantically equivalent C++ (`non_matching`). Verified with a
  Unicorn ARM differential test across 36 cases plus five negative controls.

## Contract and Behavior
- **Signature:** `extern "C" u32 func_0013fa8c(void* arena, const void* desc)`
  - `r0` (`arena`) is a header whose `+0x04` word is the inclusive end of the
    free region and whose `+0x08` word is the write cursor.
  - `r1` (`desc`) is a descriptor: signed entry count at `+0x38`, and a
    self-relative displacement at `+0x3C` whose base is `desc + 0x3C`.
  - `r2`/`r3` are not read. The only caller is `0x0012DFD0`
    (`bl 0x0013fa8c` at `0x0012DFD0`), which ignores the return value and
    immediately reloads `r0`.
- **Destination selection:** `dst = [arena+0x08]`; when that cursor is zero the
  shared global arena is used instead (`dst = [0x004652A0]`).
- **Entry scan (`0x0013FAC0..0x0013FB60`):** the count is loaded once and tested
  signed (`<= 0` skips the scan). For `i` in `[0, count)`:
  - `slot = (desc + 0x3C + [desc+0x3C]) + 4*i` with the usual null fallback:
    a zero displacement sets the pointer to 0, so the listing then reads
    address `4*i`.
  - `entry = slot + [slot]` (again 0 when `[slot]` is zero).
  - `flags = [entry+0x08]`.
  - `flags & 1`: add one to the counted total, emit nothing.
  - otherwise: emit the two words `0` and
    `0x000F0000 | ((3*k + 0x205) & 0xFFFF)` (`k` = pairs emitted so far), then
    add the object's `+0x28` word when `flags & 2`, else one, to the total.
    `k` increments only for emitted pairs.
- **Header (`0x0013FB64..0x0013FBC0`):** six words at the next free index:
  `0x76543210`, `0x801F02BB`, `0x0000BA98`, `0`, `packed`, `0x000F0202`, where
  `packed = (0xFFFE0000 + ((1 << total) << 16)) | ((total << 28) + 0xF0000000)`.
  `1 << total` is an ARM register shift: the amount is `total & 0xFF`, and 32
  or more shifts out every bit (the middle term then contributes nothing). The
  right-hand term is the ARM encoding `(total << 28) + 0xF0000000`, which the
  compiler may fold to `(total - 1) << 28`; both are identical modulo 2^32.
- **Block table (`0x0013FBC4..0x0013FC08`):** guarded by the signed test
  `total - 1 > 0`; `total - 1` blocks of six words follow. Block `n` (1-based)
  is `{n, 0x803F0232, 0, 0, 0, 0}`.
- **Commit (`0x0013FC0C..0x0013FC74`):** `size = next_index * 4`. Every word is
  written before the bounds test, so a rejected allocation still leaves all
  emitted data in memory. Then:
  - cursor path: re-read `[arena+0x08]`; if `cursor + size <= [arena+0x04]`
    (unsigned), store `cursor + size`.
  - fallback path (cursor was zero): re-read `[0x004652A0]`; if
    `[0x004652A0] + size <= [0x004652A4]` (unsigned), store the sum back.
- **Return:** `size` in bytes (`next_index << 2`), independent of whether the
  arena accepted the allocation.
- **Control flow:** two loops only — the signed entry scan and the signed block
  loop. No direct or indirect calls, no stack locals; the 32-byte frame holds
  only the saved `r4-r11`.
- **Cross-check:** the sibling size helpers `0x0013FC98` and `0x0013FD0C` compute
  the same total (`4 * (2*pairs + 6*total)`) from the same `+0x38/+0x3C/+0x08/
  +0x28` fields, which confirms the field interpretation used here.

## Unresolved Limits
- There are no helper calls, so nothing is stubbed; every word this routine
  produces is exercised directly.
- A zero `+0x3C` displacement, a zero array word, or a null destination cursor
  makes the original dereference address 0/`4*i`/8 and fault. The C++ follows
  the same 32-bit addresses instead of assuming a valid pointer, but that fault
  path is not part of the tested contract (the fixture pages are all mapped).
- The semantic meaning of the emitted words (they look like instruction/register
  descriptors) is not claimed; only their values, order and widths are.
- The two arenas are plain cursor/limit pairs here; no other fields of the
  caller's arena object or descriptor are read.
- No emulator or whole-game runtime comparison was run for this isolated
  candidate.
