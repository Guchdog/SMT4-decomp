## Role and Behavior
- **Role:** Sorts the bottom status screen item entries array using the active camp item sort mode and direction.
- **Details:**
  - Reads camp sort configuration from `Camp_GetSortConfig()`, examining byte `0x16`.
  - Determines sort direction: bit 7 non-zero indicates descending sort order.
  - Switches on `sort_key = item_sort & 0x7F`:
    - `sort_key == 1`: sorts by item ID (`StatusDown_ItemSortByIdDesc` / `StatusDown_ItemSortByIdAsc`).
    - `sort_key == 8`: sorts by item type/category (`StatusDown_ItemSortByTypeDesc` / `StatusDown_ItemSortByTypeAsc`).
    - `sort_key == 2`: sorts by item count/quantity (`ItemSort_ByCountDesc` / `ItemSort_ByCountAsc`).
    - `sort_key == 3`: sorts by item name string order (`ItemSort_ByNameDesc` / `ItemSort_ByNameAsc`).
