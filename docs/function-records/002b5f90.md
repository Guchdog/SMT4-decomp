## Role and Behavior
- **Role:** Implements 64-bit integer division / scaling by multiplying a 64-bit dividend pointer with a 64-bit constant magic multiplier, taking the high 64 bits, shifting arithmetically right by `shift`, and applying symmetric round-towards-zero correction for negative numbers.
- **Details:**

  - Multiplies `a` by `mul` to obtain the upper 64 bits of the 128-bit product (`mul_high_s64`).

  - If `a < 0`, adds 1 to correct arithmetic right shift to round towards zero.
  - Returns the 64-bit scaled integer in `r0:r1`.
