# `func_001285c4` — H2 input calibration clamp

## Reconstructed behavior

The production function is typed C++ in `src/engine/leaf_batch11_b.cpp`. Given
an aligned calibration block, it clamps signed halfwords at offsets `0` and `2`
to minimums `40` and `36`, then clamps signed halfwords at offsets `6`, `8`, and
`0xA` to a maximum of `145`. It leaves offset `4` and all other bytes unchanged.
The function returns no value and makes no calls. A single ARM instruction
materializes the shared upper bound so the compiled body stays within its
76-byte original slot; the comparisons, branches, and stores are C++.

## Limits

The tests use valid, disjoint synthetic ordinary RAM and a controlled ring
reader. They support the clamp semantics and this caller composition; they do
not establish physical input provenance, freshness, scheduling, device/MMIO
behavior, malformed pointers, aliasing, runtime reachability, or whole-title
behavior. The ledger classification is `non_matching` because candidate bytes
differ from the original.
