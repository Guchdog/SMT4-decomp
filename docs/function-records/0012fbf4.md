## Computations
- `min4 = 4.888000011444092f` (0x409C6A7F) is a lower clamp. The converted `+0x0C` and
  `+0x14` values are compared against it through the signed ordering of their IEEE-754 bit
  patterns (`cmp`/`vcvtgt`), so any value not greater than 4.888f is replaced by 4.888f.
- `slot = (u32)(clamped * 0.20458264648914337f)` (0x3E517E1D), stored as `slot * 160`
  (5 slots of 32 words) with a zero companion word.
- `scale = ((f32)(u32)self[+0x10] * 0.001f) * 32728.0f` (0x3A83126F, 0x46FFB000); the two
  multiplications are separate single-precision steps.
- Loop `i = 0, 1`: `+0xBC+4i = 0`; `exp = ((f32)(s32)self[+0xB4+4i] * -3.0f) / scale`;
  `result = powf(10.0f, exp)`; `+0xC4+4i = (s32)(result * 128.0f)`.
- `ratio = self[+0x1C]`; if the signed bit pattern is greater than 0x3F733333 (0.95f) the
  value is replaced by 0.95f. Negative values therefore never clamp.
- `mirror = self[+0x2D] == 1`:
  - direct: `+0xF0 = (s32)((1.0f - ratio) * 128.0f)`, `+0xF4 = (s32)(ratio * 128.0f)`
  - mirrored: `+0xF0 = (s32)((ratio - 1.0f) * 128.0f)`, `+0xF4 = (s32)(ratio * -128.0f)`

## Differential Evidence
`tools/test_leaf_0012fbf4.py` compiles this translation unit with the project ARMv6K
freestanding settings and compares the pinned original bytes (`extracted/exefs/code.bin`)
against the candidate in Unicorn.

- Both helpers are stubbed with deterministic behaviour: `powf` logs the exact `s0`/`s1`
  bit patterns and returns a value keyed on the exponent (including out-of-range results
  for a zero exponent and class-preserving infinity/NaN); the zero-fill stub logs the
  destination and length and performs the fill.
- Compared per run: ordered call log, `r0`, PC (trap address), SP, the complete `self`
  buffer (0x400 bytes), the 64 KiB fill window, the untouched stack above the entry SP,
  callee-saved `r4-r11`, and `d8-d15`.
- 18 fixture cases cover: baseline, both clamp boundaries (0 and 0xFFFFFFFF counts), a
  zero scale denominator, signed `+0xB4` pair values, exactly-0.95 and one-ulp-above ratio,
  negative ratio, negative zero, +100.0 ratio, mirror selector 1 and not-1, inf/NaN float
  fields, zero fill length, null fill pointer, and an out-of-window fill pointer.
- A compiled negative control relocates the 0.95f clamp literal to 0.9375f; the harness
  detects the resulting semantic difference in 3 cases.

Command: `python tools/test_leaf_0012fbf4.py` — 18/18 cases plus the negative control pass.

## Limitations
- The differential harness stubs `powf`; the real 1908-byte helper body is not
  differentially validated here beyond its argument/return ABI.
- Synthetic fixtures supply the object fields; real object initialization, the true
  zero-fill destination/length contents, and the caller's subsequent use of the written
  fields are not runtime-validated. No emulator or integrated scenario was run.
- Field semantics beyond the observed arithmetic (for example the meaning of the
  pursuit slots and the 0.95f ratio) are not named beyond the ARM evidence.
