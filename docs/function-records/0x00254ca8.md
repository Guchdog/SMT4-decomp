# `0x00254CA8` — logical query and special-axis gate

The original 840-byte ARM service is expressed as typed C++ in `src/engine/leaf_batch45_b.cpp`. The compiled body is 640 bytes with 18 calls to the original logical-query, axis-reader, and angle helpers. Its exact mode ordering, ID precedence, repeated calibration queries, VFP angle conversion, and result suppression are documented in the [static contract](../agent-work/h2-00254ca8-contract.md).

Run005 passed 76 comparable direct original-versus-candidate cases. Three compositions also passed through the original `0x001FF3C4` axis mover for initialized H2 cursor scenarios. A wrong-helper-target control was detected, the slot IPS roundtrips, and the full ARMv6K build passed 204/204 TUs. The direct suite compares return, ordered helper IDs/results, global state, SP, and callee-saved registers; it uses deterministic helper stubs and finite, explicitly written sample outputs. Thirty-six cases differed only in FPSCR N/Z condition bits, which AAPCS32 does not require a public function to preserve.

**Unresolved supported-domain limit:** `0x0027FBC8` can return without writing its output floats, while the original caller ignores the status and reads old stack values. The candidate locals remain uninitialized, which is not portable defined C++; the differential explicitly excludes this case, and no evidence proves that real H2 avoids it. The ledger is `non_matching` to reflect the changed bytes, not a claim that this domain is semantically supported. Independent review accepted only the written-output domain. NaN/Inf, unusual FPSCR flags, physical input mapping, and live H2 scheduling also remain unresolved. See the [offline integration report](../agent-work/h2-00254ca8-integration.md) and [independent review](../agent-work/h2-00254ca8-independent-review.md).
