# `func_0013b8f8` — selector-1 signed deadzone normalizer

## Reconstructed behavior

The typed implementation accepts output halfword pointers, signed 32-bit
samples, and signed calibration values A/B. For each coordinate, the negative
branch computes a 32-bit wrapped negation, compares it signed against A, and
conditionally adds A to the original coordinate; the nonnegative branch
conditionally subtracts A. It forms wrapped `U²+V²` and `F²`, where
`F=low32(B-A)`. If signed `F² > R`, it stores low halfwords U then V directly.
Otherwise it follows the original scaled-radius/Newton estimate and calls the
original signed divider `0x002C615C` for the estimate and both scaled
coordinates. It preserves 32-bit product/shift wrap, low-halfword quotient
stores, and returns the sign-extended low halfword of F in `r0`.

The reader supplies sign-extended halfword samples, so caller input `-32768`
reaches the negative branch as `0xFFFF8000`; `RSB #0` yields `+32768`. Only a
direct signed 32-bit `INT32_MIN` input wraps to `0x80000000`. The implementation
and tests preserve both cases.

## Limits

Evidence covers valid, disjoint synthetic ordinary RAM and a controlled
`0x0012A758` ring-reader seam. Original divider `0x002C615C` remains a
dependency. Pointer aliasing, malformed pointers, MMIO, concurrent mutation,
hardware input provenance, and whole-title runtime behavior are not
established. Signed reinterpretation of wrapped bits and arithmetic right shift
are verified for the pinned ARM target/compiler, not claimed as
host-independent C++ semantics.
