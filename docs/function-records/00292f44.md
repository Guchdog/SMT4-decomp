## Role and Behavior
- **Role:** Changes the active display mode of the bottom status screen, updating panel animations, clearing touch regions, and transitioning sub-states.
- **Details:**
  - If `work->active_mode == mode`, exits early without changes.
  - Updates `prev_active_mode = active_mode` and sets `active_mode = mode`.
  - Checks transition direction from `Camp_GetTransitionDir()`:
    - If negative, sets sprite animation index 3 mode 0 (`UiAnimSprite_SetAnim(&work->panel_sprites[0], 3, 0)`).
    - Else if positive, sets sprite animation index 2 mode 0 (`UiAnimSprite_SetAnim(&work->panel_sprites[0], 2, 0)`).
  - Unregisters all active touch regions via `UiTouch_UnregisterLastRegion()`, zeroes `registered_touch_count`, and fills `slot_touch_handles` with `0xFFFFFFFF`.
  - Sets `state_timer = 0`, `prev_state = state`, and `state = 2`.
  - Maps display mode to sub-state:
    - Mode 0 -> `sub_state = 0`
    - Mode 1 -> `sub_state = 3`
    - Mode 2 -> `sub_state = 0x10`
    - Mode 3 -> `sub_state = 0x11`
    - Mode 4 -> `sub_state = 0x13`
    - Mode 5 -> `sub_state = 0x15`
  - Sets camp screen fade color to `0x323232FF` via `Camp_SetFadeColor(0, 0x323232FF)`.
