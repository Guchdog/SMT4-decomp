# `0x002C00D4` — single-threaded test-and-set flag

## Contract

Pinned US ARM image `code.bin` (SHA-256
`1f98884fe997af22e032a14c51a46c872b05b0e079a0f29e307b0e059cfaa558`) contains
a 20-byte ledger span beginning at `0x002C00D4`. The executable Thumb body is
18 bytes and returns at `0x002C00E4`; the ledger-final `0xFFFF` halfword at
`0x002C00E6` is not reached. It loads one 32-bit word through `r0`. If nonzero,
it returns `r0=0` without writing. If zero, it stores `1` to that word and
returns `r0=1`. The function uses no stack and changes no callee-saved GP or
VFP registers. It is a non-atomic ordinary load/conditional store; no atomicity
or concurrent test-and-set guarantee is supported.

## Caller evidence

Pinned ARM callers at `0x001099B4`, `0x001F6948`, and `0x0036C380` use `BLX`
to this Thumb entry, then compare `r0` with zero to gate one-time sound,
effect-matrix, and UI-command initialization respectively. This supports the
return polarity as a first-writer/first-initializer decision in those observed
single-threaded contexts, not as a synchronization primitive.
