# `0x00297704` — forward an asynchronous table-load request

## Recovered behavior

The wrapper receives a name pointer in `r0`, output/status pointer in `r1`, flags in `r2`, and an unused input word in `r3`. It calls the original `AsdLoadFile_func_002ae6c8` (`0x002AE6C8`) with `(name, output, flags, nullptr, scale-bits=0, size=4)`. The loader call uses the legacy base AAPCS stack layout: the fifth and sixth raw words are `[sp]=0` and `[sp+4]=4`. The wrapper returns the callee's raw `r0` unchanged.

The actual TitleConfig initializer calls it twice: `("camp/config.bf", work+0x14C, 0)` and `("camp/config.mbm", work+0x150, 0)`. These are request-output slots; the wrapper does not make the asynchronous request complete synchronously.

## C++ reconstruction and evidence

The typed implementation is in [leaf_batch18_b.cpp](../../src/engine/leaf_batch18_b.cpp). The outgoing loader declaration uses `pcs("aapcs")` because the pinned naked loader consumes the raw scale and size words from the stack. The compiled body is 24/32 bytes with one `R_ARM_CALL` to even ARM entry `0x002AE6C8`. The bytes differ, so the ledger is `non_matching`.

The offline runner hooks the original loader entry and compares its register and stack arguments, SP alignment, wrapper return, preserved `r4-r11`/`d8-d15`, and output memory. The coordinator run passed 34 direct wrapper cases and the exact two-call TitleConfig slice; a size-word mutation was detected. Independent review passed 66 fresh direct cases and the same caller composition, confirmed the even ARM target, slot-only IPS replay and `non_matching` label, and detected the same size mutation. The full ARMv6K build passed all 204 translation units. The downstream hook returns a controlled value and does not model real loading or request completion.

## Limits

Evidence is limited to valid mapped names and output slots with the loader intercepted at entry. It establishes forwarding and raw return, not path resolution, async queue mutation, completion timing, failure behavior, loaded asset contents, resource lifetime, or initializer readiness. Runtime reachability and full H2 lifecycle remain unverified. Condition flags and downstream loader effects are outside the tested contract.

See the [coordinator report](../agent-work/h2-297704-wrapper-conversion.md) and [independent review](../agent-work/h2-297704-wrapper-independent-review.md).
