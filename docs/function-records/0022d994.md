## Limits
- Fixtures are synthetic: `self`, anchor records, size records, the overlay
  object and helper return values are not captured game data.
- `0x2BF6C8`, `0x2BF710`, `0x230F18`, `0x231D60`, `0x2313EC`, `0x2BEF7C`,
  `0x2BEF70` and the overlay callback are stubbed; no real layout lookup,
  rendering, clipping or overlay-stack state is exercised.
- `0x2BF6C8`'s id→record mapping (its 125-entry/20-byte layout) is not modeled;
  the stub returns a deterministic synthetic record per call.
- The overlay `depth` index is used without a bounds check, matching the
  original; the differential fixtures only cover in-range depths.
- No caller-composition, whole-game or runtime equivalence is claimed.
