# `0x002BF9F0` — preview animation helper

Status: experimental readable candidate; not integrated or independently
reviewed. The pinned ARM contract is recorded in
[`h1-preview-helper-contract.md`](../agent-work/h1-preview-helper-contract.md).

The candidate in `experiments/semantic_equivalence/h1_preview_helper_candidate.cpp`
uses an opaque byte pointer and explicitly models the fields and branches
supported by the pinned body. It preserves the nine direct call sites across
the five external dependencies: two animation calls to `0x002BDAC0`, four
interpolation calls to `0x002C615C`, and one each to `0x002B1FC0`, `0x002B1DFC`,
and `0x002B1C8C`. The body returns 1 on its null / signed early gate; otherwise
it executes the common tail, writes `+0x85`, computes `+0x8A` from `+0x86..+0x89`,
and returns that signed byte.

The isolated ARM differential passed 13 synthetic fixture cases against the
pinned original body, with all five external callees replaced by named stubs.
The interpolation stub returns signed `delta / duration` (zero for duration
zero); the other stubs return zero and do not model callee side effects. The
fixtures use valid row and sequence storage, but do not prove the H1
`scene+0xD74` object lifecycle, real pointer/index validity, call bindings,
callback timing, caller behavior, or runtime behavior. See
[`h1-preview-helper-candidate.md`](../agent-work/h1-preview-helper-candidate.md)
and its private report under `build/agent-work/H1-semantic/` for exact hashes,
commands, corrected counterexamples, and limitations.

This is candidate evidence only. Promotion requires independent review and a
separate caller/lifecycle contract; no production source was changed.
