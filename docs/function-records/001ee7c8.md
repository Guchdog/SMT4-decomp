# StatusDown_PopulateItemList (0x001ee7c8)

## Summary
- **Address:** `0x001ee7c8`
- **Size:** 384 bytes
- **Domain:** UI / Status Down Screen (Bottom Screen Party Status)
- **Status:** Semantically verified (`non_matching` in ledger)

- **Differential Suite:** `tools/test_status_down_lists.py`

## Role and Behavior
- **Role:** Scans the global item table and populates the bottom status screen inventory list using current item quantities, clamps saved grid cursor coordinates, and sorts items.
- **Details:**
  - Resets `item_count = 0` and `item_nonzero_count = 0`.
  - Zeroes `item_entries[1280]` via `AsdMem_Zero`.
  - Scans item table IDs `0..0x4FF` via `Battle_GetTalkEntry(i)`:
    - Filters entries requiring bit 0 of flags set and non-zero quantity in `item_counts`.
    - Appends entry `(item_id, qty)` into `item_entries`, increments `item_nonzero_count`, and increments `item_count`.
  - Configures 4-column item grid cursor via `UiListCursor_Setup(&work->item_cursor, work->item_count, 9, 4, 1, 1)`.
  - Clamps or preserves saved grid cursor position (`item_saved_row`, `item_saved_col`) within valid item bounds, setting the selected row and column on `item_cursor`.
  - Calls `StatusDown_SortItemList()` to sort the item entries according to sort settings.
  - Sets `needs_refresh = 1`.
