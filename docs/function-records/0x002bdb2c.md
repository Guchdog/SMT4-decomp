# `0x002BDB2C` — initialize a TitleConfig sprite node

## Recovered behavior

The helper accepts a writable 0x8C-byte sprite node in `r0`, a selector in `r1`, an index in `r2`, a readable 0x20-byte group descriptor in `r3`, a 32-bit panel value at entry `[sp]`, and a float scale in `s0`. It clears the node through original `AsdMem_Zero` (`0x002C4B30`), then writes the selector, index, `0xFFFFFFFF`, scale, three unit floats, the low 16 bits of the panel, the group pointer, five descriptor words from group offsets `0x0C..0x1C`, and five one-byte flags at node offsets `0x86..0x8A`. The raw return is `sprite + 0x8C`, inherited from the clear helper's incremented `r0`.

The actual `titleConfig_func_002f4ca0` caller supplies `(work+0x5C, 0x2F, 0, work+0x3C, 0xC9, 1.0f)`. Its group and sprite are adjacent and non-overlapping. The caller ignores the return.

## C++ reconstruction and evidence

The typed implementation is in [leaf_batch30_c.cpp](../../src/engine/leaf_batch30_c.cpp); `tools/h2_2bdb2c_sprite_setup_experiment.py` builds and stages it at the original virtual address. The body is 148/152 bytes and retains one ARM call relocation to the even, aligned original `0x002C4B30` entry. The coordinator offline run passed 36 direct cases, the exact TitleConfig caller slice, and a wrong-zero-helper negative control. An independent fresh-seed run passed 52 direct cases plus the caller slice and detected the same negative control. The full ARMv6K build passed 204/204 translation units. The slot-only IPS roundtrip and scope check passed.

The ledger is classified `non_matching` because the compiled body differs from the pinned bytes. The candidate coalesces some adjacent flag-byte stores into halfword stores. Final memory state is supported for ordinary, non-overlapping RAM; write-width/order parity for MMIO, concurrent observers, or other side-effecting memory is not established. The runner checks `r4-r10`, `d8-d15`, and final SP, but does not explicitly sentinel-check `r11`, condition flags, or SP at the helper-call boundary; the reviewer verified the candidate `r11` save/restore in its prologue/epilogue. This record does not claim that the descriptor table is valid, that any resource is loaded, or that the node is rendered.

## Limits

Evidence covers ordinary aligned RAM, a readable descriptor, a writable node, and the proven non-overlapping TitleConfig layout. Null or malformed pointers, descriptor lifetime and extent beyond 0x20 bytes, table contents, resource lookup, allocation, rendering, concurrent observation, runtime reachability, and the full H2 lifecycle are unverified. Other legacy call sites using a seven-argument C++ declaration require their own callsite ABI audits.
