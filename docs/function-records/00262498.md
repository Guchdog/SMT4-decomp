# Function Record: camp_func_00262498 (0x00262498)

## Summary
- **Address:** `0x00262498`
- **Size:** 432 bytes (105 ARM instructions plus three literal words)
- **File:** `src/engine/leaf_batch41_c.cpp`
- **Role:** Camp/battle weight selector. It gathers up to nine entry ids from a
  script-VM table or an indexed object, decodes a per-entry multiplier from a
  record field, and applies the resulting weight through one of two float
  scalers.
- **Status:** Semantically equivalent C++ (`non_matching`). Verified with a
  Unicorn ARM differential test across 67 cases and six negative controls.

## Contract and Behavior
- **Signature:** `extern "C" s32 camp_func_00262498(u8* self, u32 arg1,
  s32 arg2)`
  - `r0` (`self`): object read at +0x20, +0x36 and +0x43.
  - `r1` (`arg1`): forwarded to the fixed-point scaler and returned unchanged
    when the low state flags are `0xFA0`.
  - `r2` (`arg2`): signed branch selector. Negative selects the script-VM
    interaction table; non-negative selects an indexed object.

### Inactive-self gate (0x002624A8..0x002624BC)
- `ldrh r1,[self+0x36]; lsls r1,r1,#20` keeps the low twelve flag bits.
- When `(flags & 0xFFF) == 0`, the conditional `ldrb r1,[self+0x43]` runs; if
  that byte is also zero the function returns 0.
- Flag bits 12..15 are discarded by the shift and have no effect.

### Entry gathering
- **`arg2 < 0` (0x002624E8..0x00262518):**
  1. `0x002B66EC()` returns the script-VM interaction table; `sb` is the
     sign-extended `s16` at table+0x24.
  2. `0x002841A0(entries, 1)` copies four table words from +0x34..+0x40 into
     the zeroed five-word buffer and may fill the ninth `u16` slot.
  3. `0x002AE394(u16 self[0x20])` maps the id; its result is passed as `count`
     to `0x0028412C(self, count, 2)`, whose result is the `bonus` addend.
- **`arg2 >= 0` (0x0026251C..0x0026253C):**
  1. `0x002A89E4(arg2)` returns an indexed object; a null result returns 0.
  2. `sb` is the sign-extended `s16` at object+0x16.
  3. Four words at object+0x34..+0x40 are copied verbatim; the fifth word stays
     zero.

### Fixed nine-entry scan (0x00262540..0x002625A0)
For `i = 0..8`, read `entry = u16 entries[i]`:
- An entry of 0 is skipped.
- `0x002840B8(entry)` returns a record pointer; null is skipped.
- `field = u32 record[0x38]`. The entry contributes only when
  `(field >> 11) & 0x1F == 0x14` (equivalently `(field << 16) >> 27`).
- `selection = (field >> 16) & 0xF` (equivalently `(field << 12) >> 28`):
  selection 5 adds 1, selection 6 adds 2, anything else adds 0.

### Tail dispatch (0x002625A4..0x00262630)
The +0x36 halfword is re-read after the helper calls:
- `(flags & 0xFFF) == 0xFA0` returns `arg1` unchanged.
- Otherwise, when the low twelve bits are non-zero:
  `0x003BF764(sb, bonus, 0, s0=float(low), s1=1.0f, s2=1.0f,
  s3=scale_table[weight])`. The helper computes
  `trunc(s0 * s3) + bonus` (the two trailing integer additions are r1 and r2).
- Otherwise the low bits are zero, so read `byte = self[0x43]`; zero returns 0,
  and a non-zero byte calls `0x003BF7AC(arg1, s0=byte * 0.01f)`.

### Data and helper contracts
- `0x00446D30` is the scale table read by the far literal load. The pinned
  image holds `1.0f, 1.25f, 1.5f, 1.875f` and zeros beyond index 3; the weight
  can reach 18, so indices 4..18 read zero in the shipped data.
- `0x003BF764` is a 24-byte leaf: `vmul.f32 s0,s0,s3`,
  `vcvt.s32.f32`, then `add r0,r0,r1; add r0,r0,r2`.
- `0x003BF7AC` is a 36-byte leaf: if the raw `s0` bits are >= `0x3F800000`
  (signed compare) it returns `r0` unchanged, else
  `trunc((float)(s32)r0 * s0)`.

## Limits
- `0x002840B8` is stubbed: its real body performs a managed-record lookup with
  an allocation fallback; only the returned record pointer and the +0x38 word
  are consumed here.
- `0x002841A0`'s ninth-slot value is derived by the real helper from its own
  lookup; the test supplies it as a fixture to exercise loop index 8.
- The scale-table contents past index 3 and all pointed-to records are runtime
  data, not recovered constants.
- There are no indirect calls in this function.
