# `0x002C32F8` — bind a sprite group descriptor

## Recovered behavior

`camp_func_002c32f8` takes a writable group pointer in `r0`, three raw words in `r1-r3`, and seven more raw words on the stack at entry `[sp..sp+0x18]`. These stack values are word payloads; the original temporarily loads three into VFP registers only to copy their bits into memory. It writes halfwords at offsets `0,2,4,6,8`, then full words at `0x0C,0x10,0x14,0x18,0x1C`. The two bytes at `+0x0A..+0x0B` are untouched. The raw return is `group+0x14`; the TitleConfig caller ignores it.

For TitleConfig, `0x002F4D34..0x002F4D6C` first calls `UiSpriteGroup_Init(group)` and then binds table `0x00407EC6`, count `0x18`, and seven zero stack words. The initialized descriptor is therefore 0x20 bytes with zero padding at `+0x0A..+0x0B` and zero trailing fields, except for its table pointer and count.

## C++ reconstruction and evidence

The typed implementation is in [leaf_batch13_b.cpp](../../src/engine/leaf_batch13_b.cpp). `tools/h2_2c32f8_group_bind_experiment.py` compiles the production TU and stages the 76-byte body at its original VMA with a slot-only IPS. The candidate is 76/76 bytes with no relocations; its bytes differ from the original, so the ledger is `non_matching`.

The coordinator offline run passed 51 direct cases (three directed and 48 seeded), the exact TitleConfig group-init/bind caller slice, an independent expected-descriptor calculation, and a negative control that removes the count store. The run compares full descriptor bytes, raw return, GPR/VFP callee-saved registers and final SP. Independent review passed 67 fresh direct cases plus the caller slice and count-store control; the full ARMv6K build passed 204/204 translation units.

## Limits

Evidence covers aligned ordinary writable RAM and raw 32-bit argument words. The caller initializes the descriptor with `0x002C3344` before binding; direct tests poison the gap bytes and prove the binder leaves them unchanged. The compiled C++ reorders some independent stores, so write-order or access-width equivalence is not asserted for MMIO, concurrent observation, or other side-effecting memory. Table contents, visual/resource meaning, pointer faults, physical UI behavior, scheduling and complete H2 runtime remain outside this record.
