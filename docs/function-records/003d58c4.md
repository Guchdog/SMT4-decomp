### VFP code-generation note
Clang lowers `base + delta * fraction` to `vmul` + `vadd`. That is numerically
identical to the original's `vmla` for finite values (Unicorn's `vmla` is
non-fused), but it can select a different NaN payload when signalling NaNs are
mixed. The reconstruction therefore emits `vmla.f32` through a small
`always_inline` helper, so the candidate matches the original bit-for-bit for
every tested input, including NaN payloads.
