# Function Record: func_00167694 (0x00167694)

## Summary
- **Address:** `0x00167694`
- **Ledger size:** 1848 bytes. The whole span `0x00167694..0x00167DCB` is the
  routine: two complete return paths (`0x00167C74`/`0x00167C78` for the narrow
  width path, `0x00167DC4`/`0x00167DC8` for the wide path). There is no plan
  body split and no literal pool inside the range; the two constants it loads
  live in the **preceding** routine's pool (see below).
- **File:** `src/engine/leaf_batch34_c.cpp`
- **Role:** Four-plane 8-byte-group edge-preserving horizontal filter. It walks
  a plane block, keeps a rounded average of two packed source vectors per byte
  lane, and replaces a lane with the packed source byte when the signed
  magnitude of the lane difference reaches a broadcast threshold.
- **Status:** Semantically equivalent C++ (`non_matching`). Verified with a
  Unicorn ARM differential test over 60 cases plus five compiled negative
  controls.

### Group kernel (expanded four times at `0x001676D8..0x00167B10` and once per
tail iteration at `0x00167B34`)
Per 8-byte group, `base` addresses four planes at `base + 0x200*p`, `p = 0..3`:

1. Load the word pair `+4`/`+8` of each plane and interleave it with
   `pkhtb`/`pkhbt`:
   - `r4 = pkhtb(plane3+4, plane1+4)`, `r3 = pkhtb(plane2+4, plane0+4)`,
     `r6 = pkhbt(plane1+8, plane3+8)`, `r5 = pkhbt(plane0+8, plane2+8)`.
2. Transpose with `uxtb16` / `uxtb16 ..., ror #8` and `orr ... lsl #8` into
   four four-byte lane vectors: `A = r2`, `B = r3`, `C = r1`, `D = r4`.
3. Blend:
   - `avg = uhadd8(A, B)`, `mix = uhadd8(uhadd8(~D, C), 0x01010101)` twice,
     `hi = uqsub8(mix, 0x20202020)`, `lo = uqsub8(0x20202020, mix)`,
   - `sl = uqsub8(uqadd8(avg, hi), lo)`,
   - `fp = uqadd8(uqsub8(avg, hi), lo)`.
4. Three per-lane selectors, each driven by the GE flags of an `ssub8` whose
   operand is a byte-wise absolute difference (the intermediate `uadd8` only
   builds that difference; its own GE bits are overwritten):
   - `|C - A|` (as bytes) against threshold B → `sl`/`fp` become `A`/`B`;
   - `|D - B|` against threshold B → `A`/`B`;
   - `|A - B|` against threshold A → `A`/`B`.
   `ssub8` alone sets GE; its saturating result register is dead, so only the
   flags are observable. GE for a lane means `signed(diff_byte) >=
   signed(threshold_byte)`, i.e. differences at or above `0x80` compare
   negative and select the blended value.
5. Store one byte per plane: `base[0x200*p + 7] = sl >> 8p`,
   `base[0x200*p + 8] = fp >> 8p` — eight byte stores per group.

### Row loop (`0x001676AC..0x00167C78`)
```
counter = cols - 0x20                       // signed comparisons throughout
if ((s32)counter <= 0) {                    // narrow path, 0x00167C7C
    saved = cols - 8;                       // also [sp+4]
    for (;;) {
        do { group(base); base += 8; saved -= 8; } while ((s32)saved > 0);
        base += 0x800;                      // 0x00167DAC
        rows -= 4;
        if (rows == 0) return state;
        base += 0x808 - cols;               // - saved
        saved = cols - 8;
    }
}
saved = cols - 0x20;                        // [sp+4]
for (;;) {                                  // wide path, 0x001676D4
    do {                                    // four groups per 0x20-byte chunk
        group(base+0x00); group(base+0x08);
        group(base+0x10); group(base+0x18);
        base += 0x20; counter -= 0x20;
    } while ((s32)counter > 0);
    counter += 0x18;                        // 0x00167B28
    if (counter != 0) {
        do { group(base); base += 8; counter -= 8; } while ((s32)counter > 0);
    }
    base += 0x7E8;                          // 0x800 - 0x18
    rows -= 4;
    if (rows == 0) return state;
    base += 0x808 - cols;                   // - saved
    counter = cols - 0x20;
}
```
Both paths therefore end a row with the same net `base` advance
(`0x808 - cols`); the wide path additionally runs a whole number of
`0x20`-byte chunks before the 8-byte tail. For the aligned widths the game
uses (multiples of 8) the number of groups per row is `(cols - 8) / 8`: the
last eight bytes of the row are intentionally left untouched, and the
`0x800 - 0x18` row step together with the `0x808 - cols` correction lands
`base` exactly on the next `0x800`-byte plane block. Widths below `0x10` are
clamped to a single group by the unconditional first tail iteration.

## Implementation
- Anonymous-namespace SWAR helpers mirror the ARMv6 SIMD byte instructions
  (`uxtb16`, `ror #8`, `pkhbt`, `pkhtb`, `uhadd8`, `uqsub8`, `uqadd8`,
  `uadd8`, `ssub8` GE mask, `sel`), and `ReplicateByte` is the two `orr`
  broadcasts. `FilterGroup` is the group kernel; `RowFilter` is the loop above.
  Both are `always_inline`, so `func_00167694` compiles to a single leaf body
  with no relocations (9644 bytes with clang -O2 after unrolling).
- `LoadWord` uses byte accesses; all stores are single-byte stores.
