# `0x00207D84` — generic UI transform wrapper

## Status

Readable C++ in `src/engine/leaf_batch30_c.cpp`; ledger classification is
`non_matching` because the final candidate is 156 bytes for a 128-byte original
extent. A standalone staged experiment passes bounded semantic review, but the
candidate is not integrated into the current cumulative H2 image: its proposed
cave overlaps allocated Draw/Secondary code. No direct TitleConfig or Audio
Settings reachability is established.

## Recovered behavior

The wrapper takes no arguments. It calls the original `0x002C5218` to fetch the
projection context through the global pointer chain, copies the four input
words at `0x004EA91C` to fixed scratch `0x00472550`, then passes the first three
words to original `0x0026330C` with projection index zero. It writes the
projected x/y/z and a zero fourth word back to the global vector in order. Its
machine-visible return is `r0=0x004EA91C` and `s0=projected z`; both audited
caller callsites ignore those registers and consume global memory.

## Evidence and limits

`tools/ui_transform_00207d84_experiment.py` compiles the affected TU, resolves
both ARM call relocations at the staged final VMA, and compares original and
staged images under Unicorn ARM/VFP. Seven finite direct fixtures include basis,
negative, perspective, seeded, and near-denominator values; four FPSCR rounding
modes also pass. Two original `0x0024B874` compositions hit both callsites
`0x0024B8E0` and `0x0024B908`. They stub unrelated UI services
`0x002698F4`, `0x00269768`, and `0x0024C62C`; the latter returns a fixed s0.
Three comparator-injection controls detect swapped x/y, a missing w-zero result,
and a changed scratch word. All four affected TUs compile individually.

The body does not fit the original 128-byte slot. The standalone experiment
stages it at `0x003FEE54`, the 428-byte residual after the 2,096-byte Calc body
at `0x003FE624`; that range is zero in the pinned image and the recorded static
reference scans found no entries. The independent review checked the current
cumulative H2 manifest and found the same range already contains Draw helper
code/data and Secondary code. The proposed placement would overwrite those
records, so it is not integrated into that image. A new complete-image layout
or an in-slot implementation is required before cumulative integration. The
experiment uses synthetic valid pointers and finite contexts, keeps projection
callees original, and establishes neither natural H2 reachability nor
whole-screen or runtime equivalence.
