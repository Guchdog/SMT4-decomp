# `0x00207D84` — generic UI transform wrapper

## Status

Readable C++ in `src/engine/leaf_batch30_c.cpp`; ledger classification is
`non_matching` because the compiled ARMv6K body is 104 bytes inside the 128-byte
original slot `[0x00207D84, 0x00207E04)` (padded with 24 bytes / six ARM NOP
words `0xE320F000`). Tightening the vector/scratch copies to a 16-byte structure
assignment (`Vec4Words`) under `__attribute__((minsize))` reduced the body from
156 bytes to 104 bytes, eliminating the prior `0x003FEE54` code cave and its
collision with Draw/Secondary in the cumulative H2 image. No direct TitleConfig
or Audio Settings reachability is established.

## Recovered behavior

The wrapper takes no arguments. It calls the original `0x002C5218` to fetch the
projection context through the global pointer chain, copies the four input
words at `0x004EA91C` to fixed scratch `0x00472550` in ascending word order,
then passes the first three words to original `0x0026330C` with projection index
zero. It writes the projected x/y/z and a zero fourth word back to the global
vector in ascending word order. Its machine-visible return is `r0=0x004EA91C`
and `s0=projected z`; both audited caller callsites ignore those registers and
consume global memory.

## Evidence and limits

`tools/ui_transform_00207d84_experiment.py` compiles `src/engine/leaf_batch30_c.cpp`,
stages the 104-byte body in-slot at `0x00207D84` (`0x00207D84..0x00207E04` with a
24-byte ARM NOP tail), resolves both ARM call relocations at final in-slot VMAs
(`0x00207D8C -> 0x002C5218` and `0x00207DC0 -> 0x0026330C`), and compares
original and staged images under Unicorn ARM/VFP (`build/agent-work/H2-semantic/h2-cave-reloc-00207d84/run-001/checks/direct/report.json`):
- `7/7` finite direct fixtures pass (basis x/y/z, negative, perspective,
  finite near-denominator, seeded `20261102`), matching `r0`, `s0`, `fpscr`,
  `sp`, `r4-r11`, `s16-s31`, global vector (`0x004EA91C`), global scratch
  (`0x00472550`), ordered 4-byte global writes, and caller-owned stack.
- `4/4` FPSCR rounding modes (`RN`, `RP`, `RM`, `RZ`) pass.
- `2/2` original `0x0024B874` caller compositions hit both callsites
  (`0x0024B8E0` and `0x0024B908`) and match output/global state (stubbing
  unrelated UI services `0x002698F4`, `0x00269768`, and `0x0024C62C`).
- `3/3` comparator-injection negative controls detect swapped x/y, a missing
  w-zero store, and a mutated scratch word.
- `0` collisions with the cumulative H2 image (`build/h2-86928-integration/cumulative-image/manifest.json`,
  `629` IPS records, `slot_bytes_unmodified_in_cumulative_image=true`, and `0`
  interior references into `[0x00207D88, 0x00207E04)`).

The experiment uses synthetic valid pointers and finite contexts, keeps
projection callees original, and establishes neither natural H2 reachability nor
whole-screen or runtime equivalence.
