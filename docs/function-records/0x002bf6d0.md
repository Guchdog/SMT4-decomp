# `camp_func_002bf6d0` — H2 indexed manager-node resolver

## Reconstructed behavior

The helper forwards both 32-bit arguments `(group, node_index)` to the
`0x002B0188` manager resolver. From the returned manager it follows the
pointer chain at `+4`, then dereferences the node-base pointer. It interprets
`node_index` as signed for quotient/remainder: `q = node_index / 1000` using
truncation toward zero, `r = node_index - 1000*q`. The result is the low-32-bit
address `node_base + 20*r`. The C++ candidate calls the original signed divider
`0x002C615C` for `q`, preserves the raw pointer return, and uses integer address
arithmetic to retain target wrap behavior. Its 60-byte body fits the 64-byte
slot; its two ARM calls target even entries `0x002B0188` and `0x002C615C`.

## Evidence

The pinned direct differential in
`build/agent-work/H2-semantic/h2-bf6d0-manager-slot-convert/run002/checks/coordinator-seed-20261114/`
matched 2,269 cases, including every signed index from -1000 through 1000,
signed 32-bit endpoints and adjacent block boundaries, plus 256 deterministic
random indices. It compared raw return, both resolver arguments, `r4-r11`, SP,
faults, and writes outside the stack. The original H2 touch caller
`0x002B88C4` also matched all 42 cases with the actual original manager
resolver and node-table path. Three controls changing the block divisor,
dropping the forwarded index, or changing the 20-byte stride were detected.

The exact-slot IPS replay and one-slot-only audit passed. The implementation
TU `leaf_batch27_b.cpp` and caller TU `leaf_batch32_c.cpp` compiled. The ledger
classification is `non_matching` because the compiled bytes differ.

## Limits

The direct cases use a deterministic resolver return seam and valid aligned
synthetic ordinary RAM; caller cases execute the original resolver and caller
with a controlled manager table. The candidate calls the original divider,
which leaves stack spill bytes below SP; this evidence does not claim parity
for temporary stack residue. Invalid pointers, arbitrary aliasing, MMIO,
manager lifecycle, physical input meaning, and runtime behavior are not
established.
