# `script_vm_func_002b8b78` — six-slot profile transition

The 340-byte ARM entry at `0x002B8B78` is now readable typed C++ in
[`leaf_batch32_c.cpp`](../../src/engine/leaf_batch32_c.cpp). It compares the
full 32-bit request with the selected profile byte, applies the signed manager
latch and six-byte scan, performs both profile lookups, updates the selected
and previous profile bytes, configures six slots in order, then reloads the
current object for the final service transition. Its raw `r0` return is kept as
`u32`; direct dependencies remain the original functions.

and its read-only local

340-byte function slot. The original table bytes used are `05 06 04 03 02 01`.
