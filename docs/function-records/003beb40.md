# Function Record: ui_func_003beb40 (0x003beb40)

## Summary
- **Address:** `0x003beb40`
- **Size:** 576 bytes (original span `[0x003beb40, 0x003bed80)`)
- **File:** `src/engine/leaf_batch45_a.cpp`
- **Role:** Integer percentage-like estimator for a unit pair. Combines the
  primary unit record's stat (`stat * 4.5`), a caller-supplied base value and
  multiplier, two category factors, a status factor, a per-record 0.8/1.0
  factor, the view builder's percentage, an optional battle-object bonus, the
  camp modifier table, and an affinity percentage, then converts the result to
  a signed integer.
- **Status:** Semantically equivalent C++ (`non_matching`). The compiled body is
  not byte-identical (568 B of generated code versus the 576 B original; the
  compiler also reorders independent float multiplies and folds the two
  `0x23EBF0` call sites into one with a conditional table offset). The ledger
  row is classified `non_matching` with this semantic record.

## Contract and Behavior

### Signature and ABI
```c
extern "C" s32 ui_func_003beb40(void* ctx, s32 primary_id, s32 secondary_id,
                                s32 range_a, s32 range_b,
                                float base_value, float scale);
```
- `ctx = r0`, `primary_id = r1`, `secondary_id = r2`, `range_a = r3`;
  `range_b` is the single caller stack word at `[entry_sp]` (read as
  `[sp, #0x90]` after the original frame is built).
- The two floats arrive in `s0`/`s1` (hard-float AAPCS with four integer
  arguments); `f0` is the base value, `f1` the multiplier.
- Return: signed 32-bit in `r0`, produced by `vcvt.s32.f32 s0, s16` in the
  common tail.
- The original preserves `r4-r8, sb, sl, fp` and `d8-d11`; the candidate
  preserves the same set (it additionally saves `d12`). Final `sp` is restored
  to the entry value.

## Contract corrections found during implementation
- **Return conversion wording.** The contract says the tail "truncates toward
  zero". The instruction is `vcvt.s32.f32` (not `vcvtr`), which uses the FPSCR
  rounding mode; with the reset FPSCR value this is round-to-nearest-even.
  Clang emits the same `vcvt.s32.f32` for a C++ `(s32)float` cast on this target,
  so the implementation matches the original without an asm shim. The harness
  compares the resulting integer under a zeroed FPSCR and includes near-half
  and out-of-range values.
- **Redundant primary flag test.** Disassembly confirms that
  `0x3BECF0`/`0x3BECF8`/`0x3BECFC`/`0x3BED04` collapse to "secondary record
  bit 2 selects `camp+0`, otherwise `camp+8`". `primary_record[0] & 4` only sets
  flags that are overwritten before use. The C++ implements the collapsed
  selection and the differential covers all four primary/secondary combinations.
- **Affinity index domain.** `view[0x0E + idx]` is unguarded, but the view is
  copied to a 0x24-byte stack copy: indices `0x00..0x13` read defined view bytes
  (`0x12`/`0x13` read `view[0x20]`/`view[0x21]`), while `0x14` and above read
  frame padding. Indices `0x00` and `0x11` are the documented in-array range;
  the harness covers `0x00..0x13` and excludes `0x14+` because that is an
  overread of uninitialized stack bytes, not reproducible behavior.
- **`vmla` vs. separate multiply/add.** The original computes
  `f0 + stat * 4.5` with `vmla`; Clang emits a separate `vmul`/`vadd`. Since the
  stat is a signed halfword and 4.5 is exactly representable, `stat * 4.5` is
  exact in single precision for every `s16` input, so both forms are
  bit-identical.

## Limits
- Fixtures are synthetic: the unit table, record fields, view contents, camp
  table, and null-row page use scripted values, not captured game data.
- Every helper is stubbed, including `0x27DCA0`/`0x282B94` (the harness mirrors
  the 109-row scan), `0x22A824`, `0x3BE898`, `0x2475E4`, `0x23EBF0`,
  `0x2AE3F0`/`0x2AE394`/`0x28412C`. No real helper body, global manager state,
  or rendering is exercised.
- `0x2475E4`'s switch and field meanings, the status-id source inside
  `0x22AD74`, and the `0x22A824` global flag chain (`[0x0043427C]` bit 0x200)
  remain unresolved; only the behaviors this function observes are modeled.
- Overread affinity indices (`>= 0x14`) and `0x22A824` out-of-domain `3-stat`
  table indexing are not reproduced; both depend on undefined/unmapped memory.
- The candidate's internal frame (0x78 bytes) differs from the original 0x90
  bytes; only the documented ABI inputs, call arguments, saved registers, and
  return state are compared.
- No caller composition or runtime/whole-game equivalence is claimed.
