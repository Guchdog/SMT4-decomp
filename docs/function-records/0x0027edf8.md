## Production body and ledger

The production body is exactly 24 bytes and has no relocations. Its instructions
are `uxtb`, `orr`, `orr`, `str`, `str`, `bx lr`. Compared with the original,
only `and r1,r1,#0xff` changes to the equivalent `uxtb r1,r1`; the two
replication operations, store footprint, and return remain the same. The source
uses empty register constraints to keep the unsigned shift/OR operations
separate in Clang's output, and inline `str` instructions so `u8*` does not
assert four-byte alignment.

The ledger row is `non_matching`, which truthfully records the instruction
encoding difference. The production patcher installs the body at the original
VMA and verifies the 24-byte slot, zero relocations, patch round-trip, and
covered direct-branch/aligned-pointer references into the function interior.
