# `0x002C6C10` — unsigned quotient/remainder service

## Contract from the pinned image

The original ARM entry spans 48 bytes at `0x002C6C10`. It accepts an unsigned
32-bit dividend in `r0` and divisor in `r1`, returns quotient in `r0` and
remainder in `r1`, clobbers `r2/r3` and condition flags, and preserves
`r4-r11`, SP, and LR. It performs no memory access or nested call. For divisor
zero, it returns `r0 = 0xFFFFFFFF` and `r1 = dividend`; it does not fault or call
an error handler. See the [pinned contract reconstruction](../agent-work/h2-002c6c10-divmod-contract-recon.md)
for instruction-level branch targets and caller analysis.

## H2 callers

Mode-0 query `0x002B902C` passes `counter-threshold` and the runtime selector;
it consumes only the remainder after reaching the repeat path, where the
unsigned dividend is positive. A selector of zero therefore produces a
nonzero remainder and false. TBB row-count helper `0x002C0E4C` guards zero
stride and consumes only the quotient. Both caller fields are unsigned words;
neither caller establishes general signed 31-bit bounds.

## C++ conversion status

No production C++ replacement is accepted. A freestanding typed shape using
`dividend/divisor`, `dividend%divisor`, and the zero-divisor result compiled to
52 bytes and one `R_ARM_CALL` to `__aeabi_uidiv`, so it exceeds the original
slot by four bytes and has an unresolved helper placement/recursion question.
Calling the neighboring signed helper `0x002C615C` is not justified for the
full unsigned caller domains. Keep the original 48-byte implementation until a
full-domain C++ body and dependency placement are established.

A seven-case pinned caller probe compared original `0x002B902C` with the
current typed production candidate using selector zero. Eligible positive
numerators returned false in both; pulse, availability, invalid-ID, and
threshold bypasses also matched. This supplements but does not replace the
original nonzero-selector matrix. The probe deliberately retains original
`0x002C6C10`; it does not reconstruct it.

## Limits

The contract is pinned-binary/static-caller evidence plus bounded mode-0 caller
cases. TBB payload/stride resource limits, live counters/selectors, scheduler,
input delivery, and runtime behavior remain unverified.
