# `camp_func_002b8794` — H2 profile-slot registry updater

The helper ignores slots `>= 6`, then reads the current manager pointer from
`0x0043DA2C`; a null manager returns without writes. For nonzero `mode`, it
uses the six-word registries at `0x0043DA50` and `0x0043DA68`. A negative first
entry can claim the requested registry pair when any manager reservation byte
at `manager+0x4B8..0x4BD` is nonzero. A matching pair is cleared to
`0xFFFFFFFF` in both arrays. The H2 wrapper calls this helper with `mode=0`.

For the manager update, it writes the low byte of `priority` at
`manager+0x494+slot*4`, the low halfword of `value` at
`manager+0x496+slot*4`, then updates the slot row at `manager+slot*0x8C`:

- `priority == 8`: `+0x3C = 4`, `+0x34 = 0x12`, `+0x38 = 0xFFFFFFFF`.
- `priority == 7` or `9..17`: `+0x3C = 1`, then `+0x34 = 0x12`, `+0x38 = 0xFFFFFFFF`.
- Other priorities: `+0x34 = 0x12`, `+0x38 = 3`, `+0x3C = 0xFFFFFFFF`.

The typed definition is in
[`leaf_batch41_a.cpp`](../../src/engine/leaf_batch41_a.cpp). The compiled body
is 272 bytes in its 304-byte slot with no relocations. It differs from the
pinned code and is correctly classified `non_matching`.

`tools/h2_profile_slot_registry_experiment.py` passed 12 direct manager/
registry fixtures and both original caller slices (`0x99` initializer and
`0xDC` callback), each executing six real helper calls. Three mutation controls
were detected; the slot-only IPS replay and the two affected-TU builds passed.
The ordinary aligned manager fixtures are synthetic. Other wrapper services
are controlled hooks in the caller runs; manager lifecycle, natural callback
reachability, audio output, and runtime behavior remain unproven.
