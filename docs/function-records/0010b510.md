# GuestWin_HandlePrompt (0x0010b510)

## Summary
- **Address:** 0x0010b510
- **Size:** 104 bytes
- **Domain:** UI / Guest Dialog Prompt Timer Processor
- **Status:** Semantically verified (non_matching in ledger)
- **Source File:** src/ui/window.cpp
- **Differential Suite:** tools/window_batch4_experiment.py

## Role and Behavior
- **Role:** Iterates over 16 guest prompt slots, decrements active timers, and raises expiration flag `0x8`.
- **Details:**
  - Retrieves UI engine context via `UiEngine_GetContext()` (`0x002C2B1C`).
  - Loops over 16 prompt records (`stride = 0x14`):
    - Reads flag byte at `ctx + 0x3C80 + i * 0x14`.
    - Tests if active and unexpired: `(flags & 7) == 7 && !(flags & 8)`.
    - If active, reads 16-bit timer at `ctx + 0xF28 + i * 0x14`.
    - If `timer > 0`, decrements timer and writes it back.
    - If `timer == 0` (or reaches 0), sets expiration bit `flags |= 8` and writes back to `ctx + 0x3C80 + i * 0x14`.
- **Differential Coverage:** Verified in Unicorn emulator across full 16-slot matrix with various flag and timer configurations against original ARM binary.
