## Recovered contract

The argument is an unsigned 32-bit logical query ID. IDs `>=31` return zero
before any global or counter reads. For valid IDs, the helper reads bit 0 of the
mode word at `0x004650A8`. If the bit is clear, it reads
`counter = *(u32*)(0x004E3C58 + 4*id)` and returns one immediately when
`counter == 1`. Otherwise it continues with the selected counter value. If the
availability bit is set, it substitutes zero for the counter and does not read
the counter table.

The helper reads an unsigned threshold at `0x004650AC`. If `counter <=
threshold`, it returns zero. Otherwise it calls the existing quotient/remainder
service at `0x002C6C10` with `(counter-threshold, *(u32*)0x004650B0)`. It returns
one when the service's remainder in `r1` is zero, and zero otherwise. The H2
initialization path sets the threshold to 7 and selector to 2; the query uses
those runtime fields rather than constants.

H2 Calc uses mode-0 IDs 4 and 3, then fallback IDs `0xD` and `0xC` respectively
when the first query returns zero. This can make the first counter value a
one-refresh pulse and later eligible counter values repeat on the configured
selector interval after the threshold. The input producer's cadence and the
physical meaning of these logical IDs remain unproven.
