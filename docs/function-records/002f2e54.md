# Function Record: ui_func_002f2e54 (0x002F2E54)

## Summary

- **Address:** `0x002F2E54`
- **Size:** 440 bytes (`[0x002F2E54, 0x002F300C)`): 106 ARM instructions through
  the unconditional `pop {r4, r5, r6, r7, r8, sb, sl, pc}` at `0x002F2FF8`,
  followed by the four literal words at `0x002F2FFC..0x002F300B`:
  `0x004724CC`, `0x0044EA00`, `0.0f` (`0x00000000`) and `1.0f`
  (`0x3F800000`).
- **File:** `src/engine/leaf_batch41_c.cpp`
- **Role:** Brackets two UI element submissions with a push/pop of the GPU
  render-state stack at `*0x0044EA00 + 0x124C`, selects render mode 0, and
  forwards the caller's two packed words and a biased integer origin to the
  two draw helpers `0x002C0B1C` and `0x002100F8`.
- **Status:** Semantically equivalent C++ (`non_matching`). The candidate body is
  392 bytes versus 440 bytes. Control flow, both helpers' guard bytes, the exact
  push/pop node accesses (including the `count == 3` dirty-word alias), the
  capture-before-helper order, all arguments/rows of the call log and the full
  memory effect are preserved. Behavioural support is the differential runner
  below, not byte identity.

## Contract and ABI

```cpp
extern "C" u32 ui_func_002f2e54(s32 x,       // r0
                                s32 y,       // r1
                                s32 width,   // r2
                                s32 height,  // r3
                                u32 packed_a, // [sp+0]
                                u32 packed_b);// [sp+4]
```

- The prologue saves `{r4-r8, sb, sl, lr}` and `vpush {d8, d9}` (s16-s19); the
  epilogue restores exactly those. `r9`/`r10` are used as scratch and restored;
  `r11` is never touched by the original. `SP` is unchanged and there is no
  local frame. The two stack words are read from the caller's frame with
  `add r2, sp, #0x30; ldm r2, {r5, r6}` at `0x002F2E70/0x002F2E78`, i.e. before
  any helper runs.
- `x`/`y` are converted through the runtime bias pair at `0x004724CC`:
  `vcvt.f32.s32`, `vadd.f32`, `vcvt.s32.f32`. `width`/`height` are forwarded
  directly as `vcvt.f32.s32` values. All four later arguments to the draw
  helpers are single precision in `s0..s3`.
- **Return value:** the pop's `new_top` when its flush callback did not run, or
  the callback result when it did. No static caller exists in the pinned image
  (see *Callers*), so the value's use cannot be observed; it is returned as
  `u32` to keep register-level differential tests exact.

## Recovered behaviour

### Capture phase (`0x002F2E7C..0x002F2EA0`, before the first helper)

1. `push_base = *0x0044EA00` (render-register block base).
2. `bias_x = *(f32*)0x004724CC`, `bias_y = *(f32*)0x004724D0`. The pair is
   written at runtime by the setter at `0x002E70B0` (`ldr r0, [pc]; vstmia r0,
   {s0,s1}`); its static image value is zero.
3. `biased_x = (s32)((f32)x + bias_x)`, `biased_y = (s32)((f32)y + bias_y)`.
   The conversion truncates toward zero; VFP saturates out-of-range results and
   maps NaN to zero.
4. The two stack words are copied into `r5`/`r6` (word at `[sp+0]` into `r5`,
   word at `[sp+4]` into `r6`). The reconstruction uses the same
   capture-before-helper order.

### Push (`0x002F2EA4..0x002F2EE8`)

`pushed = ui_func_002c5f7c(1, 1)`; the node at `push_base + 0x124C` is accessed
as flat words:

```
count    = node[0]
previous = node[2 + count]
node[0]          = count + 1
node[2 + count+1] = pushed
if (node_byte[0x18] != 0 || previous != pushed) {
    node[0x1C](pushed);   // indirect, no null check
    node_byte[0x18] = 0;
}
```

The dirty byte is read **after** the slot store. At `count == 3` the store
lands on the word at `+0x18`, so the dirty byte observes the low byte of
`pushed` (`0x10`) even when the node was previously clean. The candidate models
the node as a flat word array specifically to keep this order (a bounded
`slots[4]` array made clang hoist the byte load above the out-of-bounds store).

### Mode and draws (`0x002F2EEC..0x002F2FAC`)

1. `ui_func_002c1d3c(*0x0044EA00, 0)` — the global is re-read after the push, so
   a callback that rewrites it is observed.
2. If `packed_b >> 24 != 0` (the second stack word), byte-swap it
   (`__builtin_bswap32`) and call
   `ui_func_002c0b1c(swapped, swapped, swapped, swapped,
    (f32)biased_x, (f32)biased_y, (f32)width, (f32)height, 0.0f)`.
3. If `packed_a >> 24 != 0` (the first stack word), byte-swap it and call
   `ui_func_002100f8` with the same `r0..r3`/`s0..s3` plus `s4 = 0.0f`,
   `s5 = 1.0f`.

The guard is on the top byte of the unswapped word (equivalently the alpha byte
of a little-endian packed colour word); a zero top byte skips that draw
entirely. Both words suppress their draws independently. The byte swap is
exactly `R<<24 | G<<16 | B<<8 | A` for a stored `A | B<<8 | G<<16 | R<<24`
word; the original builds it with `lsl`/`lsr`/`orr`.

### Pop (`0x002F2FB0..0x002F2FF8`)

The node is re-derived from a **fresh** read of `*0x0044EA00`:

```
count    = node[0]
previous = node[2 + count]
node[0]   = count - 1
new_top   = node[2 + count - 1]
if (node_byte[0x18] != 0 || previous != new_top) {
    result = node[0x1C](new_top);
    node_byte[0x18] = 0;
    return result;
}
return new_top;
```

The pop is flat and unchecked like the ARM. Note that `return pop_previous`
would be equivalent whenever no callback runs, because the no-callback path
requires `previous == new_top`.

## Differential verification

`tools/test_leaf_002f2e54.py` compiles `src/engine/leaf_batch41_c.cpp`, extracts
the `ui_func_002f2e54` body, resolves the four direct calls to deterministic
stubs at the original addresses, resolves the `g_RenderRegisterBase` relocation
to `0x0044EA00`, and runs the pinned original against the candidate on separate
Unicorn ARM machines with identical fixtures.

Per case it compares:

- returned `r0`, continuation PC, final SP, callee-saved `r4-r11` and `d8-d15`;
- the caller's two stack words (must remain untouched);
- the ordered call log, including the viewport helper's `(1,1)`, the mode
  helper's `(base, 0)`, both draw helpers' four colour registers and raw
  `s0..s4`/`s0..s5` bits, and every flush callback's target/value;
- the complete 2 MiB data region (both nodes, the render-base global, the bias
  pair and every other byte) and the ordered list of writes outside the private
  stack;
- an independent Python model of the capture/push/draw/pop sequence, using the
  probed ARM `vcvt` saturation/truncation/NaN semantics.

Coverage: both words drawn, one word suppressed, both suppressed; top-byte
boundaries `0x00FFFFFF`, `0x01000000`, `0x7FFFFFFF`, `0x80000000`,
`0xFFFFFFFF`; node counts 0..3 including the count-3 store that rewrites the
dirty byte; dirty-forced and previous-difference flushes; both callback targets;
base switches during the viewport helper, the mode helper, the push callback,
the pop callback and a second flush; bias values 0, ±0.5, 0.75/-1.25, ±1e30,
NaN and ±inf; a bias pair rewritten during the viewport helper (the captured
pair must still be used); signed coordinate/extent boundaries including
`INT_MIN`/`INT_MAX` saturation and zero-crossing truncation.

Result: **49/49 cases pass**, plus 10 negative controls (push kind, push enable,
render mode, stack offset, both literal floats, bias address, alpha guard, draw
extent order, pop comparison, pop callback result) that are each detected.

## Limits / unresolved

- No static caller or function-pointer reference exists for this address in the
  pinned image, so caller-side integration cannot be exercised. The test drives
  the function directly.
- The bias pair at `0x004724CC` is a runtime global; its initializer/consumer
  elsewhere (`0x002E70B0` and its callers) is outside this function's scope.
  The test sets and mutates it explicitly.
- The draw helpers are stubbed at their ABI boundary; their internal rendering
  effect is not reimplemented. Their argument registers and call order are
  checked exactly.
- The reconstruction is not byte-identical (392 B vs 440 B). `non_matching` is
  the truthful ledger classification; this record carries the semantic
  evidence.
