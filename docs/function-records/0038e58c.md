## Behavior

1. `0x00234278(sp)` constructs the local 20-byte message object.
2. `root = *(void**)0x00432FC8` is loaded after that call (the load is sunk
   into the state-4 block by the compiler, where it is the only consumer).
3. `switch (*(u32*)(context + 0x08))`:
   - **0**: `created = 0x00234160(context+0x20C, 0)`; `state = 1`;
     `source = created`; return. A pre-existing source is not released.
   - **1**: `message = source->vtable[3]()`; copy the 20 bytes onto the local
     message. If `0x0027EC84(&message) != 0` (first byte `0`), set `state = 2`
     and return. If `0x002A17C0(&message) == 0` (first byte `< 0x64`), return.
     Otherwise dispatch the opcode.
   - **2**: if `source != nullptr`, call `source->vtable[1](source)` (deleting
     destructor). `created = 0x00234160(context+0x20C, 5)`;
     `state = 3`; `source = created`; return. No id is written.
   - **3**: `message = source->vtable[3]()`; copy the 20 bytes. If
     `0x0027EC84(&message) != 0`, set `state = 4` and return (no release,
     unlike `0x00392ACC`). If `0x002A17C0(&message) == 0`, return. Otherwise
     dispatch the opcode.
   - **4**: `0x00234368(pair, root)` fills two words; `mapped =
     0x002A1578(pair)`. If bit 31 of `mapped` is clear, `state = 5`,
     `counter = 3` and return. Otherwise `state = 0x270F`, byte `+0x210 =
     0x64` and the raw two-word pair is stored at `+0x214`/`+0x218`; return.
   - **5**: `counter = counter - 1` (wrapping 32-bit subtraction, signed `> 0`
     test). If still positive, return. Otherwise `result = 6`, `state = 0`,
     and release/clear the owned source if non-null.
   - **`0x270F`**: `0x00234004(context, 0x0C, 3)`; return.
   - **anything else**: return.
4. Opcode tail (shared by states 1 and 3, reached only when the first message
   byte is `>= 0x64`):
   - `0x66` (`'f'`): copy the 20 bytes to a private stack slot and call
     `0x002342B8(context, &copy)`; return.
   - `0x67` (`'g'`): `state = 5`, `counter = 3`; return.
   - any other `>= 0x64` byte: `state = 0x270F`; copy the 20 bytes to
     `context + 0x210`; return.
   - bytes `1..0x63` never reach the tail: `0x002A17C0` returns zero and the
     routine returns without changing the context.
