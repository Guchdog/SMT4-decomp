## Recovered object layout and flow

The first gate is byte `object+0x88`: nonzero returns immediately. Next,
`object+0x64` is loaded as the translation-row table pointer; null also returns
without writes. The normal path reads signed halfword animation index `+0x68`
and progress `+0x6A`. Row address is `table + 12 * signed_index`, computed with
32-bit ARM wrap. Each row uses float words at `+0/+4`, unsigned duration at
`+8`, and mode byte at `+0xA`.

Duration is zero-extended from `LDRH` and compared signed against the
sign-extended progress using `BGT`:

- If `duration > progress`, interpolation runs. Direction byte `+0x6C` selects
  the signed order of two row float words: nonzero direction subtracts
  `(row+4)` from `(row+0)`, while zero direction subtracts `(row+0)` from
  `(row+4)`. The pinned VFP operation order is `VSub.f32`,
  unsigned-duration-to-float `VCVT`, `VDiv.f32`, then add to the current float
  at `+0x24` with `VAdd.f32`. Progress at `+0x6A` increments as a halfword.
- Otherwise the endpoint path uses row mode and direction to select the row's
  first or second raw word and stores it at `+0x24`: nonzero row mode selects
  `(row+4)` for nonzero direction and `(row+0)` for zero; zero row mode selects
  `(row+0)` for nonzero direction and `(row+4)` for zero. It then branches by row mode.
  Nonzero row mode clears progress immediately and skips sequence logic. Zero
  row mode does **not** clear progress unless a sequence animation is actually
  installed.

In row mode zero, feature byte `+0x84` and sequence pointer `+0x78` gate
sequence handling. Entries have stride `0x1C`; the tested word is at entry
`+0x14`, and signed direction byte is at `+0x18`. Current `-1` sets completion
byte `+0x88` without incrementing index. Otherwise the signed halfword index
`+0x80` increments before the next word is checked. Next `-1` and `-3` complete;
next `-2` resets the index and installs animation/frame from entry zero; an
ordinary next word installs the next animation and its signed direction byte.
An installed sequence animation clears progress and `+0x8A`, selects a raw
endpoint word from its translation row, and stores that value to `+0x24`.
Disabled sequence or null sequence pointer sets `+0x88=1` but leaves progress
unchanged.

Every path that passes both early guards copies `+0x24` to `+0x28` and `+0x2C`
at the common tail. The early guard paths do not perform that copy.
