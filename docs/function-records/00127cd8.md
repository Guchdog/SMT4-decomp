# Function Record: func_00127cd8 (0x00127CD8)

## Summary

- **Size:** 420 bytes (span `[0x00127CD8, 0x00127E7C)`, including the two
  literal-pool words at `0x00127E74` = `0x00000125` and `0x00127E78` =

- **Role:** Per-slot descriptor-record stream encoder. For every slot in the
  object's `u8` slot count it follows the slot's descriptor pointer, walks a
  fixed-stride record array, and either sets one bit in a 32-bit mask word or
  emits 2 / 6 encoded 32-bit words into that slot's output buffer. It then
  publishes the number of emitted words for the slot.
- **Status:** Reconstructed as readable C++ and **semantically verified**

  relocations, so it is not byte-identical; the ledger row is `non_matching` and
  this record carries the semantic evidence.

### Opcode semantics
`tag` is `0x2C0` when `descriptor[6] == 0` and `0x290` otherwise. `stream_mode`
is `tag | 0x803F0000`, and the opcode-1 parameter bias is `tag - 0xF`
(`0x2B1` / `0x281`).

- **Opcode 0 — set mask bit.** `mask_word` is the selected object word
  (`+0x29C` / `+0x2A0`). The original reads it, ORs in
  `ArmLsl(FieldA & 1, Parameter)`, and stores the result back. The read and
  store always happen, even when the field bit is clear or the mask is zero.
  ARM `lsl` by a register uses the low byte of the shift count and yields zero
  for counts of 32 or more, so parameter `32`/`33` OR in nothing while `256`
  and `257` behave exactly like `0` and `1`. No output word is emitted.
- **Opcode 1 — packed word + parameter word.** Emits
  `FieldA | (FieldB << 8) | (FieldC << 16) | (FieldD << 24)`, then
  `(Parameter + (tag - 0xF)) | 0x000F0000`. Two output words.
- **Opcode 2 — six-word stream.** Emits, in order:
  1. `Parameter`
  2. `stream_mode` = `tag | 0x803F0000`
  3. `((FieldC >> 16) & 0xFF) | (FieldD << 8)`
  4. `((FieldB >> 8) & 0xFFFF) | (FieldC << 16)`
  5. `(FieldA & 0x00FFFFFF) | (FieldB << 24)`
  6. `0xEAD0FEAD`

  The original loads `FieldC` and `FieldB` twice (before and after the
  intervening stores); the reconstruction keeps the duplicate loads so the
  load/store order is identical even if the record array aliases the output.

All three opcodes are 32-bit little-endian stores with a post-incrementing
cursor.

### Control flow
```text
for (slot = 0; slot < object[0x08]; ++slot) {
    descriptor = (u8*)*(u32*)(object + 0x0C + 4*slot);
    out = (u32*)(object + 0x368 + slot*0x928);
    out_begin = out;
    variant = descriptor[0x06];
    tag = variant ? 0x290 : 0x2C0;
    mask_word = variant ? object+0x2A0 : object+0x29C;
    stream_mode = tag | 0x803F0000;
    entries = descriptor + *(u32*)(descriptor+0x18);
    for (j = 0; j < *(u32*)(descriptor+0x1C); ++j) {   // count re-read
        record = entries + 20*j;
        switch (*(u16*)(record)) {
        case 0: *mask_word |= ArmLsl(*(u32*)(record+4) & 1, *(u16*)(record+2)); break;
        case 1: emit two words (see above); break;
        case 2: emit six words (see above); break;
        default: break;
        }
    }
    *(u32*)(object + 0x12868 + 4*slot) = out - out_begin;
}
return object;
```

The slot count and the record count are both re-read from memory at their loop
bottoms (`0x00127E60` and `0x00127E30`), matching the original; the C++ loop
conditions perform those reloads. The mask-word accumulate is
read-modify-write per opcode-0 record, so several such records in one slot
accumulate bits.

### Differences from the original
- Candidate size is 380 bytes versus 420. GCC uses a different register
  allocation, folds the two mask-word addresses into one base with a computed
  offset, does not reuse the original literal pool, and materialises the
  `0x803F0000` / `0x000F0000` constants with different instruction forms.
- The original's unconditional mask store on opcode 0 is preserved as a single
  OR expression (one load, one store) per record.
- The record array is assumed not to alias the output buffer or the mask word.
  The per-record read-modify-write order, the kept duplicate loads in opcode 2
  and the loop-bottom record-count reload reproduce the original's accesses for
  the overlapped cases the body can observe.
