## Behaviour

- Starts at `base + 0x2000`. Each iteration filters 0x20 bytes; each 4-byte lane
  reads six rows at `centre{-0xc00,-0x800,-0x400,0,+0x400,+0x800}` and rewrites
  only the four middle rows (`-0x800, -0x400, 0, +0x400`), in that store order.
- Per lane: `pair = uhadd8(C, D)`; `B_out` starts as `uhadd8(pair, A)` and
  `E_out` as `uhadd8(pair, F)`; each is replaced by the original `B`/`E` when
  `|A-C|` / `|F-D|` reaches `threshold_b` per byte. The two centre outputs start
  from `pair` sharpened by `m = uhadd8(uhadd8(uhadd8(~E, B), 1), 1)`:
  `C_out = uqadd8(pair, uqsub8(m, 0x20))` then
  `uqsub8(..., uqsub8(0x20, m))`, `D_out = uqsub8(pair, uqsub8(m, 0x20))` then
  `uqadd8(..., uqsub8(0x20, m))`. Finally, for each byte where
  `|B-C| >= threshold_b`, `|D-E| >= threshold_b` or `|C-D| >= threshold_a`,
  all four outputs are replaced by their original row values (`B`, `C`, `D`,
  `E` respectively) — the four selects are per-byte and compose to an OR of the
  masks.
- Packed arithmetic: `uhadd8`, `uqsub8`, `uqadd8`, `uadd8`, unsigned `usub8`
  (GE = unsigned `a >= b`, **not** the signed `ssub8` used by the neighbouring
  0x0015f7bc/0x0015fba4 kernels), `mvn` and `sel`.
- Loop control: horizontal counter = `width_bytes - 0x10`, decremented by 0x20
  per chunk with a signed `> 0` branch. Exactly zero filters four trailing
  lanes (0x10 bytes); negative skips them after the unconditional first chunk.
  The vertical counter (`height_bytes - 8`) is decremented by 8 per band and
  loops while non-zero (`subs`/`bne`), so values where `height_bytes < 0x10`
  wrap for ~2^29 bands and are treated as out of domain.
- ABI: the original pushes only `{r0, lr}` and therefore clobbers callee-saved
  `r4-r11` (shared ABI violation with `0x0015f7bc`). The C++ candidate is a
  normal AAPCS function and preserves them.
