## Role and Behavior
- **Role:** Resets existing registered touch regions and registers touchable screen regions and buttons tailored to the active bottom-screen status state machine state (`work->state`).
- **Details:**
  - Unregisters all previously registered regions by calling `UiTouch_UnregisterLastRegion()` in a loop for `work->registered_touch_count`.
  - Resets `work->registered_touch_count = 0`.
  - Clears `work->slot_touch_handles` (41 entries initialized to `-1`) via `camp_func_002c4450`.
  - Dispatches by `work->state`:
    - **State 3 (Party Selection / Main View):** Registers `UiTouch_RegisterRegion(0x1A, 0x414 + i)` for party slots, and registers shoulder L (`0x50F`) and R (`0x50E`) button regions.
    - **State 4 (Party Selection / Minimal):** Registers party slot regions (`0x414 + i`) without shoulder buttons.
    - **State 6 (Prompt / Action Select):** Registers party slots (`0x414 + i`) plus action button (`0x4F1`).
    - **State 11 (Party Slot Target / Custom Rect):** Registers party slots up to `count - 2`, then calculates the custom layout bounding rectangle from layout nodes `0x4F1` and `0x41F` via `camp_func_002bf6d0` and registers it via `UiTouch_RegisterRectRegion`.
    - **State 16 (Command / Skill Submenu):** Registers 7 submenu touch slots (`0x466 + i`), suppressing slots 1 and 2 if `Flag_CheckEventBit(0x410)` is false, followed by shoulder L and R button regions.
    - **State 17 (Skill List):** Registers 11 skill row slots (`0x44C + i`), scroll-up (`0x4E7`), scroll-down (`0x4E8`), action button (`0x4E9`), and shoulder L/R buttons.
    - **State 19 (Item Grid):** Registers touch regions for up to a 9x4 grid (36 slots, `0x4AE + idx`), scroll-up (`0x4E7`), scroll-down (`0x4E8`), action button (`0x4E9`), and shoulder L/R buttons.
    - **State 21 (Item Actions):** Registers scroll-up (`0x4EA`), scroll-down (`0x4EB`), action button (`0x4EC`), and shoulder L/R buttons.
    - **States 22, 23, 25, 26 (Category Select & Confirmation):** Registers category slot regions (`0x414 + i`) up to `count - 2`, and registers the confirmation/back slot with `0x54A`.
    - **Default:** All other states perform the initial unregister and clear without registering new regions.
