## Supported contract

The helper accepts a pointer to readable, halfword-aligned `uint16_t` values. It returns the number of consecutive nonzero halfwords before the first zero, excluding that zero. The original reads exactly through the terminating zero, performs no writes, preserves the AAPCS callee-saved registers and stack, and returns through `bx lr`. Direct callers use ARM `BLX` and continue in ARM state after the Thumb helper returns.

C++ proposal is `extern "C" uint32_t candidate_002b5c2c(const uint16_t*)`. The source uses `__attribute__((target("thumb"), noinline))`; a final inline `cmp count,#0` reproduces the original returned-value NZCV (`C=1`, `V=0`, `N/Z` from count in the supported range). This compare was added after differential testing exposed the compiler's default flags differed for positive counts. The precondition excludes null/unterminated inputs, unaligned pointers and address-space/count wraparound; the original has no bound or null check.
