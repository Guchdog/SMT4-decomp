# `0x0028DF3C` — H2 conditional global store

## Contract

The helper accepts and returns a raw 32-bit `r0`. It computes `r0 + 1` modulo 2^32 and performs an unsigned comparison against 3. When `(r0 + 1u) < 3u`, it stores the original unmodified word at `0x0043E0BC`; otherwise it leaves that word untouched. Thus values 0, 1, and `UINT32_MAX` store, while 2 and other tested values do not. It has no stack frame or pointer checks, performs no memory reads beyond its PC-relative literal in the original, and preserves SP and `r4-r11`.

The original callback `0x00221168` calls this helper at `0x00221174` with zero, then passes its raw return (zero) into `0x00289640`. Another existing caller in `leaf_batch45_a.cpp` declares the symbol as `void`, calls it with `0xFFFFFFFF`, and discards `r0`. The implementation exposes the raw `uint32_t` return; existing cross-TU declarations and call sites were left unchanged. Their observable ARM boundary remains the raw input in `r0`, conditional store, and raw `r0` output.
