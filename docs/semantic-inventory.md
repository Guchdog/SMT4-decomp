## How to interpret progress

- Source inventory: the measured definitions below, including partial and exact-code experiments.
- Differential evidence: bounded original-versus-C++ executions recorded by each experiment; a static test link does not establish that the experiment ran or passed.
- Integrated replacement: code installed in a reproducible patch and reached by its real callers.
- Runtime validation: the documented scenario and observed behavior, with remaining original dependencies.

Historical totals such as 169 semantic candidates and 229 combined functions used different scopes. Do not add this inventory to the byte-exact milestone or interpret a coincidentally equal number as reconciliation. Promotion requires per-address evidence and the [functional acceptance criteria](reconstruction-milestones.md).
